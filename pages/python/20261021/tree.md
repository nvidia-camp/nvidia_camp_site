- self는 메서드를 호출한 현재 객체를 가리키는 관례적 이름.
- 서로 다른 객체의 역할 목록을 독립적으로 변경하는지 확인.

##### 주의: 클래스 속성의 List는 공유된다 (PDF p.11)

- 클래스 속성의 List는 객체 사이에서 공유되는 가변 상태.
- __init__에서 self.roles를 새로 생성해 객체별 독립 상태 구성.

### 2교시 · 객체지향 확장과 모듈

#### 객체지향과 객체 조합

##### 객체지향은 “역할을 나누는 설계”다 (PDF p.14)
