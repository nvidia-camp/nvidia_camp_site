## 3. 레이아웃 (2026-11-02 개편: 지도 A·B 분리)
사용자 피드백으로 한 지도에 관점을 하나만 두도록 둘로 나눴다. 첫 판은 확대 구조·데이터 흐름·도입 띠·교시 태그·UDL 절 번호를 한 그림에 겹쳐 읽기 어려웠다. 각 지도 맨 위에 "읽는 법" 한 줄을 둔다.

- **지도 A · 모델 안:** → 방향은 사진이 점수로 바뀌는 순서, ▼ 방향은 확대다.
  - ① 한 줄 흐름(layer-2): 사진 → 특징 추출부 → Global Pool → flatten → Head와 Shape. 아래에 Backbone/Head 괄호를 둔다.
  - ② Conv 블록(layer-4)
  - ③ Kernel 연산(layer-5): PDF p.6의 5×5 예시를 그리드로 그린다.
- **개념 관계:** 단계마다 화살표 옆 "관계 문장"(`.rel`)으로 쓰고 끝에 UDL 근거를 단다. 첫 판의 "왜 이런 구조인가" 띠와 Shape 따라가기 구역은 여기에 흡수했다.
- **지도 B · 모델 밖:** → 방향은 작업 순서다(데이터 준비 → 모델 후보 → 학습 → 평가·저장 → 장치 비교 → 성능표). 단계마다 교시와 "지도 A와 만나는 곳"을 적는다. 모델 후보 단계는 전이학습 표로 확대한다.
- **구성 순서:** 머리말 → 기초 개념 → 지도 A → 지도 B → 코드로 보기. DIAGNOSIS(증상 표)는 사용자 요청으로 삭제했다(2026-11-02). 전체 그림이 우선이고, 실습 관점은 코드로 보기가 맡는다.
- **기초 개념:** "이미 배운 것" 6개와 "오늘 새로 나오는 것" 10개로 나눈다. 새 용어 카드는 위쪽 accent 선으로 구분한다. 카드마다 한 줄 정의, 지도 위치 배지, UDL 근거를 둔다. Stride·Padding·Pooling에는 작은 칸 그림을 붙인다.
- **너비:** 기초 개념·지도는 1440px, 코드는 1120px.

## 4. 반복 패턴
- **칩:** 이름 · 한 줄 설명 · Shape만 둔다. UDL 절 번호는 관계 문장과 지도 아래 "근거" 줄로 옮겼다.
- **교시 필터:** 지도 A에만 둔다(1·2·3·6교시). 지도 B는 이미 교시 순서다.
- **위치 배지:** 기초 개념 카드의 A-①/A-②/A-③/B-n 배지 색은 레이어 색과 같다.

## 5. UDL과 PyTorch·강의의 차이 (본문 반영)
- **합성곱:** UDL은 엄밀히 교차상관이라고 밝힌다(10.2.1 각주).
- **ResNet 블록 순서:** UDL 그림 11.7은 BN → ReLU → Conv 순서(v2)이고, torchvision ResNet18은 Conv → BN → ReLU 순서(v1)다. 지도에는 블록 순서를 넣지 않고 Residual 개념만 표시했다.
- **BatchNorm 평가용 통계:** UDL은 학습 데이터 전체 통계를 고정한다고 설명하고, PyTorch는 running 평균을 쓴다.
