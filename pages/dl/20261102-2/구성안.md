# Day12 보조자료 구성안 (초안)

- **목적:** 수강생이 Day12 강의 PDF(`20261102-2.pdf`, 103쪽)를 펴 놓고 이해할 수 있게 한다. 강의는 범위와 읽는 순서를 정하고, 설명은 교재에서 가져온다.
- **교재:**
  - GF: Goodfellow·Bengio·Courville, *Deep Learning* (2016). 책 쪽수 + 16 = PDF 쪽수.
  - UDL: Prince, *Understanding Deep Learning* (2023). 책 쪽수 + 14 = PDF 쪽수.
- **구성:** 한 장 지도 → 공통 바탕 → 모델 셋(RNN·LSTM·Transformer) → 갈래(Autoencoder) → 같은 기준으로 비교.
- **모델마다 같은 틀:** 풀려는 문제 / 핵심 아이디어 / 구조 그림 / 계산 하나 / Shape / 한계. 이 틀을 가로로 읽으면 강의 p.72 비교표가 된다.

## 0. 한 장 지도 · 강의 p.2–3, p.17

- **업무 목적 두 칸**
  - ① 다음 값 예측: RNN → LSTM → Transformer
  - ② 입력 재구성: Autoencoder
- **계보선:** RNN → LSTM → Attention은 "순서를 더 잘 읽는" 한 줄의 발전이다. 각 화살표에 "왜 넘어갔나"를 한 줄씩 적는다.
  - 근거: UDL 12장 Notes "From RNNs to transformers" (책 233쪽). RNN은 먼 정보를 잊고, LSTM·GRU가 일부 해결했고, 번역에서 "특정 입력 단어에 주목"하는 아이디어가 Attention으로 이어졌다.
- **Autoencoder는 갈래로 둔다.** 이 줄의 다음 단계가 아니라는 것을 그림으로 보여 준다.

## 1. 공통 바탕 · 순서 데이터 · 강의 p.18–22 (1교시)

| 칸 | 내용 | 근거 |
|---|---|---|

| 핵심 아이디어 | **위치(시점)끼리 가중치를 공유한다.** Day11 CNN이 공간에서 공유한 것을 시간축에서 한다. 오늘 배우는 순서 모델들의 공통 출발점 | GF 10장 도입, UDL 12장 도입 |
| 구조 그림 | `[B,T,F]` 직육면체 + Padding 칸 + `lengths` | 강의 p.19–20 |
| 짚을 점 | Padding은 길이가 다른 것을 한 Batch로 묶는 장치일 뿐, 실제 값이 아니다. 그래서 이후 모든 모델에서 "Padding 제외"가 다시 나온다(RNN 마지막 시점, Attention key mask, 평균 Pooling) | 강의 p.21, 43, 65, 77 |

## 2. RNN · 강의 p.23–33 (2교시)

| 칸 | 내용 | 근거 |
|---|---|---|
| 풀려는 문제 | 길이에 상관없이, 같은 규칙으로 과거를 읽고 요약하려면? | GF 10.1 |
| 핵심 아이디어 | `h_t = f(h_{t-1}, x_t; θ)`. **같은 f를 시점마다 반복**한다. h는 지금까지 읽은 과거의 **손실 있는 요약**이다(길이와 상관없이 크기가 hidden_size로 고정) | GF 10.1 (식 10.5, 책 376쪽) |
| 구조 그림 | 접힌 그림 ↔ 펼친 그림. 펼친 그림에서 U·W·V가 모든 시점에 같다는 것을 색으로 표시 | GF 그림 10.2–10.3 ↔ 강의 p.24 |
| 계산 하나 | 강의 p.26 식 `h_t = tanh(W_x x_t + W_h h_{t-1} + b)`를 펼친 그림 위에 겹쳐 읽기 | 강의 p.26, GF 식 10.8 |
| Shape | `output` = 펼친 그림의 h 전부 `[B,T,H]`, `h_n` = 마지막 h. 단층·단방향·Padding 없음이면 `output[:,-1]`과 `h_n[-1]`이 같다. 입출력 유형(p.25)은 "어느 h를 읽느냐"의 차이 | GF 10.2 설계 패턴(그림 10.3·10.5) ↔ 강의 p.25, 27, 30 |
| 한계 ① 기억 | 같은 W를 T번 곱한다. 0.9⁵⁰ ≈ 0.005, 1.1⁵⁰ ≈ 117이므로, 먼 과거의 영향은 사라지거나 폭발한다. 길이 10~20만 돼도 SGD로 학습이 거의 실패한다는 실험이 있다 | GF 10.7 (스칼라 wᵗ 예, 책 403쪽) ↔ 강의 p.31 |
| 한계 ② 속도 | 앞 시점이 끝나야 다음 시점을 계산할 수 있다. 시간 O(T)이고 병렬화할 수 없다 | GF 10.2 (책 381쪽) ↔ 강의 p.31, 81 Q1 |

## 3. LSTM · 강의 p.34–45 (3교시)

| 칸 | 내용 | 근거 |
|---|---|---|
| 풀려는 문제 | 곱셈을 반복하는 것이 소실의 원인이다. 그렇다면 **곱해지는 값이 1 근처로 유지되는 경로**가 필요하다 | GF 10.9.2, 10.10 |
| 핵심 아이디어 | ① 이동평균 `μ ← αμ + (1-α)v`처럼 **더하기로 이어지는 자기 연결**(leaky unit)을 둔다. ② 그 α를 고정하지 않고, 입력을 보고 **Gate가 시점마다 정한다** | GF 10.9.2 → 10.10.1 (Gers 2000) |
| 구조 그림 | 위쪽 직선 = Cell state 고속도로, 밸브 셋 = forget·input·output gate | GF 그림 10.16 단순화 ↔ 강의 p.35, 37 |
| 계산 하나 | 강의 p.6: `0.5×2 + 0.4×0.5 = 1.2`. "남길 양 + 새로 쓸 양"이다. forget≈1이면 기억이 거의 그대로 흐른다 | 강의 p.6, 37 ↔ GF 식 10.41 |
| 연결 | 더하기 경로는 Day11 ResNet의 `x + F(x)` 지름길과 같은 발상이다(연결 설명이며 교재 주장 아님으로 표시) | UDL 11.2 |
| Shape | `(h_n, c_n)` 둘 다 `[L×D,B,H]`. c는 내부 기억이라 `output`에는 h만 나온다 | 강의 p.36, 39–41, 45 Q1 |
| 한계 | 여전히 순차 계산이다(O(T)). 먼 정보는 여전히 한 줄 통로를 거쳐 와야 한다 | UDL 12장 Notes ↔ 강의 p.31 |
| 참고 | 실험상 핵심은 forget gate이고, forget bias를 1로 두면 강해진다 | GF 10.10.2 |

## 4. Attention과 Transformer Encoder · 강의 p.59–75 (5–6교시)

| 칸 | 내용 | 근거 |
|---|---|---|
| 풀려는 문제 | 먼 위치를 한 줄 통로로 전달하지 말고 **직접 연결**하면 어떨까? 단, 연결 세기는 내용에 따라 달라야 한다("it"은 "restaurant"을 봐야 함) | UDL 12.1 |
| 핵심 아이디어 | 출력 n = Σₘ a[xₘ,xₙ]·vₘ. 가중치는 양수이고 합이 1이다. **Value를 비율대로 나눠 담는 라우팅**이다 | UDL 12.2 (식 12.3, 그림 12.1) |
| 계산 하나 | 강의 p.9: `0.2×10 + 0.3×20 + 0.5×30 = 23`이 바로 이 식이다 | 강의 p.9 ↔ UDL 12.2 |
| Q·K·V | 같은 x에 선형변환 셋을 적용한다. q·k는 유사도이고, softmax는 key들끼리의 경쟁이다. 강의 p.61의 역할 설명을 이 식으로 정리 | UDL 12.2.2 ↔ 강의 p.61, 69 Q1 |
| 왜 √d로 나누나 | 내적이 크면 softmax가 한쪽으로 쏠려 gradient가 거의 0이 된다. 예: [8,4,0] → [0.98, 0.02, 0.00], ÷4 → [0.67, 0.24, 0.09] | UDL 12.3.2 ↔ 강의 p.61 |
| 왜 Position이 필요하나 | Attention은 입력 순서를 바꿔도 결과가 같이 바뀌기만 한다(순서를 모름). "The woman ate the raccoon" 예. 학습 가능한 위치 표현도 교재가 인정한 방식 | UDL 12.3.1 ↔ 강의 p.66, 75, 69 Q2 |
| Multi-head | Head마다 D/H 크기를 쓴다. 그래서 `embed_dim`이 `num_heads`로 나누어져야 한다 | UDL 12.3.3 ↔ 강의 p.63, 73 |
| Encoder Layer | `X + MhSa → LayerNorm → x + MLP → LayerNorm`. PyTorch 기본값 `norm_first=False`와 같은 순서 | UDL 12.4 (식 12.13) ↔ 강의 p.64, 66, 71 |
| 왜 LayerNorm인가 | BatchNorm은 시점마다 통계를 따로 둬야 하고, 테스트 길이가 더 길면 처리가 불명확하며, 작은 Batch에서 불안정하다 → 샘플마다 정규화하는 LayerNorm | UDL 11.4 Notes (책 203쪽) |
| Mask | softmax 전에 점수를 −∞로 만들어 가중치를 0으로 한다. Causal은 미래 key, Padding은 채운 key를 막는다(Padding mask는 같은 원리의 응용으로 표시) | UDL 12.7 ↔ 강의 p.65, 77 |
| Shape | `[B,T,16]` → Layer → `[B,T,16]`(크기 유지) → 실제 위치만 평균 `[B,16]` → Head `[B,2]` | UDL 12.2.3 ↔ 강의 p.8, 67, 77 |
| 한계 | 가중치가 위치 쌍마다 하나라서 T²개다. 대신 모든 위치를 한 번에 계산한다(병렬) | UDL 12.2.1, 12.9 ↔ 강의 p.71, 81 Q2 |

## 5. 갈래 · Autoencoder · 강의 p.46–58 (4교시)

| 칸 | 내용 | 근거 |
|---|---|---|
| 풀려는 문제 | 정답 라벨 없이 데이터의 주요 패턴(정상 패턴)을 배우려면? | GF 14장 도입 |
| 핵심 아이디어 | 입력을 정답으로 삼아 복사하게 하되, **완벽히 복사하지 못하게 막는다.** 그래야 무엇을 남길지 우선순위를 배운다 | GF 14장 도입 (책 502쪽) |
| 구조 그림 | x → f(Encoder) → h(Latent) → g(Decoder) → r | GF 그림 14.1 ↔ 강의 p.7, 47 |
| 병목 | 코드 차원 < 입력 차원(undercomplete)이면 가장 두드러진 특징을 잡는다. 선형 + MSE면 PCA와 같은 부분공간이므로, Autoencoder는 비선형 PCA다 | GF 14.1 ↔ 강의 p.49 |
| 너무 작게, 너무 크게 | 너무 작으면 중요한 정보도 잃는다. 용량이 너무 크면 1차원 코드로도 "샘플 번호"를 외워 복사할 수 있어 아무것도 배우지 못한다 | GF 14.1–14.2 ↔ 강의 p.49, 57 응용 |
| 왜 오차가 '이상 후보'인가 | 학습 데이터를 닮은 입력만 잘 복사하도록 제한된 모델이라서, 낯선 입력은 오차가 커진다. 하지만 용량·전처리·분포의 영향도 받으므로 확정이 아니고, 임계값은 valid에서 정한다 | GF 14장 도입 ↔ 강의 p.51, 54, 58 |
| Denoising | 손상된 입력 → 깨끗한 원본을 예측한다 | GF 14.5 ↔ 강의 p.51, 57 심화 |
| Shape | `[B,8]→[B,4]→[B,2]→[B,4]→[B,8]`. `reduction="none"` → `[B,8]` → `mean(dim=1)` → `[B]` | 강의 p.7, 55–56 |
| 왜 갈래인가 | 오늘의 Autoencoder는 시간축이 없는 Linear 모델이다. 목적(재구성)과 지표가 달라 같은 표에 섞지 않는다 | 강의 p.52, 72, 76 |

## 6. 같은 기준으로 비교 · 강의 p.70–92 (6–7교시)

- **p.72 표 다시 읽기:** 표의 각 칸이 위 모델 틀의 어느 칸에서 왔는지 연결한다.
  - "핵심 연결" ← 핵심 아이디어
  - "병렬화"·"길이 비용" ← 한계
- **O(T)와 O(T²)를 강의 p.88 길이로 계산**
  - RNN·LSTM: 순차 계산 16·32·64·128단계
  - Attention: 점수 256·1,024·4,096·16,384개
  - 길이가 2배가 되면 RNN의 순차 단계는 2배, Attention의 점수 개수는 4배가 된다.
- **Padding 비율:** 채운 칸도 계산된다. Attention에서는 그 낭비가 제곱으로 커진다(강의 p.83, 92 Q2).
- **측정 해석(강의 p.90):** 이론상 계산량과 측정 시간은 다르다. 작은 입력에서는 실행 준비·전송 오버헤드가 지배한다. 교재 근거가 없으므로 강의 내용만 짧게 정리한다.
- 8교시 프로젝트는 지도 칸 ①·②를 다시 합치는 것으로 한 줄만 적는다(강의 p.11).

## 정한 판단

- **"코드로 보기" 구역은 따로 두지 않는다.** 모델마다 Shape 칸이 강의 코드 쪽을 직접 가리킨다.
- **교재 밖 내용은 표시한다.** LSTM과 Residual의 연결, Padding mask의 원리, 측정 오버헤드는 교재 본문 주장이 아니므로 그렇게 표시한다.
- **각 모델 구역 머리에 "강의 p.○–○를 읽을 때"를 단다.**
