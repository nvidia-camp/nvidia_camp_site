## 3. 레이아웃
- **한 장 지도(#map):** 위에서 아래로 읽는다.
  1. 공통 입력 띠: `[B,T,F]`, Padding, 가중치 공유
  2. 두 갈래: ① 예측(RNN → LSTM → Transformer), ② 재구성(Autoencoder). 점선으로 나눈다
  3. 아래 띠: 7교시 길이 비교, 8교시 결과표 분리
- **세로 = 모델 하나, 가로 = 비교.** 카드 넷은 CSS `subgrid`로 같은 행을 공유한다. 행 순서는 머리 → 그림 → 식 → 핵심 한 문장 → 이름표 → 기억 → 계산 → Shape → 정답·지표 → 강의 쪽이다. 아래 다섯 행을 가로로 읽으면 강의 p.72 비교표가 된다.
- **모델 사이 화살표 = 다음 모델로 넘어간 이유.** 주황 "문제" 상자와 설명 이름표로 표시한다.
- **이름표 → 설명 창:** 이름표를 누르면 `<dialog>`에 질문 하나가 열린다. 순서는 질문 → 한 줄 답 → 그림 → 접힌 교재 설명(+ 교재 절·강의 쪽)이다.
- **질문 목록(#notes):** 질문 16개(Q1~Q16)를 지도와 같은 네 칸 + 공통 바탕에 둔다. 질문 하나는 아래 순서로 쓴다.
  - 쉬운 질문 → 한 줄 답(말로 먼저) → (비유) → 그림 → "코드에서는"(실습 코드 한 줄로 착지, 강의 쪽 표시)
  - 수준 기준: 강의 퀴즈를 스스로 풀 수 있는 수준. 교재는 답과 그림을 정확하게 만드는 데만 쓴다.
  - 교재 설명 칸은 없앴다. 출처는 하단 "질문별 근거"에만 둔다.
  - 비유는 Q3·Q9·Q10·Q15 네 곳에만 둔다.
  - 용어는 원어(Hidden state, Cell state, Gradient, softmax, Padding, Latent 등)를 쓴다.
  - 개편 이력:
    1. 글 카드 23개 → 질문 16개: "이해하기 어렵고 복잡하다"는 피드백.
    2. 교재 설명 제거, 수준 낮춤: "강의보다 깊다"는 피드백.
    - 이전 판은 scratchpad `d12_index_v1.html`, `d12_index_v3pre.html`에 백업.
- **좁은 화면(64rem 이하):** 카드를 세로로 쌓고 화살표는 ↓로 바꾼다. 비교 행은 카드 안에 이름과 함께 남는다.

## 4. 교재와 강의·PyTorch의 차이, 교재 본문 밖
- **LSTM 표기:** 교재 GF는 상태를 s, input gate를 g로 쓴다. 지도는 강의·PyTorch 표기(c, i, g)를 따른다.
- **Encoder Layer 순서:** UDL 식 12.13(Residual 뒤 LayerNorm)은 PyTorch 기본 `norm_first=False`와 같다.
- **교재 본문 밖 (표시함):**
  - LSTM과 Residual의 연결(이 자료의 해석): 점선 이름표와 배지로 표시
  - Padding Mask: 교재의 Causal Mask와 같은 원리의 응용
  - 측정 시간 해석: 강의 p.90 내용만 옮김
