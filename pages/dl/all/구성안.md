## 4일 요약

> Day9에서 Tensor로 작은 신경망(ANN)을 만들고 순전파 → 손실 → 역전파 → 갱신으로 이어지는 학습 루프를 익혔습니다. Day10은 같은 루프에서 Optimizer·학습률·Batch를 바꿔 보고, train·valid 학습곡선으로 과적합을 진단해 Dropout·BatchNorm·Early Stopping을 더했습니다. Day11은 이미지를 읽는 CNN과 전이학습, Day12는 순서가 있는 데이터를 읽는 RNN·LSTM·Transformer와 입력을 복원하는 Autoencoder를 다뤘습니다. 학습 루프는 4일 내내 같고, 바뀌는 것은 학습 조건(Day10)과 모델 안의 층 구조(Day11~12)입니다.

4일 공통 학습 루프: `optimizer.zero_grad()` → `model(x)` → `loss_fn(...)` → `loss.backward()` → `optimizer.step()`, 평가는 `model.eval()` + `torch.no_grad()`

매일 수업 순서: 개념·시연 → 실습 → 7교시 측정·통합 → 8교시 재실행·설명

## 2. 날짜별 비교

열은 위와 같은 날짜입니다. 그날 새로 추가된 부분은 날짜 색으로 표시합니다.

### 2-1. 내부 구조 (입력에서 결과까지의 처리 순서)

| Day9 | Day10 | Day11 | Day12 |
|---|---|---|---|
| Tensor `[N, 2]` → **Linear → ReLU → Linear** → 점수 → **CrossEntropyLoss** → **backward → SGD 갱신** | 같은 ANN + **Dropout · BatchNorm** · Optimizer **AdamW · Scheduler** · **mini-batch** · epoch마다 train·valid 기록 → **Early Stopping · best 복원** | 이미지 `[N, C, H, W]` → **Conv2d → ReLU → MaxPool2d**(반복) → Global Pool → Linear Head → `[N, 2]` · 전이학습: **ResNet18 Backbone(고정) + 새 Head** | `[B, T, F]` → **RNN·LSTM**(Hidden state) → 마지막 시점 → Linear → 다음 값 · **Autoencoder**(Encoder → Latent → Decoder) · **Transformer Encoder**(Self-Attention + Mask) → Pooling → Head |
| 학습 루프가 처음 등장 | 모델은 그대로, 학습 조건이 추가 | 공간 구조를 읽는 층으로 교체 | 순서를 읽는 층으로 교체, 목적별로 모델이 갈림 |

### 2-2. 메소드 (단계별 대표 메소드, 모두 PyTorch · Day11은 torchvision 포함)

4일 공통: 위 "4일 공통 학습 루프" 한 줄

| 단계 | Day9 | Day10 | Day11 | Day12 |
|---|---|---|---|---|
| 준비 | `torch.tensor` · `.to(device)` · `TensorDataset` · `DataLoader` | `DataLoader(batch_size, shuffle)` | `ImageFolder` · `transforms.Compose` · `RandomHorizontalFlip` | `pad_sequence` · `pack_padded_sequence` |
| 처리·모델 | `nn.Linear` · `nn.ReLU` · `nn.CrossEntropyLoss` · `optim.SGD` | `optim.AdamW` · `lr_scheduler` · `nn.Dropout` · `nn.BatchNorm1d` | `nn.Conv2d` · `nn.MaxPool2d` · `models.resnet18` · `requires_grad_(False)` | `nn.RNN` · `nn.LSTM` · `nn.TransformerEncoder` · `nn.MSELoss` |
| 결과 확인 | `argmax` · `.item()` · `state_dict` | 학습곡선 기록 · `load_state_dict`(best 복원) | `torch.inference_mode` · `time.perf_counter` · `torch.cuda.max_memory_allocated` | `MSELoss(reduction="none")`(사례별 오차) · `src_key_padding_mask` |

요약 한 줄: 학습 루프 코드는 4일 내내 같고, Day10은 Optimizer와 규제 층, Day11~12는 모델 안의 층 클래스가 바뀐다.

### 2-3. 주요 파라미터 (날짜별로 사람이 정하는 주요 값)

| Day9 · 학습 루프 설정 | Day10 · 학습 안정화 설정 | Day11 · 합성곱·전이학습 설정 | Day12 · Sequence 입력·구조 설정 |
|---|---|---|---|
| `lr`: 한 번 갱신할 때 가중치를 바꾸는 크기 | Optimizer 종류: SGD(`momentum`) / AdamW. 기울기로 가중치를 바꾸는 규칙 | `kernel_size`: 한 번에 함께 계산할 주변 영역 크기 | `hidden_size`: 시점마다 넘기는 Hidden state의 크기 |
| `epochs`: train 전체를 반복하는 횟수 | `p`: Dropout이 학습 중 0으로 만드는 비율 | `stride`: Kernel이 한 번에 이동하는 칸 수 | `batch_first`: 입력 축 순서를 `[B, T, F]`로 쓸지 여부 |
| `batch_size`: 한 번 갱신에 쓰는 표본 수 | `weight_decay`: 가중치가 커지지 않도록 줄이는 정도 | `padding`: 가장자리에 채우는 칸 수 (출력 크기 유지) | Mask·`lengths`: Padding으로 채운 위치를 계산에서 빼기 |
| `device`: 계산할 장치 (CPU / CUDA) | `patience`: valid가 나아지지 않아도 기다릴 epoch 수 | `requires_grad`: 학습할 층 선택 (Head-only · Partial) | Latent 크기: Autoencoder가 입력을 압축할 차원 수 |

실측(값을 바꿨을 때 결과 변화)은 넣지 않습니다.

### 2-4. 평가 기준 (결과를 무엇과 비교해 평가하나)

| Day9 | Day10 | Day11 | Day12 |
|---|---|---|---|
| 학습이 되는지 확인: loss 감소, valid Accuracy, seed 고정 재실행 | train·valid 곡선 비교: valid loss가 가장 낮은 best epoch, 중단 시점 ≠ best 시점 | 모델과 장치를 따로 비교: valid Accuracy·오류 사례, 같은 조건의 시간·처리량·Peak VRAM | 목적별로 따로 평가: 예측 MSE ≠ 재구성 오차(점검 후보) ≠ 분류 Accuracy |

요약 한 줄: 모델 구조가 달라져도 같은 분할·같은 지표에서 조건 하나만 바꿔 비교하고, 목적이 다른 결과는 섞지 않는다.
