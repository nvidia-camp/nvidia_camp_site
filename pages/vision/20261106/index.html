객체 탐지와 추적

오늘 한 문장YOLO는 이미지를 한 번 보고 격자 칸마다 박스 후보를 낸다. conf와 NMS로 후보를 걸러 "무엇이(Class) 어디에(Box) 얼마나 확실하게(Confidence)" 있는지 남기고, 정답과의 IoU로 채점하고, 영상에서는 같은 객체를 Track ID로 잇는다.

한 장으로 보는 YOLO

격자 칸마다 후보를 내고, 두 번 걸러 남긴 뒤, 정답과 비교해 채점한다

Backbone·Neck·Head한 번 보고 격자마다 예측

420개 후보칸마다 박스 4개 + 클래스 점수 3개. 점이 클수록 점수가 높다(0.25 초과)

→

conf로 거르기conf=0.25

11개점수 낮은 후보를 버림. 같은 객체에 박스가 여러 개 겹쳐 있다

→

NMS로 중복 지우기iou=0.7

4개 = Results겹친 박스 중 점수가 가장 높은 것만 남김

→

정답과 비교해 채점평가 IoU ≥ 0.5

TP 3 · FP 1점선 = 정답 3개, 초록 = TP, 주황 = FP. NMS 기본값 0.7에서 남은 중복 1개가 FP가 됐다

응용 val 이미지 1장(정답 3개)을 공식 추론 경로 그대로 실행한 결과입니다. 입력 160×128 → 격자 20×16 + 10×8 + 5×4 = 420칸.

꼭 알고 갈
YOLO 개념

1

격자 칸마다 후보를 하나씩 낸다. 이미지를 한 번 보고(One-stage) 칸마다 박스 숫자 4개와 클래스별 점수를 냅니다. 객체가 3개여도 후보는 420개입니다.

2

격자는 세 가지 크기다. 촘촘한 격자는 작은 객체, 성긴 격자는 큰 객체를 맡습니다. Neck이 여러 크기의 특징을 섞는 이유입니다.

3

그래서 두 번 거른다. conf는 점수 낮은 후보를, NMS는 같은 객체에 겹친 중복을 지웁니다. 정답과 비교하는 평가 IoU는 채점할 때만 씁니다.

공식 문서의 기본 사용법 그대로, 오늘 배우는 과정을 가장 짧게 줄였습니다

① 좌표1

픽셀 xyxy → box_convert로 중심·크기 → 이미지 크기로 나눔

② 채점 기준2

box_iou로 예측 × 정답 겹침 표 → 0.5 이상이면 같은 객체

③ 라벨·데이터3

라벨 한 줄 = class cx cy w h, dataset.yaml로 경로·클래스 연결

④ 학습4

구조(.yaml)로 모델 만들기 → train() → best.pt·last.pt

⑤ 검증5

val() → mAP50·mAP50-95

⑥ 추론6

predict(conf) → 안에서 후보 420개 → conf → NMS → Results

⑦ 추적7

track(tracker) → Track ID

⑧ 재실행8

같은 입력·설정으로 다시 실행해 이미지 수·프레임 수·지표 대조

import cv2
import torch
from torchvision.ops import box_convert, box_iou
from ultralytics import YOLO

import준비

OpenCV는 그리기, torchvision.ops는 박스 계산, ultralytics는 YOLO 학습·추론·추적을 맡습니다.

boxes = torch.tensor([[12, 18, 52, 58]], dtype=torch.float32)  # x1, y1, x2, y2
cxcywh = box_convert(boxes, in_fmt="xyxy", out_fmt="cxcywh")
labels = cxcywh / torch.tensor([160, 128, 160, 128])           # x는 W, y는 H로
cv2.rectangle(image, (12, 18), (52, 58), (0, 255, 0), 2)      # 색은 BGR

1교시① 좌표

같은 박스를 픽셀 xyxy(모서리)에서 cxcywh(중심·크기)로 바꾸고, x는 폭 W로, y는 높이 H로 나눠 0~1로 만듭니다. OpenCV 색은 BGR 순서입니다.

문서: PyTorch torchvision.ops 문서 · OpenCV 5.0 Drawing Functions

iou = box_iou(pred_boxes, gt_boxes)        # [예측 수, 정답 수] 겹침 표
matched = iou >= 0.5                       # 같은 클래스와 1:1로 연결되면 TP

2교시② 채점 기준

box_iou는 예측 × 정답 겹침 표를 만듭니다. 0.5 이상이고 클래스가 같으면, 점수 높은 예측부터 정답 하나에 하나씩만 TP로 연결합니다.

문서: PyTorch torchvision.ops 문서

# labels/train/img_000.txt  →  0 0.200000 0.296875 0.250000 0.312500
#                              class cx cy w h  (객체 없는 이미지는 빈 파일)

# dataset.yaml
path: data              # 데이터 폴더

3교시③ 라벨·데이터

라벨 한 줄 = 객체 하나(class cx cy w h). dataset.yaml이 경로와 클래스 이름을 모델에 연결합니다. 객체가 없는 이미지는 빈 파일입니다.

문서: Ultralytics Datasets › Object Detection

model = YOLO("yolo26n.yaml")
model.train(data="dataset.yaml", epochs=60, imgsz=160)

4교시④ 학습

.yaml은 구조만 만들어 처음부터 학습하고, .pt는 학습된 가중치까지 불러옵니다. 학습이 끝나면 best.pt·last.pt가 남습니다.

문서: Ultralytics Modes › Train

metrics = model.val()

학습 직후 model은 best.pt입니다. 인자 없이 val()을 부르면 학습한 데이터 설정 그대로 val을 채점합니다.

문서: Ultralytics Modes › Val

for result in results:
    result.boxes.xyxy, result.boxes.cls, result.boxes.conf  # 0개일 수도 있음

안에서 후보 420개 → conf로 거름 → NMS로 중복 제거 → Results. 탐지가 0개인 이미지도 결과에 남습니다.

results = model.track("demo.avi", tracker="bytetrack.yaml", stream=True)
for result in results:

Tracker가 프레임 사이 같은 객체에 Track ID를 붙입니다. ID가 아직 없는 프레임이 있으니 is_track을 먼저 확인합니다.
