# Vision 4일 종합 · 디자인 기록

## 목적

Day13~16(Vision·멀티모달 AI 응용 1~4/4)을 한 장으로 묶는다. 위쪽 "4일 흐름"은 누구나 4일의 큰 흐름(전처리 → 분류 → 탐지 → OCR)을 바로 이해하도록, 아래 "날짜별 비교"는 전공자가 내부 구조·메소드·파라미터·평가 기준이 날마다 어떻게 더해지는지 확인하도록 만든다. 합의한 내용은 `구성안.md`에 있다.

## 사용자 지정 (2026-11-09)

- 날짜별 함수 나열이 아니라, 큰 그림 위에 "내부의 큰 변화, 파라미터, 메소드"가 늘어나는 모습을 보여 준다.
- 다음 날로 넘겨주는 것과 4일 공통 원칙 목록은 뺀다. 공통 순서는 머리말 한 줄로 둔다.
- 가로로 읽는 흐름(파라미터·메소드·평가)은 별도 구역 없이 각 행의 한 줄 요약으로 묶는다.
- 메소드는 단계별(준비 / 처리·모델 / 결과 확인) 대표만, 파라미터는 날짜별 카드(4개, 한 줄 뜻)로 쓴다.
- 대표 실측은 뺀다(각 날 oneday 요약에 있음).
- "계단" 같은 비유와 압축한 표현을 쓰지 않는다. 제목·설명은 평범한 문장으로 쓴다.

## 색

- 기본 토큰은 Day14~16 oneday 요약과 같다(`--color-primary #142849` 등).
- 날짜 면 색은 강의 PDF p.3 구역 색 팔레트를 날짜 구분에 재사용했다: Day13 `#E9F5EC`, Day14 `#FBF2DF`, Day15 `#F0ECF8`(Day13~15 준비·학습평가·설명정리), Day16 `#E9F3FC`(Day16 OCR).
- 날짜 글자·배지 색은 면 색을 어둡게 만든 파생값이다: `#2E6B45`, `#7A4F0E`, `#5B4A8E`, `#245C9C`. 흰 글자 대비 6.35·7.11·7.46·6.81:1(`build.py`가 4.5:1 이상인지 검사).

## 레이아웃

- 공통 격자: 행 이름 1칸 + 날짜 4칸(각 반칸 2개). "전날과 달라진 점" 카드는 이웃 날짜의 반칸씩 걸쳐 경계 위에 놓인다. 두 구역의 열이 같은 폭으로 맞는다.
- 날짜 머리의 색 막대 높이가 날짜마다 높아진다(0.75 → 3.75rem).
- 64rem 이하에서는 한 줄로 쌓고 칸마다 날짜 배지를 보인다. 라이브러리 이름 행은 숨긴다.

## 다시 만드는 명령 (site/pages/vision/all 폴더에서)

```bash
uv run render.py index.html Vision_4일종합.pdf [스크린샷 폴더]
```
