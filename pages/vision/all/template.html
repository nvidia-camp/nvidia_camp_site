13 → 14필터 값을 모델이 학습

Day13의 Blur Kernel과 CNN의 합성곱은 같은 계산입니다. Day13에서는 Kernel 값을 사람이 정했고, Day14에서는 Backbone(특징 추출기)이 데이터로 학습합니다. 사전학습된 Backbone을 가져와 Head(분류기)만 새로 학습하는 방식이 전이학습입니다.

Day13 개념지도 · Day14 p.5
14 → 15클래스에 위치(Box) 추가

Head가 클래스와 함께 Box와 Confidence를 출력합니다. 후보가 수백 개 나오기 때문에 conf와 NMS로 걸러 내고, 영상에서는 Tracker가 Frame 사이의 같은 객체에 같은 ID를 붙입니다.

Day15 p.4·9
15 → 16Box 안의 글자 인식

글자 영역을 Box로 찾고(Day15와 같은 형식) 그 안의 문자를 인식해 문자열을 얻은 뒤, 필요한 값을 JSON 필드로 정리합니다. VLM은 언어모델이 답을 문장으로 만듭니다. 문서에 없는 값을 만들어 낼 수 있어 OCR 원문과 비교해 확인합니다.

전처리 설정

  • ksizeBlur에서 평균을 낼 주변 영역 크기

Day14

학습 설정

  • requires_grad학습할 층 선택 (Head-only · Partial · Full)
  • lr한 번 업데이트할 때 가중치를 바꾸는 크기
  • epochs학습 데이터 전체를 반복하는 횟수
  • weight클래스 불균형을 보정하는 클래스별 가중치
Day15

결과 필터링·평가 기준

  • conf결과로 남길 최소 점수
  • iou (NMS)중복 Box로 보고 제거할 겹침 기준
  • 평가 IoU정답으로 인정할 겹침 기준 (0.5 / 0.5~0.95)
  • imgsz모델 입력 이미지 크기
Day16

OCR 입력 조건 · VLM 생성 설정

  • blockSize·CAdaptive Threshold의 주변 영역 크기와 보정값
  • --psmTesseract의 페이지 구조 가정 (6 텍스트 블록, 7 한 줄, 8 한 단어)
  • max_new_tokensVLM이 생성할 최대 토큰 수
  • do_sample샘플링 여부 (False면 같은 입력에 같은 답)
