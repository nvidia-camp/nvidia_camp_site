| | Day13 · 11/04 | Day14 · 11/05 | Day15 · 11/06 | Day16 · 11/09 |

| 전환 | 제목 | 설명 | 근거 |
|---|---|---|---|
| 13 → 14 | 필터 값을 모델이 학습 | Day13의 Blur Kernel과 CNN의 합성곱은 같은 계산입니다. Day13에서는 Kernel 값을 사람이 정했고, Day14에서는 Backbone(특징 추출기)이 데이터로 학습합니다. 사전학습된 Backbone을 가져와 Head(분류기)만 새로 학습하는 방식이 전이학습입니다. | Day13 개념지도, Day14 p.5 |

| 15 → 16 | Box 안의 글자 인식 | 글자 영역을 Box로 찾고(Day15와 같은 형식) 그 안의 문자를 인식해 문자열을 얻은 뒤, 필요한 값을 JSON 필드로 정리합니다. VLM은 언어모델이 답을 문장으로 만듭니다. 문서에 없는 값을 만들어 낼 수 있어 OCR 원문과 비교해 확인합니다. | Day15 p.104, Day16 p.4·7 |

## 2. 날짜별 비교

열은 위와 같은 날짜입니다. 그날 새로 추가된 부분은 날짜 색으로 표시합니다.

### 2-1. 내부 구조 (입력에서 결과까지의 처리 순서)

| Day13 | Day14 | Day15 | Day16 |
|---|---|---|---|
| 이미지 → Gray → Resize → Blur → Threshold → Morphology → **규칙 기반 판단** | 이미지 → 입력 변환 → **Backbone**(빌려 옴) → **Head**(새로 학습) → 클래스 점수 | 이미지 → Backbone → **Neck** → Head(클래스·Box·점수) → **conf → NMS** → **Tracker** | OCR: 전처리 → 글자 영역 탐지 → **문자 인식** → **필드 JSON** · VLM: 이미지 + 질문 → Vision Encoder → **언어모델** → 답 |
| 모델 없음. 파라미터는 사람이 지정 | 학습하는 모델이 처음 등장 | 객체마다 결과 1개 | 여러 모델과 단계를 연결 |

### 2-2. 메소드 (단계별 대표 메소드)

| 단계 | Day13 · OpenCV | Day14 · PyTorch | Day15 · Ultralytics | Day16 · Tesseract·Transformers |
|---|---|---|---|---|
| 준비 | `cv2.imread` · `cvtColor` · `resize` | `ImageFolder` · `transforms.Normalize` | `box_convert` (라벨 좌표 변환) | `adaptiveThreshold` · `warpPerspective` |
| 처리·모델 | `GaussianBlur` · `Canny` · `threshold` · `morphologyEx` | `requires_grad_(False)` · `nn.Linear` · `CrossEntropyLoss` · `optimizer.step` | `YOLO()` · `model.train` · `model.predict` · `model.track` | `image_to_data` · `pipeline("image-text-to-text")` |
| 결과 확인 | `imwrite` · `VideoWriter` | `argmax` · `f1_score` · `confusion_matrix` | `result.boxes` · `box_iou` · `model.val` | `re.search` · `jiwer.cer` · `json.dump` |

요약 한 줄: Day15부터 학습·추론은 함수 한 줄(`model.train`, `pipeline`)이고, 결과를 확인하는 코드가 늘어난다.

### 2-3. 주요 파라미터 (날짜별로 사람이 정하는 주요 값)

| Day13 · 전처리 설정 | Day14 · 학습 설정 | Day15 · 결과 필터링·평가 기준 | Day16 · OCR 입력 조건 · VLM 생성 설정 |
|---|---|---|---|
| `ksize`: Blur에서 평균을 낼 주변 영역 크기 | `requires_grad`: 학습할 층 선택 (Head-only · Partial · Full) | `conf`: 결과로 남길 최소 점수 | `blockSize`·`C`: Adaptive Threshold의 주변 영역 크기와 보정값 |
| `thresh`: 흰색(물체)으로 나눌 밝기 기준값 | `lr`: 한 번 업데이트할 때 가중치를 바꾸는 크기 | `iou` (NMS): 중복 Box로 보고 제거할 겹침 기준 | `--psm`: Tesseract의 페이지 구조 가정 (6 텍스트 블록, 7 한 줄, 8 한 단어) |
| `interpolation`: Resize할 때 새 픽셀 값을 계산하는 방법 | `epochs`: 학습 데이터 전체를 반복하는 횟수 | 평가 IoU: 정답으로 인정할 겹침 기준 (0.5 / 0.5~0.95) | `max_new_tokens`: VLM이 생성할 최대 토큰 수 |
| `fps`: 저장할 영상의 초당 프레임 수 | `weight`: 클래스 불균형을 보정하는 클래스별 가중치 | `imgsz`: 모델 입력 이미지 크기 | `do_sample`: 샘플링 여부 (False면 같은 입력에 같은 답) |

실측은 각 날 oneday 요약에 있어 넣지 않습니다.

### 2-4. 평가 기준 (결과를 무엇과 비교해 평가하나)

| Day13 | Day14 | Day15 | Day16 |
|---|---|---|---|
| 처리 결과의 형식 확인: shape·dtype, 재읽기 | 전체 성능과 클래스별 성능 확인: Accuracy ≠ Macro F1, Confusion matrix | 클래스·위치·중복을 함께 확인: 클래스 + 위치 IoU + 중복 아님 → mAP50·mAP50-95 | 글자·필드·근거를 따로 확인: CER ≠ 필드 정답 ≠ 근거 일치 |

요약 한 줄: 출력이 복잡해질수록 따로 확인할 지표가 늘어난다.
