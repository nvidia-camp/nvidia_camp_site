# 머신러닝 핵심 치트시트 디자인

## 1. 기준과 목적
[새싹 과정 공통 DESIGN.md](../../../DESIGN.md)를 적용한다. Day7 학습 흐름·필수 함수·원칙을 빠르게 찾는 복습 문서. 토스 공식 자료의 일관성·간결한 문구·접근성을 참고하며 수치는 과정 자체 규칙이다.

## 2. 색상
PDF 토큰: primary #142849, heading #1C2B40, text #222F44, muted #52667E, canvas #F9FBFE, surface #FFFFFF, soft #F0F6FD, border #D8E4F2, code-bg #1B2435, code-text #FFFFFF. HTML의 --color-* 변수를 단일 원본으로 사용하고 짧은 별칭은 이를 참조한다.

## 3. 글자
Segoe UI·Malgun Gothic, 코드 Consolas. 제목 40px/모바일 30px, 구역 24px, 단계 20px, 본문·함수 설명 16px, 보조·코드 14px. 본문 행간 1.7, 코드 1.65. 한글 단어 단위 줄바꿈과 긴 API 이름의 안전한 줄바꿈.

## 4. 레이아웃
최대 너비 1120px, 설명 문단 720px. 여백 16–48px. 간격 4·8·12·16·24·32·48·64px. 카드 반경 16px, 버튼·코드 12px. 짧은 소개 뒤 실제 내용. 7단계 경로는 7열·4열·2열로 전환. 760px 이하 요약표와 520px 이하 함수표는 카드형 행.

## 5. 반복 패턴
한국어 단계명·영문 보조명, 요약표, 데이터 역할 안내, 단계별 details, 함수표, 어두운 코드·복사 버튼, 출처. 단계 설명과 필수 원칙은 항상 표시. 선택 경로와 열린 단계는 연한 청색 배경과 글자 위계로 표시.

## 6. 동작과 접근성
주요 버튼 최소 44px 높이. 호버·눌림·키보드 포커스 제공. 링크 밑줄과 단계 번호로 탐색 가능성 표시. 코드 내부 가로 스크롤 안내와 복사 피드백. 인쇄 시 상세 펼침·밝은 코드 배경. 200% 확대와 375·768·1280px 확인.

## 7. 구현과 검증
오프라인 단일 HTML. CSS 변수와 기존 DOM을 사용. 외부 글꼴·런타임 의존성 없음. 학습 내용 변경 시 연결 예제를 다시 실행하고 브라우저에서 넘침·조작·인쇄·로컬 링크를 검증.

## 내용 선별 기준
교재에 등장한 사실만으로 핵심 함수에 넣지 않는다. 여러 상황에서 반복 쓰고, 초급자가 기본 흐름을 직접 실행하는 데 필요한 함수를 우선한다. 함수·메서드와 설정값을 구분한다. 모델 종류는 역할을, 설정은 조절 의미를 익힌다. 자동 탐색·모델 내부 속성·복잡한 열별 처리 조합은 핵심 암기 범위에서 제외한다. Pipeline은 누수 방지를 위한 제공 틀로 설명하며 조합 문법의 암기를 요구하지 않는다. 연결 예제는 기본필수 정상 20건·숫자 한 열로 축소하고 원본 통합 실습과의 차이를 명시한다.
