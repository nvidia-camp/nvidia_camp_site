# PyTorch 핵심 치트시트 디자인

공통 기준: [공통 DESIGN.md](../../../DESIGN.md). 아래는 이 문서에만 적용하는 규칙이다.

## 목적과 범위
- A4 가로 한 장. 전체 학습 흐름과 단계별 핵심 메소드·파라미터를 한눈에 본다.
- 구획 순서는 PyTorch 한국어 튜토리얼 「파이토치 기본 익히기」를 따른다: 0 흐름 → 1 텐서(shape) → 2 데이터 → 3 모델 → 4 손실·기울기 → 5 최적화 → 6 평가·과적합 → 7 저장 → P 파라미터 두 종류.
- 포함 기준: 지도학습의 기본 메커니즘(미니배치 → 순전파 → 손실 → 역전파 → 경사하강 → 반복 → 일반화 평가)에 직접 필요한 것만.
- 파라미터는 두 종류만 남긴다: 학습 결과를 좌우하는 하이퍼파라미터(lr, batch_size, epochs, 은닉 크기), shape를 맞추는 파라미터(in_features/out_features, dim, -1).
- 뺀 것: Conv2d, Embedding, BatchNorm, 스케줄러, AdamW, momentum, dtype, permute·cat 등. 따라 치는 노트북에서 다룬다.

## 레이아웃
- 3단: 왼쪽(1.2fr) 전체 흐름 코드 + 배치 shape 표 + 자주 하는 실수, 가운데 1~3, 오른쪽 4~7 + P.
- 흐름 코드 맨 위에 하이퍼파라미터를 변수로 모으고(`lr, batch_size, epochs`) 배지 P로 파라미터 표와 잇는다.
- 흐름 코드의 줄 끝 번호 배지는 아래 카드 번호와 같다.
- 1160px 이하 화면에서는 한 줄로 쌓고 글자를 키우며, 흐름 코드의 번호 배지는 숨긴다.
