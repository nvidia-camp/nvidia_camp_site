# OpenCV 치트시트 디자인·근거

- 목적: Day13의 익숙한 코드로 이미지 처리와 영상 반복의 전체 흐름, 핵심 함수·인자를 한눈에 확인.
- 기준: [새싹 공통 디자인](../../../DESIGN.md), 사용자 제공 PyTorch_치트시트.pdf의 가로 한 장·3단·코드 번호와 설명 카드 연결 구조.
- 기본 색: #142849 / #1C2B40 / #222F44 / #52667E / #F0F6FD / #D8E4F2 / #1B2435. Day13 PDF p.48·90도 남색·연청 체계임을 확인. 코드 구문과 인자 강조 색은 기존 PyTorch 치트시트의 파생 색 재사용.
- 인쇄: A4 가로 한 장. 본문 9pt, 코드 7.8pt. 모바일은 같은 내용을 1열로 표시하며 본문 12pt·코드 10pt로 확대.
- 전체 코드: 응용 07_project.py의 Gray → Resize → GaussianBlur → Canny를 그대로 사용. 반환 gray/small/edge와 Frame 재사용 유지. 이미지 한 장으로 축약하고 읽기·저장 검사, try/finally 자원 해제 추가. CSV·시간 측정은 생략. 정상 수업 입력용이며 assert 검사에는 Python -O 실행 제한이 있음.
- 갈래 A는 심화 image_ops.py의 threshold·3×3 RECT·Opening을 인용. Canny 출력에 연속 적용하는 것으로 오해하지 않도록 blur에서 별도 분기. 갈래 B는 flip·회전의 학습용 예. 실제 데이터셋의 무작위 증강 정책과 고정 예제 구분.
- 함수 설명은 OpenCV 4.13 공식 문서와 버전 고정 Context7 /opencv/opencv/4.13.0을 대조. 외부 글꼴·JavaScript 라이브러리·이미지 다운로드 없음.

## 검증 결과 (2026-11-04)

- 실제 실행은 기존 pdf2zh-next 도구 환경의 OpenCV 5.0.0·NumPy 2.5.3을 uv run으로 사용. OpenCV 4.13.0 환경에서 실행한 것으로 표기하지 않음. 새 패키지·프로젝트 의존성 추가 없음.
- 임시 디렉터리에 수업의 scene.png·sample.avi를 복사해 전체 코드 실행. 출력 PNG 원소 완전 일치, 영상 실제 디코드 48Frame·12FPS·160×120·4초 확인. 원본·수업 outputs는 수정하지 않음.
- Threshold/Opening 출력 0·255, flip 크기 보존, 회전 2×3 행렬과 출력 크기 확인.
- 375·768·1280·1440px에서 페이지 가로 넘침·깨진 앵커 없음. 코드 블록은 모바일에서 내부 가로 스크롤. 480px 이하 흐름은 2열, 코드 번호 배지는 숨김.
- 실제 클립보드 복사 성공·실패 안내 확인. 복사 내용은 실행한 코드와 문자 단위 일치하며 번호 배지를 제외.
- Chrome PDF 1쪽(가로 A4), 텍스트와 모든 핵심 함수·바닥글 포함. 6개 공식 문서 링크와 25개 내부 번호 링크 확인. 텍스트 하단 잘림 없음. PDF와 모바일 화면 직접 확인.
- 최종 본문 9pt·코드 7.8pt를 유지하고 설명 반복을 줄임. 세로 코드 → 가운데 핵심 함수 → 오른쪽 영상·갈래 구조. 모바일 본문 12pt·코드 10pt.
- 강의 저장소에는 커밋하지 않음.
