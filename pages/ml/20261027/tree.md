### 1교시 · Decision Tree의 분류·회귀 원리

#### 데이터 계약과 평가 정책

##### 공통 데이터와 예측 시점은 그대로 유지 (PDF p.7)

- 실행 전 입력 4열과 실패 분류·소요시간 회귀의 정답 정의 유지.
- 분류 주 지표는 실패 F1, 회귀는 ms 단위 RMSE.
- 정답·실행 후 정보·식별자 제외와 기존 60·20·20의 ID·순서 보존.
- 합성 요청 100건의 결과를 실서비스 대표 성능으로 일반화하지 않음.

##### 오늘의 평가 규칙 · CV와 valid를 구분 (PDF p.8)

- train60은 fold 내부 전처리를 포함한 5-fold 비교에 사용.
- 기존 valid20은 오류·기존 결과 진단, test20은 최종 선택 전까지 보관.
- 후보·지표를 미리 고정해도 CV·valid 반복 조회의 선택 편향은 남음.

#### 질문·노드·불순도

##### Decision Tree · 질문을 나누어 예측한다 (PDF p.9)

- 한 번에 한 특성 조건으로 자료를 둘로 나누는 예측 구조.
- 루트·내부 노드·잎의 역할과 학습 자료로 질문을 고르는 과정 구분.
- 분류는 잎의 클래스 분포, 회귀는 잎의 대표 수치 사용.

##### 작은 예제 · “글자 수 ≤ 500”이라는 질문 (PDF p.10)

- 글자 수 500 이하와 초과로 6개 사례를 두 잎에 배분하는 원리 예제.
- fit은 질문 선택, predict는 저장된 조건을 따라 잎으로 이동하는 단계.

##### 질문 선택 · 섞인 정도가 얼마나 줄었는가? (PDF p.11)

- Gini는 분류 노드의 클래스 혼합 정도.
- 부모 대비 자식의 표본 수를 반영한 가중 불순도 감소로 후보 질문 비교.
- 더 큰 감소량의 선택과 전체 트리의 전역 최적화는 구분.
- Gini를 평가 점수·회귀 오차로 해석 금지.

#### 첫 트리 학습과 원리 실습

##### 첫 분류 트리 · 조건과 예측 확인 (PDF p.12)

- 깊이 1의 분류 트리에서 임계값·예측·클래스 확률 확인.
- 학습 깊이와 잎 수를 조회해 실제 구조와 설정 대조.

##### 회귀 트리 · 숫자를 구간별 평균으로 예측 (PDF p.13)

- squared_error 기준 회귀 트리는 잎의 정답 평균으로 예측.

- 트리는 깊이·잎·가지치기, Forest는 개별 복잡도·특성·트리 수, XGBoost는 깊이·규제·학습률·회차 조절.
- 고정 후보·지표에서 한 번에 바꾼 조건·손실·계산량·편차를 진단.
- 과소적합과 과적합의 균형을 검증.

##### 조기 종료 · 손실 개선이 멈추는 지점을 찾기 (PDF p.52)

- 독립 시연은 train60을 inner42·stop18로 나눠 손실 개선 중단 시점 관찰.
- 교재 제시 최적 회차 64·실제 학습 79회와 개선 없는 15회 종료 조건 구분.
- stop도 선택용 자료이며 valid20·test20을 사용하지 않음.
- 기본 XGB80 비교와 별도 실험으로 기록.

#### 5-fold 구성과 누수 방지

##### 교차검증 · 한 번의 검증 분할에 덜 의존 (PDF p.53)

- train60을 5개 부분으로 나눠 매 회 48건 학습·12건 평가.
- 후보마다 같은 fold를 적용해 점수·평균·편차 비교.
- CV도 후보 선택 결과이므로 최종 일반화 성능 확정과 구분.

##### 5-fold의 안쪽에서 전처리도 다시 학습 (PDF p.54)

- 각 fold의 학습48에서 전처리와 모델을 모두 fit.
- fold 평가12는 학습된 변환과 예측만 적용.
- cross_validate의 test_score는 fold 평가 반환 이름으로 보관 test20과 구분.

##### 틀린 CV와 올바른 CV · 학습 범위가 다르다 (PDF p.55)

- train60 전체 전처리 후 CV는 fold 평가 통계가 학습에 들어가는 누수.
- 아직 학습하지 않은 전체 Pipeline을 전달해 fold 학습48 안에서 전처리 학습.
- train 내부에서도 학습·평가 경계를 독립적으로 유지.

#### CV 실행과 fold 통계 검사

##### cross_validate에 Pipeline 전체를 전달 (PDF p.56)

- 고정 분류 fold와 전체 Pipeline으로 cross_validate 실행.
- 학습·평가 점수와 fold 모델을 반환해 결과와 학습 범위 확인.
- std(ddof=0)은 5개 결과의 기술적 산포.

##### fold별 결과 · 평균 하나로 가리지 않기 (PDF p.57)

- Forest의 fold F1 평균 0.280·표준편차 0.254와 개별 0점 fold를 함께 제시.
- 12건 평가 구성에 민감한 결과를 평균 하나로 가리지 않음.
- fold 편차를 95% 신뢰구간·정확한 미래 성능 범위로 해석 금지.

##### 각 fold의 중앙값이 학습48에서 왔는지 검사 (PDF p.58)

- fold별 학습 모델의 imputer 통계와 해당 학습 인덱스48의 중앙값 대조.
- 학습·평가 인덱스 교집합 0과 전 fold의 통계 출처 확인.

#### 분할 정책과 교차검증 실습

##### 문제에 맞는 분할기와 점수 해석 (PDF p.59)

- 독립 분류는 StratifiedKFold, 독립 회귀는 KFold로 문제별 설계.
- 연속 정답의 직접 층화 금지와 요청 단계·미래 요청의 그룹·시간 분할 필요 구분.
- 같은 문제 후보는 같은 fold, 다른 문제 지표는 합산 금지.

##### 3분 퀴즈 · fold 안의 학습 범위 (PDF p.60)

- fold 안의 전처리 fit 범위와 test_score의 뜻 확인.
- 평균±표준편차를 신뢰구간과 구분.

##### 실습 06 · train 내부 교차검증 적용 (PDF p.61)

- 기본필수는 Tree·Forest·XGB에 같은 5-fold를 적용해 F1 점수·평균·편차 기록.
- 응용은 회귀와 음수 RMSE 부호 복원, 심화는 통계 출처 검사·4후보 탐색 또는 내부 조기 종료의 별도 실험.
- 완료는 fold ID·점수·학습 근거·test 보관.

**핵심:** 각 fold 학습 부분에서 전처리까지 새로 fit하고, 같은 fold의 점수·산포·학습 범위 증거로 후보 비교.

### 7교시 · 모델 비교와 프로젝트 통합

##### 최종 비교의 조건 · 바뀐 것과 유지한 것 (PDF p.62)

- valid는 진단, 작은 차이는 추가 검증 대상으로 기록.

#### 분류·회귀의 CV와 valid 비교

##### 분류 비교표 · 같은 fold에 같은 후보 순서 (PDF p.63)

- 기존 3개·새 3개 후보에 같은 분류 fold 적용.

##### 분류 결과 · CV와 valid의 순위가 다르다 (PDF p.64)

- 교재의 CV 평균 F1 최고는 Tree 0.542, valid 최고는 KNN3 0.545.
- 모델별 평균·편차·valid F1·FP·FN을 함께 비교.
- 유리한 평가 결과만 골라 보고하는 선택 금지.

##### 회귀 비교표 · 음수 scorer를 RMSE로 변환 (PDF p.65)

- 회귀 KFold에 neg_root_mean_squared_error를 적용.
- 큰 값 우선 scorer의 음수 부호를 되돌려 fold별 RMSE의 평균 계산.
- CV와 별도로 valid RMSE를 ms 단위 기록.

##### 회귀 결과 · 0.78ms 차이를 과장하지 않기 (PDF p.66)
