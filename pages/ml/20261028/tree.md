### 1교시 · 혼동행렬과 분류 지표

#### 양성 라벨과 지표의 분모

##### 좋은 모델의 기준을 먼저 정한다 (PDF p.9)

- 예측 대상과 오류의 손실을 기준으로 주 지표 선택
- 같은 자료·양성 라벨·평가 기준에서 후보 비교

##### 혼동행렬 · 양성은 “실패1”이다 (PDF p.10)

- 행은 실제값이고 열은 예측값인 혼동행렬 해석
- `labels=[0,1]`의 펼친 순서는 TN·FP·FN·TP
- FP는 성공의 오탐이고 FN은 실제 실패의 놓침

##### Accuracy · 전체 정답 비율 (PDF p.11)

- Accuracy는 `(TP+TN)/전체 수`인 전체 정답 비율
- 다수 클래스가 많으면 실패 발견 없이도 높은 정확도 가능

##### Precision과 Recall · 분모가 다르다 (PDF p.12)

- Precision의 분모는 예측한 양성 수 `TP+FP`
- Recall의 분모는 실제 양성 수 `TP+FN`
- 두 값이 같아도 분모가 가리키는 집합은 서로 다름

##### F1 · 두 비율의 균형을 한 값으로 (PDF p.13)

- F1은 Precision과 Recall의 조화평균
- `2TP/(2TP+FP+FN)`으로 계산하며 TN과 업무 비용은 직접 반영하지 않음
- `zero_division=0`은 분모 0 상황의 기록 정책

#### 지표 계산과 기준선

##### 혼동행렬과 네 지표를 코드로 계산 (PDF p.14)

- 실제값과 예측값으로 혼동행렬·네 지표 계산
- 양성 라벨과 행·열 순서를 고정해 손계산과 대조
- 분모 0 처리 정책을 결과와 함께 기록

##### 정확도 0.70인데 실패는 0건 발견 (PDF p.15)

- 모든 요청을 성공0으로 예측하는 다수 클래스 기준선 확인
- 높은 Accuracy와 실패 발견 능력의 차이 해석

#### 업무 기준 선택과 실습

##### 지표 선택 이유를 업무 문장으로 쓴다 (PDF p.16)

- 놓침 손실이 큰 상황에서 Recall과 실제 FN 검토
- 경고 확인 비용이 큰 상황에서 Precision과 실제 FP 검토
- 회귀에서는 오차 단위와 큰 잔차를 기준으로 MAE·RMSE 선택

##### 3분 퀴즈 · 분모와 양성 라벨 (PDF p.17)

- Precision·Recall 분모의 구분 점검
- F1이 표현하지 않는 비용과 TN 확인
- 양성 예측 0건 상황과 계산 정책의 구분

### 2교시 · ROC-AUC와 임계값

#### 연속 점수와 순위 평가

##### 점수·확률·클래스를 구분한다 (PDF p.19)

##### ROC · 임계값에 따른 발견과 오탐 (PDF p.20)

- FPR은 `FP/(FP+TN)`인 성공 요청의 오탐 비율

##### ROC 좌표와 AUC를 계산한다 (PDF p.22)

- `roc_curve`로 FPR·TPR·임계값 계산
- `roc_auc_score`에 실제 라벨과 연속 점수 전달

#### 임계값과 오류 비용

##### 임계값을 바꾸면 오류 비용이 달라진다 (PDF p.24)

- 동일 점수에 임계값 0.5·0.3을 적용해 FP·FN·F1 비교

- AUC와 함께 경고 수·Precision·Recall 검토
- 불균형 자료에서는 실제 양성 수와 PR 관점 확인
- 단일 클래스의 AUC 계산 불가를 0으로 대체하지 않음
- 확률 보정과 운영 비용은 별도 평가 대상

### 3교시 · 회귀 오차와 교차검증

#### MAE와 RMSE

##### RMSE · 큰 오차를 더 강하게 반영한다 (PDF p.28)

##### 평균·표준편차·합친 점수는 다르다 (PDF p.33)

### 5교시 · K-Means와 군집 해석

#### 지도학습과 군집의 원리

##### KNN과 K-Means는 다른 문제를 푼다 (PDF p.46)

- KNN은 입력과 정답을 이용하는 지도학습
- K-Means는 정답 없이 중심을 학습하는 비지도학습
- KNN의 K는 이웃 수이고 K-Means의 K는 군집 수
- 군집 번호는 성공·실패나 위험 순위와 무관

##### K-Means · 할당과 중심 갱신을 반복 (PDF p.47)

- 초기 중심 설정 → 가까운 중심에 할당 → 소속 점 평균으로 중심 갱신의 반복
- inertia는 중심까지의 제곱거리 합
- 초기화에 따라 학습 결과가 달라질 가능성

##### 6개 점을 두 군집으로 묶는다 (PDF p.48)

- 2차원 점6개를 K=2로 묶는 원리 예제
- `fit_predict`에는 정답 y를 전달하지 않음
- `n_init`과 `random_state`로 초기화 조건 기록

##### 군집 중심은 소속 점들의 평균 (PDF p.49)

- 군집 중심은 소속 점 좌표의 평균
- 번호를 서로 바꿔도 같은 묶음 유지
- 단위가 같은 원리 예제와 글자 수·도구 수의 실제 스케일 차이 구분

- 군집 중심을 원단위 글자 수·허용 도구 수로 해석
- 도구 수 중심의 소수는 군집 내부 평균
- 중심은 결측 대체 후 좌표의 평균이며 실제 사용량·성공률과 구분

#### 군집 수와 거리 지표

##### 군집 평가 · inertia와 silhouette (PDF p.52)

- inertia는 같은 입력·스케일에서 비교
- K 증가에 따른 inertia 감소만으로 최적 K 판단 금지
- silhouette는 같은 군집과 다른 군집의 거리를 비교하는 −1
- 1 지표
- silhouette 계산 조건은 실제 군집 수가 2 이상이고 표본 수 미만
- 거리 공간의 분리도와 업무적 유용성 구분

##### 동일한 전처리로 K=2·3·4 비교 (PDF p.53)

- 같은 전처리와 입력에서 K=2·3·4 비교
- silhouette는 군집을 학습한 표준화 공간에서 계산
- 각 K의 inertia·silhouette를 서로 다른 기준으로 기록

##### K가 많다고 항상 더 유용하지 않다 (PDF p.54)

- 원본 예제는 K=3의 silhouette가 높지만 K=4의 inertia는 더 작음
- 지표·개수·중심·입력 의미를 함께 검토
- 현재 train60의 결과를 새 자료의 최적 K로 일반화하지 않음

- 완료 기준은 정답 미사용과 군집 번호의 한계 설명
- silhouette는 기본필수 완료 조건에서 제외

**핵심:** 같은 거리 공간의 지표로 군집을 비교하고 번호·분리도를 위험도나 업무 유용성과 구분

### 6교시 · 선택 계획 확정과 최종 평가 원리

#### CV 선택 규칙과 진단 자료

##### test를 열기 전에 선택 계획을 확정한다 (PDF p.58)

- 선택 전에 후보·특성·주 지표·동점 규칙 기록
- 고정 임계값은 0.5이며 엄격한 초과 조건 사용
- valid 진단과 최종 독립 평가의 역할 구분

##### 사전 선언한 7개 후보의 개발 결과 (PDF p.59)

- 원본7후보는 같은 CV 평균 F1 규칙으로 비교
- 근소한 평균 차이를 확실한 우월성으로 해석하지 않음
- 수정판 기본필수는 원본·로그 추가 두 표현 비교
- 응용은 Logistic·Logistic_FE 두 후보이며 전체7후보는 심화 범위

##### 선택 함수는 test를 입력받지 않는다 (PDF p.60)

- 선택 함수에는 train CV와 valid 진단만 전달
- 반올림 전 CV 평균 F1 최대 후보 선택
- 정확한 동점은 사전 후보 순서 적용
- test 입력과 정답은 선택에 미사용

#### 설정 기록과 재학습·평가의 경계

##### 선택과 재학습과 평가는 별도 단계 (PDF p.61)

- 선택 → 설정 기록 → 새 모델 재학습 → 최종 평가의 단계 분리

- 기본필수·응용의 JSON은 접근 통제 장치가 아닌 실험 기록

##### 확정한 설정을 저장하고 개발80건 재학습 (PDF p.62)

- 원본 예제는 확정한 설정을 저장한 뒤 새 Pipeline을 개발80에 fit
- 개발 자료 재학습으로 전처리 통계가 달라지는 것은 허용된 변화
- 기본필수 수정판은 7교시에 개발16으로 새 모델 학습
- 원본의 `evaluation_lock.json` 대신 수정 실습은 `selection.json` 사용

##### 동결된 모델을 test20에 적용한다 (PDF p.63)

- 확정 모델은 test에 transform·predict만 적용
- 실패1의 연속 확률로 AUC 계산
- 고정 임계값의 판정값으로 분류 지표 계산

##### 최종 점수는 한계와 함께 보고한다 (PDF p.64)

- AUC와 실제 실패 발견 비율의 차이 설명
- 소표본과 합성 데이터의 한계를 최종 결과와 함께 보고
- 공개된 교육용 결과를 실제 서비스의 블라인드 성능으로 해석하지 않음
