### 1교시 · 선형회귀 원리와 첫 학습

#### 문제 정의와 데이터 준비

##### 같은 요청으로 두 가지 질문을 만든다 (PDF p.7)

- 회귀 정답은 연속 수치 `elapsed_ms`, 분류 정답은 성공 0·실패 1의 `failed`.
- 두 문제에 실행 전 확인 가능한 같은 입력 4개 열 사용.
- 수업의 사전 주 지표는 회귀 RMSE와 실패 클래스 F1.
- 실행 후 알게 되는 `elapsed_ms`를 실행 전 예측의 입력에 넣는 경우 누수 발생.

##### 공통 데이터 · Day 5의 100건을 그대로 사용 (PDF p.8)

- Day 5의 결측을 포함한 합성 요청 100건 재사용.
- 수치형 입력은 `input_chars`·`allowed_tools`, 범주형 입력은 `task_type`·`priority`.
- 식별자 또는 실행 후 정보인 `request_id`·`status`·`retry_count`는 학습 입력에서 제외.
- 작은 원리 예제와 프로젝트 합성 자료를 구분하고 실서비스 성능 근거로 일반화 금지.

##### 전날의 분할 ID를 두 문제에 함께 적용 (PDF p.9)

- 기존 입력의 인덱스로 회귀 정답을 선택해 입력과 정답의 행 순서 일치.
- 공통 분할은 train 60건·valid 20건·test 20건.

### 2교시 · 회귀 지표와 오류 해석

#### 평가 절차와 회귀 지표

##### 회귀 평가 · 학습과 검증의 역할을 분리 (PDF p.15)

- train은 전처리와 모델 계수 학습에 사용.
- valid는 학습된 규칙에 따른 예측과 후보별 오차 비교에 사용.
- test는 후보 선택에서 제외하고 최종 평가까지 보관.
- 동일 valid에서 기준선 대비 개선 여부 확인.

##### 회귀 지표 · 크기·단위·비교 기준을 함께 읽기 (PDF p.16)

- MAE는 절대오차 평균이며 정답과 같은 단위 사용.
- MSE는 제곱오차 평균으로 큰 오차에 큰 벌점 부여하며 단위도 제곱.
- RMSE는 MSE의 제곱근으로 정답 단위 유지와 큰 오차 민감성 보유.
- R²는 최대 1이고 음수도 가능하며 정확도나 오류 비율로 해석 금지.

##### 작은 배열로 MAE·RMSE·R² 확인 (PDF p.17)

- 실제값과 예측값의 행 순서를 맞춘 뒤 지표 계산.
- 작은 배열 예제로 MAE·RMSE·R²의 서로 다른 계산 결과 확인.
- MAE·RMSE의 단위와 R²의 상대적 비교 기준 구분.

#### 지표 선택과 기준선 해석

##### 지표가 달라지면 선택도 달라질 수 있다 (PDF p.18)

- 일부 큰 오차가 있는 후보와 일정한 오차가 있는 후보 비교.
- MAE가 낮은 후보와 RMSE가 낮은 후보가 달라질 수 있는 구조 확인.
- 큰 실패를 피하는 비용 등 업무 목적에 따라 주 지표 사전 결정.

##### R²가 음수라는 말의 정확한 뜻 (PDF p.19)

- R²의 기준은 평가 대상 정답의 평균을 항상 예측하는 경우.
- 그 기준보다 잔차 제곱합이 크면 R²가 음수인 결과 가능.
- train 평균을 학습하는 `DummyRegressor`의 valid R²는 반드시 0인 값이 아님.
- 상수 정답·극소 표본의 특수 동작 구분과 valid 평균을 미리 안다고 가정하는 학습 금지.

#### 공통 데이터 평가와 잔차 분석

##### 공통 자료 · 전처리 + 선형회귀로 20건 예측 (PDF p.20)

##### 평균 점수 뒤에 숨은 큰 오류를 본다 (PDF p.21)

- 잔차 양수는 실제 소요시간이 예측보다 긴 경우, 음수는 예측이 실제보다 긴 경우.
- 평균 지표와 함께 큰 오류 사례의 입력·단위·누수 여부 확인.
- 큰 오차만을 이유로 검증 사례를 임의 삭제하지 않는 분석 원칙.

### 3교시 · 로지스틱회귀와 분류 오류

#### 분류 원리와 학습 목표

##### 로지스틱회귀 · 이름에 회귀가 있어도 분류 모델 (PDF p.24)

- 이름에 회귀가 포함되어도 로지스틱회귀의 목적은 분류.
- 선형 점수를 실패 클래스 1의 확률로 변환한 뒤 판단 규칙 적용.
- 확률과 최종 클래스 구분 및 과도한 계수를 억제하는 규제의 존재 확인.

##### 선형 점수 z → 시그모이드 → 클래스 판단 (PDF p.25)

- 선형 점수 z에 시그모이드를 적용해 0~1 범위의 확률 계산.
- z=0일 때 확률 0.5이며 z 증가에 따라 실패 확률 증가.
- 추정 확률은 정답 보장 비율과 구분하며 확률의 적절성은 별도 검증 대상.

##### 점수·확률·판단 규칙을 직접 계산 (PDF p.26)

- `np.exp`로 시그모이드 계산 후 점수와 확률 관계 확인.
- 직접 정한 `p >= 0.5` 규칙을 정수 클래스로 변환.
- 확률 변환과 임계값에 의한 판단을 독립된 단계로 구분.

##### 학습할 때 줄이는 손실과 평가 지표는 다르다 (PDF p.27)

- 로지스틱회귀는 정답 클래스에 낮은 확률을 주는 경우 커지는 로그 손실과 규제를 고려해 학습.
- valid F1은 후보 선택용 지표이며 학습이 직접 최적화하는 목표와 구분.
- Precision·Recall·FP·FN 동시 보고.
- `max_iter`는 최적화 반복 상한으로 일반화 성능 보장과 무관.

#### 확률 예측과 분류 평가

##### predict_proba와 predict를 구분한다 (PDF p.28)

- `predict_proba`는 클래스별 확률, `predict`는 최종 클래스 반환.
- `classes_`에서 실패 클래스 1의 위치 확인 후 확률 열 선택.
- `C`는 규제 강도의 역수, `max_iter`는 최적화 반복 상한.

##### 혼동행렬 (PDF p.29)

- 혼동행렬은 실제 정답과 분류 결과의 조합을 TP·FP·FN·TN으로 구분한 표.
- 이 페이지 그림은 행이 분류 결과, 열이 실제 정답인 배치.
- 다음 페이지와 축 방향이 다르므로 위치 암기 대신 축 이름과 양성 정의를 기준으로 판독.

##### 오류 두 종류를 분리해서 읽는다 (PDF p.30)

- 이 페이지는 행이 실제값, 열이 예측값이며 성공 0·실패 1로 고정.
- FP는 성공을 실패로 예측해 불필요한 점검·재처리 발생.
- FN은 실패를 성공으로 예측해 문제를 놓치는 오류.
- valid 20건 중 실제 실패 6건이라는 분모와 오류 수 함께 해석.

##### 분류 지표 · 분모가 서로 다르다 (PDF p.31)

- Accuracy는 전체 사례 중 맞춘 비율.
- Precision은 실패로 예측한 사례 중 실제 실패의 비율.
- Recall은 실제 실패 중 찾아낸 실패의 비율.
- F1은 Precision과 Recall을 결합한 지표이며 TN을 사용하지 않으므로 오류 비용 설명 병행.

##### 혼동행렬과 분류 지표를 코드로 확인 (PDF p.32)

- 동일 valid 예측으로 혼동행렬과 Accuracy·F1 계산.

- `f1_score`의 기본 양성 클래스 1이 수업의 실패 정의와 일치하는지 확인.

### 4교시 · KNN 분류와 회귀

#### 이웃 탐색과 분류

##### KNN · 가까운 학습 사례를 참고해 예측 (PDF p.36)

- 입력과 학습 자료 사이 거리 계산 후 가장 가까운 K개 이웃 선택.
- 분류는 이웃 클래스 투표, 회귀는 이웃 정답 평균 사용.
- `fit`에서 학습 자료를 기억하고 `predict`에서 이웃 탐색.
- 입력 단위·특성 선택·거리 척도에 따라 이웃 변화.

##### 새 값 3.2에서 가까운 세 이웃을 찾는다 (PDF p.37)

- 1차원 새 입력 3.2와 학습 입력 간 거리로 가까운 세 이웃 탐색.
- 선택한 이웃의 라벨을 이용한 균일 투표로 분류 과정 확인.
- 정답 y를 거리 계산 입력에 포함하지 않는 원칙.

##### kneighbors로 선택된 이웃을 확인 (PDF p.38)

- `n_neighbors`로 이웃 수 설정.
- `kneighbors`가 반환하는 거리와 학습 행 인덱스로 선택된 입력 확인.
- 이웃 목록·거리·모델 예측을 직접 계산한 결과와 대조.

#### 회귀 예측과 주요 설정

##### KNN 회귀 · 투표 대신 숫자를 평균 (PDF p.39)

- KNN 회귀는 이웃 라벨의 다수결 대신 수치 정답 평균 계산.
- `weights=distance`는 가까운 이웃에 더 큰 가중치 부여.
- 예측 단위는 회귀 정답의 단위이며 균일 평균과 거리 가중 평균 결과 비교.

##### KNN의 주요 설정과 실무상 한계 (PDF p.40)

- K는 train 행 수 이하인 값으로 설정.
- `uniform`·`distance` 가중치 중 거리 가중의 성능 우위는 보장되지 않음.
- 기본 Minkowski 거리에서 p=2는 유클리드, p=1은 맨해튼 거리.
- 자료 증가에 따른 저장 메모리·예측 비용과 불필요한 특성의 거리 기여 확인.

#### 외삽 비교

##### 관측 범위 밖에서 두 모델은 다르게 움직인다 (PDF p.41)

- 선형회귀는 학습한 직선을 관측 범위 밖까지 연장.
- KNN 회귀는 가까운 학습 정답의 평균으로 예측해 범위 밖에서 다른 동작.
- 두 방식 모두 관측 범위 밖 정답을 보장하지 않는 외삽 한계.

### 5교시 · 스케일링과 열별 전처리

#### 스케일과 전처리 용어

##### 스케일이 다르면 “가깝다”의 뜻도 달라진다 (PDF p.44)

- 큰 단위 특성의 차이가 거리 계산을 지배할 수 있는 문제.
- 같은 새 요청도 원 단위와 train 기준 표준화 후의 최근접 이웃이 달라지는 예시.

##### 같은 데이터라도 단위 변환이 이웃을 바꾼다 (PDF p.45)

- K=1을 고정하고 원 단위와 표준화 후 예측 비교.
- `StandardScaler.fit`에서 train 평균·표준편차 저장 후 새 입력에 같은 변환 적용.
- 단위 변환만으로 선택 이웃과 클래스가 바뀌는 원리 확인.

##### 정규화라는 말을 네 가지 의미로 섞지 않는다 (PDF p.46)

- 표준화는 특성별 평균과 표준편차를 이용한 변환이며 정규분포 생성과 구분.
- Min-Max 스케일링은 train 특성별 최솟값·최댓값 기준 범위 변환.
- 벡터 정규화는 행 벡터의 길이를 조정하는 연산.
- 규제는 큰 계수 등에 벌점을 부여하는 학습 제어이며 스케일링과 구분.

##### 표준화·Min-Max · 새 값의 범위 확인 (PDF p.47)

- StandardScaler와 MinMaxScaler를 train에서 학습한 뒤 변환 결과 비교.
- Min-Max 기본 0~1 범위는 train 범위 기준이며 새 입력은 범위 밖 값 가능.
- 새 입력 500이 예제의 Min-Max 변환 후 2.0이 되는 결과 확인.

#### 열별 처리와 Pipeline

##### 수치형과 범주형은 각자의 경로로 처리 (PDF p.48)

- 수치형 2열은 중앙값 대체 후 스케일링.
- 범주형 2열은 최빈값 대체 후 원핫 인코딩.
- ColumnTransformer로 합친 8개 특성을 회귀·분류 모델에 연결.
- Pipeline 사용 여부와 무관하게 valid·test로 fit하는 경우 누수 발생.

##### ColumnTransformer · 전날의 구조를 유지 (PDF p.49)

- 수치·범주별 Pipeline을 ColumnTransformer의 해당 열에 연결.
- train에는 `fit_transform`, valid에는 `transform` 적용.
- 자료의 변환 shape는 train (60, 8)·valid (20, 8).
- `handle_unknown=ignore`의 미지 범주는 해당 원핫 블록을 0으로 처리하고 작은 교육용 배열은 밀집 형태 사용.

##### model.fit과 predict 내부에서 일어나는 일 (PDF p.50)

- fit 단계는 전처리 학습·변환 후 모델 학습 순서.
- predict 단계는 저장된 전처리로 변환 후 모델 예측 순서.
- 검증 예측 전후 중앙값·범주 수와 특성 구조 불변 확인.
- 후보마다 전처리·모델 객체를 새로 생성해 다른 실험의 학습 상태 덮어쓰기 방지.

#### 스케일러 비교와 결과 해석

##### 스케일러만 바꾸어 공정하게 비교 (PDF p.51)

##### 스케일링의 목적과 실험 결과를 구분한다 (PDF p.52)

- 다음 교시 K 실험은 표준화를 고정한 제한된 탐색이며 전체 조합 최적값과 구분.

### 6교시 · 하이퍼파라미터 비교와 선택

#### 파라미터 구분과 실험 설계

##### K=1의 완벽한 train 점수가 답은 아니다 (PDF p.58)

- 실제 점수 곡선은 매끄럽거나 단조롭지 않을 수 있으며 K=3 선택은 고정 실험 범위 내 판단.

##### 회귀 · K는 목표에 맞춰 다시 비교한다 (PDF p.59)

- 회귀 후보 내 잠정 선택은 K=15이며 분류에서 선택한 K를 그대로 복사하지 않음.

- 기본필수는 표준화 고정 K별 분류 F1 표와 선택 근거 작성.

#### 프로젝트 통합 실습

##### 실습 07 · 회귀·분류 비교 프로젝트 통합 (PDF p.74)

- 기본필수는 Day 5 원본·분할 ID 재사용과 회귀·분류 각 3후보 비교표 및 valid 예측 저장.
- 응용은 모듈 분리·K 탐색표·Pipeline 저장과 복원·짝의 README 기반 재현.
- 심화는 미지 범주·필수 열 누락·과도한 K·통계 불변 중 두 가지 이상 자동 검사.
- 완료 기준은 실행 가능한 초안·두 비교표·valid 예측·test 미사용 기록.
- 현재 배포 기본필수는 한 파일에서 문제별 두 후보의 비교표 생성이며 함수·클래스·모듈·고급 테스트 작성 과제는 없음.

**핵심:** 문제별 비교표와 잠정 선택 근거를 남기고, 전처리부터 저장·복원까지 재현 가능한 프로젝트로 연결.

##### 보고서 · 다섯 문장으로 선택을 설명한다 (PDF p.76)

- 다섯 문장은 목표·공통 조건·잠정 선택·구체적 한계·후속 검증 계획으로 구성.

#### 검증 시나리오와 평가 기준

##### 정상·경계·실패 입력으로 확인한다 (PDF p.77)

- 정상 valid 20건에 대한 예측 개수와 ID·실제값 순서 일치 확인.
- 결측·새 범주는 학습된 규칙으로 8개 특성을 유지하고 NaN·inf·통계 점검.
- 필수 열 누락은 임의 값을 생성하지 않고 명확한 오류로 처리.
- K는 1~60 범위 사전 검사, 저장 모델은 동일 환경의 복원 예측 대조.
- 예외 미발생만으로 통과 처리하지 않고 기대 출력·단위·행 수·정책을 기준으로 판정.

##### 형성평가 · 비교 구조와 설명을 평가한다 (PDF p.78)

- 데이터·누수 방지 20점, 모델 구현 25점, 지표·비교표 25점.
- 선택 근거·한계 20점, 재현·협업 기록 10점.
- 기본필수만으로 100점 기준 충족 가능하며 과목 최종 실습평가는 10/28 예정.

#### 최종 시연과 이해 확인

##### 실습 08 · 최종 검증·시연·지표 선택 근거 (PDF p.79)

- 기본필수는 한 번의 실행으로 두 비교표·예측 결과 재생성과 선택 이유·오류·test 보관 설명.
- 응용은 짝의 재현 및 저장 모델 예측 대조와 회귀·분류 선택 기준 차이 발표.
- 심화는 정상·경계·실패 테스트 시연과 다음 모델 비교에도 유지할 평가 정책 정리.
- 완료 기준은 코드·두 비교표·예측 및 탐색 기록·보고서·Git 이력.
- 현재 배포 기본필수는 07번 재실행과 네 문장 설명이며 저장·복원·K 탐색·복잡한 테스트·Git 숙련도를 공통 100점 필수 요건으로 추가하지 않음.

##### 마무리 3분 확인 퀴즈 (PDF p.80)

- 문제별 지표 분리와 최고 valid 점수의 해석 한계 확인.
- 다음 모델 비교에도 원본·입력 계약·분할 ID·선택 지표·test 보관 정책 유지 확인.

**핵심:** 동일 결과의 재생성과 정상·경계·실패 검증을 바탕으로 선택 이유와 남은 한계를 설명.
