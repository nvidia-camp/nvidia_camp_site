# Day30 프로젝트 자료

Day25의 탭 도입, 두 모드 색상, 머리말 정렬, 현재 절 표시, 모바일 코드 칸, 진행 패널을 Day30 명세서 v1.1과 Basic 완주 안내 v2에 적용했습니다. 명세서의 요구사항 검색은 요구사항 장에 두고, 코드는 공통 복사 아이콘에 연결합니다. 표와 SVG의 스크롤은 각각의 컨테이너에 제한합니다.

완주 안내의 27개 체크는 강사 원본의 체크 키와 로컬 저장 방식으로 유지합니다. 진행 패널은 1100px부터 본문 옆에 보이며, 좁은 화면에서는 진행 버튼으로 엽니다.

`uv run --no-project make_pages.py`로 강사 원본과 이 폴더의 CSS·JS에서 두 `index.html` 파일을 재생성할 수 있습니다.

오전 강의는 원본 HTML을 lecture/에 두고, 홈과 두 프로젝트 문서에서 별도 링크로 연결합니다.

## 2026-11-27 머리말 원상 복구 (원본을 사이트 틀에 맞게 조금 튜닝)

방향: 강사님 원본의 모양과 요소 배치는 그대로 두고, 사이트 틀(위쪽 메뉴·번호 탭·고정 목차·라이트/다크·복사 아이콘·진행 패널)만 입힌다.

- 명세서: 원본 상단 줄(브랜드·날짜·바로가기·인쇄/PDF)과 칩·바로가기 버튼을 본문 위에서 남색 머리말 안 원래 순서로 되돌림. 원본의 어두운 머리말 색(`heading.css`)을 두 모드 모두에 씀. 제목 강조(em) 청록색 복구.
- 완주 안내: 칩 6개를 머리말 안으로 되돌리고, 부제 두 줄(원본 줄바꿈) 유지.
- 탭: Day25처럼 번호(1·2)와 "오전 강의 자료 →".
- 높이: 721px 이상에서 두 탭 머리말 높이를 명세서 기준으로 같게(1219px~ 358px, 721~1218px 396px), 짧은 쪽은 세로 가운데. 720px 이하는 맞추지 않고 칩·상단 줄·버튼을 한 줄 가로 스크롤로 둠.
- 글자 비교: 원본 대비 빠진 글자는 원래 왼쪽 목차 상자의 제목 "CONTENTS · 총 13절" 하나(가로 목차 띠로 바뀌며 빠짐, 이전과 같음).
