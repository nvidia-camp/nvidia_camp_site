나머지 실습은 이렇게 처리합니다.

- 실습 06 (파일 역할): 단계를 두지 않습니다. 0-3에서 세 곳(주소 연결·입력 검사·저장)을 소개하고, 매 단계 설명에서 해당 줄을 짚습니다.
- 웹 기초: 1~11단계는 그대로 두고, 강의 PDF에 있는 웹 기초를 0-1~0-4 네 장으로 앞에 둡니다. 네 장은 한 화면에 세로로 이어 봅니다. REST라는 말은 강의에 없지만 p.58의 다섯 요청이 REST 방식이라 그 표로 설명합니다.
- 이름 기준: 교시 묶음에 Method(GET·POST·PUT·DELETE)를 붙이고, 단계 이름은 모두 그 단계의 개념으로 짓습니다. 11단계 상태코드 정리에 2xx·4xx·5xx 읽는 법 한 줄을 더합니다.
- 실습 07 (통합): 11단계의 전체 코드가 곧 07 완성본입니다.
- 실습 08 (일일 프로젝트): 뺍니다. 새로 배우는 내용이 없는 과제이고, 핵심인 "재시작해도 남는다"는 11단계에서 보여 줍니다.

## 코드 규칙

실습 코드에서 바꾸는 곳과 이유입니다.

| 실습 코드 | 페이지 코드 | 이유 |
|---|---|---|
| `with LOCK:` 블록 | 뺌 | 실습 README가 "잠금은 제공 코드, 오늘 과제 아님"이라고 적고 있습니다 |
| `storage.py`의 임시 파일 저장 | 짧은 `storage.py`, 페이지에는 `read_data()`, `write_data()` 이름만 보임 | 같은 이유. 파일 처리 속은 오늘 배우는 내용이 아닙니다 |
| `KnowledgeWrite` + `Knowledge(id)` 두 모델, `response_model=` | 모델 하나 `Knowledge` | 공식 문서 Request Body의 `class Item(BaseModel)` 모양. 응답은 저장한 dict 그대로라 결과가 같습니다 |
| `same_id = ...` 변수 후 `if same_id:` | `if entry["id"] == knowledge_id:` | 비교를 바로 씁니다 |
| GET·PUT·DELETE마다 찾기 반복문 + 404 | `find_entry()` 한 곳 | 공식 문서 Handling Errors처럼 "못 찾으면 `raise`"를 한 번만 씁니다 |
| PUT: 위치 `i`를 찾아 `entries[i] = updated` | 찾은 dict에 `entry.update(...)` | 위치를 몰라도 되고, 보낸 값에 id가 없어서 ID가 그대로 남습니다 |
| DELETE: `pop(i)` + `return Response(status_code=204)` | `remove(entry)`, `return` 없음 | `status_code=204`만으로 본문 없는 204가 나갑니다 (실측) |
| category 필터 | 뺌 | 응용 범위입니다. 기본필수만 다룹니다 |

함수는 공식 문서 예제의 `async def`가 아니라 `def`를 씁니다. 공식 문서(Concurrency and async/await)도 `await`를 쓰지 않는 코드는 `def`로 쓰라고 안내합니다. 실습 코드와도 같습니다.

## 페이지 코드 (전체)

`code/main.py`와 같습니다. 실제 서버와 브라우저로 실습 확인 1~9와 재시작을 기록했고, `build.py`가 기록과 기대값을 대조합니다 (FastAPI 0.162).

```python
# main.py — 지식 관리 API
# 실행: python -m uvicorn main:app --reload
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from storage import read_data, write_data

app = FastAPI()


@app.get("/health")
def health():
    return {"status": "ok"}


@app.get("/api/knowledge")
def list_knowledge():
    return read_data()["entries"]


def find_entry(data, knowledge_id):
    for entry in data["entries"]:
        if entry["id"] == knowledge_id:
            return entry
    raise HTTPException(status_code=404, detail="Knowledge not found")


@app.get("/api/knowledge/{knowledge_id}")
def get_knowledge(knowledge_id: int):
    return find_entry(read_data(), knowledge_id)


class Knowledge(BaseModel):
    title: str = Field(min_length=1, max_length=80)
    content: str = Field(min_length=1, max_length=2000)
    category: str = Field(min_length=1, max_length=30)


@app.post("/api/knowledge", status_code=201)
def create_knowledge(knowledge: Knowledge):
    data = read_data()
    entry = {"id": data["next_id"], **knowledge.model_dump()}
    data["entries"].append(entry)
    data["next_id"] += 1
    write_data(data)
    return entry


@app.put("/api/knowledge/{knowledge_id}")
def update_knowledge(knowledge_id: int, knowledge: Knowledge):
    data = read_data()
    entry = find_entry(data, knowledge_id)
    entry.update(knowledge.model_dump())
    write_data(data)
    return entry


@app.delete("/api/knowledge/{knowledge_id}", status_code=204)
def delete_knowledge(knowledge_id: int):
    data = read_data()
    data["entries"].remove(find_entry(data, knowledge_id))
    write_data(data)
```
