경로 설정 (PATH)

프로그램을 설치했는데 "명령을 찾을 수 없다"고 나오면 PATH에 그 프로그램의 폴더가 없는 것입니다. 폴더를 찾아 PATH에 추가하는 순서입니다. 예시는 Tesseract입니다.

PATH

tesseract처럼 이름만 입력한 명령을 Windows가 찾아보는 폴더 목록입니다.

순서
  1. 명령이 잡히는지 확인
  2. 넣을 폴더 찾기
  3. PATH에 추가
  4. 새 창에서 확인
먼저 해 볼 것

설치 직후라면 PowerShell 창을 닫고 새로 엽니다. 열려 있던 창은 예전 PATH를 씁니다.

1 확인2 폴더 찾기3 PATH에 추가4 다시 확인참고 · 경로 읽기막히면
1

명령이 잡히는지 확인

PowerShell
tesseract --version
Get-Command tesseract | Select-Object -ExpandProperty Source
결과뜻
C:\Program Files\Tesseract-OCR\tesseract.exe처럼 경로가 나옴이미 PATH에 있습니다. 더 할 일이 없습니다.
"…인식되지 않습니다" 오류PATH에 없습니다. 2로 갑니다.

다른 프로그램도 같습니다. 0000 --version으로 확인하는 프로그램이면 tesseract 자리에 0000을 넣습니다.

2

PATH에 넣을 폴더 찾기

PATH에는 실행 파일이 아니라 그 파일이 들어 있는 폴더를 넣습니다.

실행 파일C:\Program Files\Tesseract-OCR\tesseract.exe
PATH에 넣을 값C:\Program Files\Tesseract-OCR (파일명 tesseract.exe를 뺀 폴더)

실행 파일이 어디 있는지 모르면 설치 폴더에서 찾습니다.

PowerShell
Get-ChildItem "C:\Program Files", "$env:LOCALAPPDATA\Programs" -Recurse -Filter tesseract.exe -ErrorAction SilentlyContinue | Select-Object -ExpandProperty DirectoryName

출력된 폴더 경로를 복사해 둡니다. 탐색기에서 설치 폴더를 열고 주소 표시줄을 눌러 복사해도 됩니다.

3

PATH에 추가

  1. Win 키 → 환경 변수 입력 → 계정의 환경 변수 편집을 엽니다.
  2. 위쪽 사용자 변수 목록에서 Path를 선택하고 편집을 누릅니다.
  3. 새로 만들기를 누르고 2에서 찾은 폴더의 절대 경로를 붙여 넣습니다.
  4. 확인을 두 번 눌러 닫습니다.

기존 항목은 지우지 않습니다. Path에 든 다른 폴더를 지우면 잘 되던 명령이 실행되지 않습니다. 추가만 합니다.

명령으로 지금 창에서만 잠깐 추가하기
PowerShell
$env:Path += ";C:\Program Files\Tesseract-OCR"

창을 닫으면 사라집니다. 맞는 폴더인지 시험해 볼 때 씁니다.

4

새 창에서 확인

PowerShell 창을 닫고 새로 연 뒤 1의 명령을 다시 실행합니다. VS Code 터미널을 쓴다면 VS Code를 다시 시작합니다.

새 PowerShell
tesseract --version
$env:Path -split ';'     # PATH에 든 폴더를 한 줄씩. 방금 넣은 폴더가 보이는지 확인

참고 · 경로 읽기

표기뜻
C:\workspace\app\main.py절대 경로. 드라이브부터 전부 적은 위치. 어디서 실행해도 같은 파일
app\main.py상대 경로. 지금 있는 폴더를 기준으로 한 위치
. · ..지금 폴더 · 한 단계 위 폴더
$HOME내 사용자 폴더 (C:\Users\내이름)
"C:\Program Files\…"공백이 있는 경로를 명령에 쓸 때는 따옴표로 감쌉니다
PowerShell
pwd                      # 지금 있는 폴더
ls                       # 이 폴더의 파일 목록
cd C:\workspace\app      # 폴더 이동
cd ..                    # 한 단계 위로
