Python 가상환경

Python 패키지를 용도별로 따로 설치해 두는 폴더입니다. 수업에서는 gpuenv와 backendenv 두 개를 실습 저장소 바깥에 만들거나, 둘을 합친 통합 환경 .venv 하나를 만듭니다. 패키지는 설치 목록 파일(requirements-….txt)로 한 번에 설치합니다.

C:\workspace\
├─ envs\                          ← 가상환경과 설치 목록을 모아 두는 폴더
│  ├─ requirements-gpu.txt        ← 설치 목록 (이 페이지에서 받음)
│  ├─ requirements-backend.txt
│  ├─ gpuenv\                     ← GPU 실습용 가상환경
│  └─ backendenv\                 ← 서버와 DB 실습용 가상환경
└─ practice_assignment\           ← 실습 저장소
   └─ .venv\                      ← (선택) 통합 환경. 위 둘을 하나로 합친 것
환경쓰는 실습주요 패키지
gpuenvPython 기초 · ML · DL · Vision · LLM과 Transformer(11/13)PyTorch(CUDA) · NumPy · pandas · scikit-learn · OpenCV · ultralytics · transformers
backendenvREST API(11/10) · API와 DB 연동(11/12) · Prompt · Context Engineering(11/16)FastAPI · SQLAlchemy · psycopg · alembic · pytest
.venv (통합)위 실습 전부. 환경을 바꾸지 않고 하나로 씁니다gpuenv + backendenv 전부, 같은 버전

둘 중 한 가지 방식만 하면 됩니다. 나눠 쓰려면 2 → 5를, 하나로 쓰려면 1을 한 뒤 6 통합 환경으로 갑니다. SQL 실습(11/11)은 Python을 쓰지 않으므로 가상환경이 필요 없습니다.

CUDA Toolkit은 따로 설치하지 않습니다. PyTorch를 설치할 때 함께 들어옵니다. Python을 설치할 때는 설치 화면의 py launcher 항목을 켜 둡니다.

PowerShell · Python 확인
py --list          # 설치된 Python 버전 목록
py -3.13 --version # Python 3.13.x

py는 Windows용 Python에 함께 설치되는 실행기입니다. 버전을 골라 실행할 수 있어서 py -3.13으로 시작합니다.

2

설치 목록 받기

설치할 패키지와 버전이 적힌 파일입니다. 폴더를 먼저 만들고, 파일을 그 폴더에 저장합니다.

PowerShell · 폴더 만들기
mkdir C:\workspace\envs -Force

아래 버튼으로 받은 뒤, 다운로드 폴더에 있는 파일을 C:\workspace\envs로 옮깁니다.

requirements-gpu.txt 내려받기 requirements-backend.txt 내려받기

명령으로 바로 받기
PowerShell
cd C:\workspace\envs
Invoke-WebRequest https://nvidiasesac.vercel.app/setup/python-venv/requirements-gpu.txt -OutFile requirements-gpu.txt
Invoke-WebRequest https://nvidiasesac.vercel.app/setup/python-venv/requirements-backend.txt -OutFile requirements-backend.txt
확인
ls C:\workspace\envs     # requirements-gpu.txt, requirements-backend.txt가 보여야 함

파일 이름이 requirements-gpu (1).txt나 requirements-gpu.txt.txt로 저장됐으면 이름을 고칩니다. 아래 명령은 파일 이름과 위치가 정확해야 실행됩니다.

3

가상환경을 만들고 패키지 설치

환경마다 두 줄입니다. 첫 줄이 가상환경을 만들고, 둘째 줄이 그 환경에 목록대로 설치합니다. 어느 폴더에서 실행해도 됩니다.

PowerShell · gpuenv
py -3.13 -m venv C:\workspace\envs\gpuenv
C:\workspace\envs\gpuenv\Scripts\python.exe -m pip install -r C:\workspace\envs\requirements-gpu.txt
PowerShell · backendenv
py -3.13 -m venv C:\workspace\envs\backendenv
C:\workspace\envs\backendenv\Scripts\python.exe -m pip install -r C:\workspace\envs\requirements-backend.txt
명령의 부분뜻
py -3.13 -m venv 경로Python 3.13으로 그 경로에 가상환경 폴더를 만듭니다.
…\gpuenv\Scripts\python.exe -m pip그 가상환경 안의 Python으로 pip를 실행합니다. 환경을 켜지 않아도 정확히 그 환경에 설치됩니다.
install -r 파일파일에 적힌 패키지를 적힌 버전대로 모두 설치합니다.

gpuenv는 내려받는 양이 많습니다. PyTorch(CUDA)만 수 GB라서 네트워크에 따라 10분 넘게 걸립니다. 마지막 줄에 Successfully installed …가 나올 때까지 창을 닫지 않습니다.

NVIDIA GPU가 없는 PC는 requirements-gpu.txt를 메모장으로 열어 cu128 세 곳을 cpu로 바꾼 뒤 설치합니다.

4

켜기 · 설치 확인

실습을 실행하기 전에 그 실습의 환경을 켭니다. PowerShell 창을 새로 열 때마다 다시 켜야 합니다.

PowerShell · gpuenv 켜고 확인
C:\workspace\envs\gpuenv\Scripts\Activate.ps1
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"   # 2.10.0+cu128 True
PowerShell · backendenv 켜고 확인
C:\workspace\envs\backendenv\Scripts\Activate.ps1
python -c "import fastapi, sqlalchemy; print(fastapi.__version__, sqlalchemy.__version__)"   # 0.128.2 2.1.8

줄 맨 앞에 (gpuenv)나 (backendenv)가 붙으면 켜진 것입니다. 다른 환경으로 바꿀 때는 바꿀 환경의 Activate.ps1을 실행하고, 끌 때는 deactivate를 입력합니다.

"이 시스템에서 스크립트를 실행할 수 없으므로" 오류가 나면 아래 명령을 한 번 실행한 뒤 다시 켭니다. 내 계정에만 적용됩니다.

PowerShell · 한 번만
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

torch.cuda.is_available()이 False면 NVIDIA 그래픽 드라이버를 먼저 확인합니다. CUDA Toolkit은 따로 설치하지 않아도 됩니다.

5

VS Code에 연결

가상환경이 저장소 바깥에 있으면 VS Code가 자동으로 찾지 못합니다. 경로를 한 번 직접 알려 줍니다.

  1. VS Code에서 실습 저장소 폴더를 엽니다 (파일 → 폴더 열기).
  2. Ctrl+Shift+P → Python: Select Interpreter를 고릅니다.
  3. Enter interpreter path…를 고르고 쓸 환경의 경로를 붙여 넣습니다.
인터프리터 경로 · 둘 중 쓸 환경 한 줄
C:\workspace\envs\gpuenv\Scripts\python.exe
C:\workspace\envs\backendenv\Scripts\python.exe

오른쪽 아래 상태 표시줄에 ('gpuenv')처럼 환경 이름이 보이면 연결된 것입니다. 한 번 넣은 경로는 목록에 남아서, 다음부터는 목록에서 골라 바꿉니다.

6

통합 환경 · 나누지 않고 하나로 쓰기

두 환경의 패키지를 한 환경에 모두 설치하는 방법입니다. 실습마다 환경을 바꾸지 않아도 됩니다. 실습 저장소 폴더 안에 .venv라는 이름으로 만들면 VS Code가 자동으로 찾습니다.

requirements-all.txt 내려받기

받은 파일을 C:\workspace\envs에 옮긴 뒤 실행합니다.

PowerShell
cd C:\workspace\practice_assignment
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r C:\workspace\envs\requirements-all.txt
.venv\Scripts\Activate.ps1
나눠 쓰기 (gpuenv · backendenv)통합 (.venv)
환경 바꾸기실습에 맞춰 바꿉니다바꾸지 않습니다
문제가 생겼을 때그 환경만 지우고 다시 만듭니다전체를 다시 설치합니다
패키지 버전같습니다. requirements-all.txt는 두 목록을 그대로 합친 파일입니다.

.venv 폴더는 git에 올리지 않습니다. 저장소의 .gitignore에 .venv/가 있는지 확인합니다.

7

환경 추가 · 갱신

상황방법
새 환경이 안내됨같은 순서입니다. 새 requirements-이름.txt를 C:\workspace\envs에 받고, 3의 두 줄에서 gpuenv와 파일 이름을 새 이름으로 바꿔 실행합니다.
설치 목록이 바뀜파일을 다시 받아 덮어쓰고, 3의 둘째 줄(pip install -r …)만 다시 실행합니다. 바뀐 패키지만 설치됩니다.
환경이 꼬임그 환경 폴더(예: C:\workspace\envs\gpuenv)를 지우고 3을 다시 합니다. 실습 코드에는 영향이 없습니다.
지금 설치된 것 보기환경을 켠 뒤 python -m pip list

실습 도중 패키지를 하나씩 따로 설치하지 않습니다. pip install 패키지로 직접 넣으면 버전이 목록과 달라져 다른 실습이 깨질 수 있습니다. 필요한 패키지는 설치 목록 파일에 추가된 것을 받아 설치합니다.
