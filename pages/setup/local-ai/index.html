AI 모델을 내 PC의 GPU에서 돌리고, 그 모델에게 코드를 읽고 고치게 하는 도구(OpenCode)를 연결합니다. 질문과 코드가 외부 서버로 나가지 않습니다.

직접 설치하기

하나씩 따라 하며 설치합니다. 명령은 Windows PowerShell(Win → PowerShell 입력)에 붙여 넣고 Enter를 누릅니다. 관리자로 열 필요는 없습니다.

Node.js 설치

OpenCode를 설치하는 도구(npm)가 Node.js 안에 들어 있습니다. npm은 따로 설치하지 않습니다. node -v에 v20 이상이 나오면 이미 있으니 건너뜁니다.

  1. nodejs.org/ko/download를 엽니다. 버전 옆에 LTS가 붙어 있는지 확인하고, 아래쪽 Windows 설치 프로그램 (.msi)을 누릅니다. 위쪽 fnm 명령은 추가 설정이 필요해서 쓰지 않습니다.
  2. 받은 파일(node-v26.x.x-x64.msi)을 실행하고 화면마다 아래처럼 합니다.

  1. PowerShell 창을 닫고 새로 연 뒤 확인합니다. 열려 있던 창은 설치된 것을 모릅니다.

2

Ollama 설치

Ollama는 AI 모델을 내 PC에서 실행해 주는 프로그램입니다. 로컬 AI의 중심입니다.

  1. ollama.com/download의 Windows 탭에 있는 설치 명령을 PowerShell에 붙여 넣습니다. 관리자 권한은 필요 없습니다.
PowerShell
irm https://ollama.com/install.ps1 | iex
  1. Install complete가 나오면 새 PowerShell 창에서 확인합니다. Ollama는 작업 표시줄 트레이에서 자동으로 실행됩니다.
새 PowerShell
ollama --version   # ollama version is 0.x.x

명령 대신 페이지의 Download manually로 OllamaSetup.exe를 받아 실행해도 됩니다. ollama만 입력하면 메뉴가 뜨는데, Esc로 닫으면 됩니다.

3

Ollama 설정 두 가지

3-1 대화 길이를 64k로

모델이 한 번에 기억하는 길이입니다. 기본값 4k로는 OpenCode가 동작하지 않습니다.

  1. 시작 메뉴에서 Ollama 앱을 엽니다. 첫 화면의 Apps 목록은 누르지 않습니다.
  2. 왼쪽 Settings → Context length 슬라이더를 64k로 옮깁니다.

64k보다 올리지 않습니다. 128k는 GPU 메모리를 넘어 느려집니다. 같은 화면의 Expose Ollama to the network는 꺼진 채로 둡니다.

3-2 모델을 1시간 동안 올려 두기

기본값은 5분 동안 쓰지 않으면 모델을 내립니다. 그러면 다시 물을 때마다 10초씩 기다려야 합니다.

PowerShell
setx OLLAMA_KEEP_ALIVE 1h   # 성공: 지정한 값을 저장했습니다.

3-3 Ollama 다시 시작

작업 표시줄 트레이의 Ollama 아이콘 오른쪽 클릭 → Quit Ollama → 시작 메뉴에서 Ollama를 다시 엽니다. 3-2 설정은 다시 시작해야 적용됩니다.

4

모델 받고 GPU로 도는지 확인

PowerShell
ollama pull gpt-oss:20b

한 번 물어보고, 모델이 어디서 돌고 있는지 봅니다.

PowerShell
ollama run gpt-oss:20b "안녕" --verbose
ollama ps
확인정상다르면
답한국어 답. Thinking...은 모델이 생각하는 과정
eval rate약 80 tokens/s40 미만이면 PROCESSOR 확인
PROCESSOR100% GPU게임·영상 등 GPU를 쓰는 프로그램 닫기
CONTEXT655364096이면 3-1 다시
UNTIL59 minutes from now 근처4 minutes면 3-3 다시

여기까지가 로컬 AI입니다. ollama run gpt-oss:20b로 터미널에서 바로 대화할 수 있습니다. 이제 이 모델에게 코드 작업을 시킬 도구를 붙입니다.

5

OpenCode 설치

OpenCode는 터미널에서 AI 모델에게 파일 읽기·수정·명령 실행을 시키는 도구입니다. Ollama를 자동으로 찾아 연결합니다.

PowerShell
npm install -g --allow-scripts=@opencode/cli @opencode/cli
opencode --version
"이 시스템에서 스크립트를 실행할 수 없으므로"Set-ExecutionPolicy -Scope CurrentUser RemoteSigned → Y → 다시 실행. 내 계정에만 적용됩니다.
opencode를 찾을 수 없음PowerShell 창을 새로 엽니다.
인터넷 글의 npm install -g opencode-ai옛 버전(v1)입니다. 설치하지 않습니다.
6

OpenCode 실행 → 로컬 모델 고르기 → 첫 작업

OpenCode는 실행한 폴더의 파일을 직접 고칩니다. 처음에는 빈 테스트 폴더에서 합니다.

PowerShell
mkdir $HOME\opencode-test -Force
cd $HOME\opencode-test
opencode

처음에는 입력창 아래에 클라우드 무료 모델 Iceman Free OpenCode가 선택되어 있습니다. 이대로 질문하면 외부 서버로 전송됩니다.

/models를 입력하고 gpt-oss:20b를 고릅니다.

입력창 아래가 gpt-oss:20b Ollama로 바뀌면 로컬 모델입니다. OpenCode를 새로 열 때마다 이 표시를 먼저 확인합니다.

입력창에 첫 작업을 넣습니다.

OpenCode 입력창
hello.py 파일을 만들고, "Hello, OpenCode!"를 출력하는 프로그램을 작성한 뒤 python으로 실행해서 결과를 보여줘

승인 창이 뜨면 내용을 읽고 허용합니다. 폴더에 hello.py가 생기고 화면에 Hello, OpenCode!가 보이면 설치가 끝난 것입니다.
