VS Code Extension

Extension은 VS Code에 기능을 더하는 프로그램입니다. 한국어 메뉴에서는 확장이라고 표시됩니다. 수업에서 안내한 Extension, Python 실습에 필요한 기본 Extension, 실습별로 있으면 편한 추천 Extension을 정리했습니다.

수업 안내 · Python 기본

수업에서 안내한 3개와 Python 실습에 필요한 3개입니다. 이 6개만 설치하면 됩니다.

추천 Extension

2개입니다. 없어도 실습은 됩니다. 필요할 때 설치합니다.

설치됐다는 표시

Extensions 화면에서 설치 버튼이 톱니바퀴 아이콘으로 바뀝니다.

1

설치 방법

  1. VS Code 왼쪽 막대에서 Extensions(확장) 아이콘을 누릅니다 (Ctrl+Shift+X).
  2. 검색 칸에 Extension 이름을 입력합니다.
  3. 이름과 게시자가 아래 캡처와 같은 항목에서 설치를 누릅니다.

왼쪽 막대에서 Extensions를 찾습니다.
캡처는 탐색기를 연 상태입니다. 왼쪽의 네모 네 개 모양 아이콘을 누르면 Extension 검색 화면으로 바뀝니다. 파란 숫자는 알림 배지이므로 PC마다 다를 수 있습니다. 아이콘이 안 보이면 Ctrl+Shift+X로 엽니다.

게시자를 꼭 확인합니다. 이름이 비슷한 Extension이 많습니다. 캡처의 게시자와 다르면 다른 Extension입니다.

명령으로 한 번에 설치하기
PowerShell · 수업 안내 3개 + Python 기본 3개
code --install-extension formulahendry.code-runner
code --install-extension ritwickdey.LiveServer
code --install-extension PKief.material-icon-theme
code --install-extension ms-python.python
code --install-extension ms-toolsai.jupyter
code --install-extension MS-CEINTL.vscode-language-pack-ko

code를 찾을 수 없다고 나오면 VS Code를 다시 시작하거나 경로 설정 (PATH)을 봅니다.

2

수업에서 안내한 Extension · 3개

Code Runner formulahendry.code-runner
열려 있는 코드 파일을 버튼 하나로 실행합니다. 오른쪽 위 ▷ 버튼이나 Ctrl+Alt+N.

Live Server ritwickdey.LiveServer
HTML 파일을 브라우저로 열고, 저장할 때마다 자동으로 새로 고칩니다. 오른쪽 아래 Go Live를 누릅니다.

Go Live
Live Server를 설치하면 맨 아래 상태 표시줄에 생기는 버튼입니다. 실습 폴더와 .html 파일을 연 뒤 누릅니다. 이 버튼은 HTML 미리보기용입니다.

Material Icon Theme PKief.material-icon-theme
탐색기의 파일과 폴더에 종류별 아이콘을 붙입니다. 설치 뒤 나오는 선택 창에서 Material Icon Theme를 고릅니다.

가상환경을 쓰는 실습은 Python Extension의 실행 버튼으로 실행합니다. Code Runner의 Run Code는 별도 실행 설정을 사용하므로, Python Extension에서 고른 가상환경과 다르게 실행될 수 있습니다. 명령 팔레트의 Python: Run Python File in Terminal을 사용하고, 실제 Python 경로를 확인합니다.

3

Python 기본 Extension · 3개

Python, Jupyter, Korean Language Pack 세 개를 설치합니다. Pylance와 Python Debugger는 Python Extension을 설치하면 함께 들어옵니다.

Python ms-python.python
Python 파일을 실행하고, 실습에 쓸 가상환경(인터프리터)을 고릅니다.

Pylance ms-python.vscode-pylance
자동 완성, 함수 설명, 오류 밑줄을 보여 줍니다. 따로 설치하지 않습니다.

Python Debugger ms-python.debugpy
중단점을 걸고 한 줄씩 실행합니다. 따로 설치하지 않습니다.

Jupyter ms-toolsai.jupyter
.ipynb 노트북을 VS Code에서 열고 실행합니다. DL · Vision 실습의 노트북에 필요합니다.

Korean Language Pack MS-CEINTL.vscode-language-pack-ko
메뉴를 한국어로 표시합니다. 설치 후 VS Code를 다시 시작합니다.

가상환경을 고르는 방법은 Python 가상환경 3단계에 있습니다.

4

추천 Extension · 필요할 때만

Error Lens usernamehw.errorlens
오류 내용을 그 줄 옆에 바로 표시합니다. 빨간 밑줄에 마우스를 올려 읽기가 번거로울 때 설치합니다.

Git Graph mhutchie.git-graph
커밋과 브랜치를 그림으로 표시합니다. 팀 프로젝트에서 브랜치를 나눠 쓸 때 설치합니다.

Extension은 적을수록 좋습니다. Extension이 많으면 VS Code가 느려지고, 기능이 겹쳐 서로 충돌합니다. 같은 일을 하는 Extension을 두 개 설치하지 않고, 쓰지 않는 Extension은 지웁니다.

실행 버튼(▷)이 보이지 않음Python Extension이 설치됐는지, 연 파일이 .py인지 확인합니다.
