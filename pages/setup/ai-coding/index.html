클라우드 도구 셋은 질문과 코드가 각 회사 서버로 전송되고 구독마다 5시간 한도와 주간 사용 한도가 있습니다. OpenCode + 로컬 모델은 한도가 없는 대신 모델이 작습니다.

어떤 도구든 지킬 5가지

  1. "완료했다"는 말을 믿지 말고 직접 확인합니다.파일이 바뀌었는지, 실행 결과가 맞는지 내 눈으로 봅니다. AI가 바꾼 코드는 diff를 읽고 설명할 수 있을 때 받아들입니다.
  2. 작업 전에 git 커밋으로 저장점을 만들어 둡니다.잘못되면 git으로 되돌립니다. 도구마다 되돌리기 명령이 있지만 git이 가장 확실합니다.
  3. 주제가 바뀌면 새 대화로 시작합니다.대화가 길어지면 앞의 지시를 잊고 한도도 빨리 줄어듭니다.
  4. 작게 시키고, 큰 일은 계획부터 봅니다.여러 파일을 고치는 일은 계획 모드에서 계획을 읽고 고친 뒤 진행합니다.
  5. 승인 창을 읽고 누릅니다.모두 자동 승인하는 옵션은 망가져도 되는 테스트 폴더에서만 씁니다.

안내문 파일 하나로 같이 쓰기

안내문은 대화를 시작할 때마다 AI가 먼저 읽는 프로젝트 설명입니다. 프로젝트 폴더에 AGENTS.md를 두면 OpenCode · Codex · agy가 읽고, Claude Code도 CLAUDE.md가 없으면 AGENTS.md를 읽습니다.

AGENTS.md 예시
# 프로젝트 안내
- Python 3.12, 실행: `uv run main.py`
- 답변과 주석은 한국어로
- 파일을 고친 뒤에는 반드시 실행해서 확인할 것
- 테스트 파일은 요청이 없으면 수정하지 않는다

짧게 쓰는 것이 좋습니다. 매 대화마다 읽기 때문에 그만큼 한도와 대화 길이를 차지합니다.
