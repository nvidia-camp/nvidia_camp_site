에이전트에게 알려 주기

전역 안내문 $HOME\.config\opencode\AGENTS.md에 설치한 도구만 한 줄씩 적습니다. Claude Code는 CLAUDE.md에 같은 내용을 적습니다.

AGENTS.md
# 사용할 수 있는 CLI
- 최신 라이브러리 문서: `npx ctx7 library <이름> "<질문>"` → `npx ctx7 docs <ID> "<질문>"`
- 파이썬: pip 대신 `uv` (`uv run`, `uv add`). 파일을 고친 뒤 `ruff check`
- GitHub: `gh` (출력은 `--json 필드 --limit N`으로 줄이기). CI 실패는 `gh run view --log-failed`
- 커밋 전: `gitleaks dir . -v`

에이전트는 내 계정 권한을 그대로 씁니다. 로그인된 gh로 저장소 삭제도 할 수 있습니다. 로컬 AI 코딩 설치 6-1의 설정이 gh repo delete를 막고 있습니다.
