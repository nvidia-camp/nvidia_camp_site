# CLI 도구

- 공통 기준: [사이트 디자인 원칙](../../../DESIGN.md).
- 기존 남색·연한 청색 색상 토큰, 글꼴, 카드·표·단계 번호를 재사용한다.
- 추천란은 작업 보조 도구와 서비스 CLI를 함께 소개한다. 각 행은 도구 → 쓰는 상황 → 에이전트에게 주는 도움 순서로 읽히고, 도구 이름은 공식 안내로 연결한다.
- 설치 명령을 나열하던 추천 표를 상황과 효과 중심의 두 표로 바꾼다. 기본 묶음에 있는 도구는 중복 설치하지 않도록 표시한다.
- 720px 이하에서는 기존 세로 표 패턴을 쓰고, 단계 제목은 줄바꿈을 허용한다. 카드 열은 `minmax(0, 1fr)`로 두어 200% 글자 확대에서도 본문 폭이 늘어나지 않게 한다.
- 외부 자산·의존성을 추가하지 않는다. HTML 다운로드에도 같은 내용이 포함된다.
