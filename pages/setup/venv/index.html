Python 가상환경 (venv)

프로젝트마다 Python 패키지를 따로 설치해 두는 폴더입니다. 수업 실습은 모두 프로젝트 폴더 안의 .venv에서 실행합니다.

왜 쓰나

프로젝트마다 필요한 패키지 버전이 다릅니다. 한곳에 모두 설치하면 서로 충돌하므로 프로젝트별로 나눕니다.

순서
  1. 만들기 (프로젝트마다 한 번)
  2. 켜기 (터미널을 열 때마다)
  3. 패키지 설치
켜졌다는 표시

PowerShell 줄 맨 앞에 (.venv)가 붙습니다.

1

설치된 Python 확인

PowerShell
py --list          # 설치된 Python 버전 목록
py -3.13 --version # Python 3.13.x

py는 Windows용 Python에 함께 설치되는 실행기입니다. 버전을 골라 실행할 수 있어서 수업에서는 py -3.13으로 시작합니다.

2

가상환경 만들기

프로젝트 폴더로 이동한 뒤 만듭니다. 폴더 안에 .venv가 생기면 된 것입니다.

PowerShell
cd C:\workspace\my-project
py -3.13 -m venv .venv

프로젝트마다 한 번만 합니다. 이름은 .venv로 통일하면 VS Code가 자동으로 찾습니다.

3

가상환경 켜기

PowerShell
.\.venv\Scripts\Activate.ps1

줄 맨 앞에 (.venv)가 붙으면 켜진 것입니다. PowerShell 창을 새로 열 때마다 다시 켜야 합니다.

확인
Get-Command python   # Source가 ...\my-project\.venv\Scripts\python.exe

"이 시스템에서 스크립트를 실행할 수 없으므로" 오류가 나면 아래 명령을 한 번 실행한 뒤 다시 켭니다. 내 계정에만 적용됩니다.

PowerShell · 한 번만
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
4

패키지 설치

(.venv)가 보이는 상태에서 설치합니다. 실습 폴더에 requirements.txt가 있으면 그 파일로 한 번에 설치합니다.

PowerShell
python -m pip install -r requirements.txt   # 목록대로 한 번에
python -m pip install requests              # 하나만
python -m pip list                          # 설치된 패키지 확인

pip 대신 python -m pip로 쓰면 지금 켜진 가상환경에 설치되는 것이 분명해집니다.

5

VS Code에 연결

  1. VS Code에서 프로젝트 폴더를 엽니다 (파일 → 폴더 열기).
  2. Ctrl+Shift+P → Python: Select Interpreter를 입력해 고릅니다.
  3. 목록에서 .venv가 들어간 항목을 고릅니다.

오른쪽 아래 상태 표시줄에 ('.venv')가 보이면 연결된 것입니다. 그 뒤로 VS Code에서 여는 터미널은 가상환경을 자동으로 켭니다.

6

끄기 · 다시 만들기

하고 싶은 것방법
끄기deactivate
켜지 않고 실행.venv\Scripts\python.exe main.py. 수업 자료의 실행 명령이 이 방식입니다.
처음부터 다시.venv 폴더를 지우고 2부터 다시 합니다. 코드에는 영향이 없습니다.

.venv는 git에 올리지 않습니다. 용량이 크고 PC마다 다릅니다. .gitignore에 .venv/를 적고, 대신 requirements.txt를 올립니다.

막히면

증상할 일
py를 찾을 수 없음Python이 설치되지 않았거나 설치할 때 py launcher가 빠졌습니다. python.org에서 다시 설치합니다.
(.venv)가 안 보임3의 명령을 프로젝트 폴더에서 실행했는지 확인합니다. ls .venv로 폴더가 있는지 봅니다.
ModuleNotFoundError가상환경을 켜지 않고 실행했거나 그 환경에 패키지를 설치하지 않았습니다. Get-Command python으로 경로를 확인합니다.
