PostgreSQL 설치 가이드

수업 전에 PostgreSQL 18과 pgAdmin 4를 설치하고, 접속까지 확인합니다.

한눈에 보기

설치할 것 (설치 파일 1개)
  • PostgreSQL Server 18
  • pgAdmin 4 · SQL 실행 도구
  • Command Line Tools · psql
설치하지 않아도 되는 것
  • Python 라이브러리
  • Docker
  • Stack Builder
끝났다는 표시

pgAdmin Query Tool에서 접속 확인 SQL을 실행하면 postgres · postgres 한 줄이 나옵니다.

1

설치 파일 내려받기

  1. postgresql.org/download/windows에서 Download the installer를 누릅니다. postgresql.org/download 첫 화면에서 왔다면 Windows를 누르면 같은 곳입니다.
  2. EDB 다운로드 표에서 PostgreSQL 18.x 줄의 Windows x86-64를 받습니다. 표 맨 위에 더 새 버전(19 등)이 보여도 수업 기준인 18.x를 받습니다.
  3. 받은 파일(postgresql-18.x-windows-x64.exe)을 실행하고, 관리자 권한을 물으면 예를 누릅니다.
2

3

pgAdmin으로 서버에 접속

  1. Win → pgAdmin 4 실행. 처음에는 여는 데 시간이 조금 걸립니다.
  2. 왼쪽 Object Explorer에서 Servers → PostgreSQL 18을 누릅니다. 아직 접속 전이라 서버 아이콘에 빨간 X가 붙어 있습니다.
  3. Connect to Server 창에 설치 때 정한 postgres 비밀번호를 입력하고 OK. Save Password를 체크하면 다음부터 묻지 않습니다.
  4. 빨간 X가 사라지고 Databases → postgres가 펼쳐지면 접속된 것입니다.

처음 실행할 때 Master Password를 물을 수도 있습니다. 물으면 pgAdmin 전용 비밀번호를 새로 정하고(DB 비밀번호와 다른 것), 묻지 않으면 그냥 넘어갑니다.

서버가 목록에 없으면Servers에서 오른쪽 클릭 → Register → Server… → General 탭 Name에 아무 이름 → Connection 탭에 Host localhost, Port 5432, Username postgres, Password 입력 → Save.

4

Query Tool을 열고 설정 확인

  1. Databases → postgres를 선택하고 위 메뉴 Tools → Query Tool을 누릅니다.
  2. Query Tool 위쪽 실행 버튼(▶) 오른쪽 ▾를 눌러 아래처럼 되어 있는지 봅니다. 기본값이 이미 이렇게 되어 있습니다. 다르면 항목을 눌러 맞춥니다.
설정값이유
Auto commit?체크 (ON)한 문장씩 바로 저장됩니다. BEGIN;을 쓰면 그때만 묶입니다.
Auto rollback on error?체크 해제 (OFF)오류 뒤 ROLLBACK;을 직접 실행해 보는 수업입니다.
5

접속 확인 SQL 실행

Query Tool에 아래 두 줄을 붙여 넣고 F5(또는 ▶)를 누릅니다.

Query Tool · postgres DB
SELECT version();
SELECT current_user, current_database();

아래 Data Output에 current_user · current_database가 모두 postgres인 한 줄이 나오면 준비 끝입니다. 두 줄을 한 번에 실행하면 pgAdmin은 마지막 줄 결과만 보여 줍니다. 정상입니다. 버전은 첫 줄만 드래그해 F5로 볼 수 있습니다.

명령창으로도 접속해 보려면 psql 접속 가이드를 봅니다. 선택입니다.

여기까지만실습용 DB(knowledge_lab) 만들기와 표 준비는 수업 1교시에 함께 합니다. 미리 만들지 않아도 됩니다.
