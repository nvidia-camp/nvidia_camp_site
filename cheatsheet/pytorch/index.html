2데이터: 미니배치로 나누기torch.utils.data

class MyDS(Dataset):
    def __init__(self, X, y):
        self.X, self.y = X, y
    def __len__(self):          # 샘플 수
        return len(self.X)
    def __getitem__(self, i):   # 샘플 1개
        return self.X[i], self.y[i]
  • DataLoader(ds, batch_size=64, shuffle=True) 64개씩 묶고, 에폭마다 섞음(학습 데이터만)
  • X, y = next(iter(train_dl)) 배치 하나 꺼내 shape 확인

3모델: 예측 만들기torch.nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Flatten(),
            nn.Linear(28*28, 512), nn.ReLU(),
            nn.Linear(512, 10))
    def forward(self, x):    # model(x)
        return self.layers(x)
  • nn.Linear(in_features, out_features) (N, in) → (N, out). 앞 층의 out = 다음 층의 in
  • nn.ReLU() 비선형. 없으면 Linear를 여러 층 쌓아도 Linear 하나와 같음

4손실과 기울기torch.nn

  • nn.CrossEntropyLoss() 분류: 로짓 (N,C), 정답 (N,) long
  • nn.MSELoss() 회귀: 예측과 정답의 제곱 오차
  • loss.backward() 모든 가중치의 기울기를 p.grad에 더함 → 매번 zero_grad()

5최적화: 가중치 갱신torch.optim

  • optim.SGD(model.parameters(), lr=lr) p ← p − lr × p.grad
  • optim.Adam(model.parameters(), lr=1e-3) 가중치마다 보폭을 조절. 처음 시도하기 무난

6평가와 과적합torch

def test(model):
    model.eval(); correct = 0  # Dropout 끔
    with torch.no_grad():      # 기울기 끔
        for X, y in test_dl:   # 안 본 데이터
            X, y = X.to(device), y.to(device)
            hit = model(X).argmax(1) == y
            correct += hit.sum().item()
    return correct / len(test_dl.dataset)

학습 손실은 내려가는데 평가 정확도가 떨어지면 과적합 → epochs 줄이기, nn.Dropout(p=0.5) 추가
