# 참고 문서 로고

홈·과목 목록의 '참고' 칩(치트시트·설치 가이드)에서 해당 도구를 식별하기 위한 공식 자산입니다.
색과 비율을 변경하지 않으며, 다크 모드에서도 흰색 받침 위에 표시합니다.
인접한 제목이 라이브러리 이름을 제공하므로 이미지의 대체 텍스트는 비웁니다.
`build_site.py`가 data URL로 HTML에 포함하여 오프라인에서도 표시됩니다.
