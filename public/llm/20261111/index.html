PostgreSQL 설치 가이드

수업 전에 PostgreSQL 18과 pgAdmin 4를 설치하고, 접속까지 확인합니다. 15분 정도 걸립니다.

한눈에 보기

설치할 것 (설치 파일 1개)
  • PostgreSQL Server 18
  • pgAdmin 4 · SQL 실행 도구
  • Command Line Tools · psql
설치하지 않아도 되는 것
  • Python 라이브러리
  • Docker
  • Stack Builder

pgAdmin Query Tool에서 SELECT version();을 실행하면 PostgreSQL 18로 시작하는 한 줄이 나옵니다.

비밀번호를 잊으면 접속할 수 없습니다. 다른 사이트에서 쓰는 비밀번호는 쓰지 마세요.

1

이미 설치되어 있는지 확인

  1. Win 키를 누르고 pgAdmin 또는 SQL Shell을 검색합니다.
  2. 나오지 않으면 → 2단계로 갑니다.
  3. 나오면 → 지우지 말고 그대로 씁니다. 버전이 17이어도 이번 실습은 동작합니다. 3단계는 건너뛰고 4단계로 갑니다.

주의예전에 설치했는데 비밀번호가 기억나지 않으면, 지우기 전에 조교에게 먼저 알려 주세요.

2

설치 파일 내려받기

  1. postgresql.org/download/windows에서 Download the installer를 누릅니다.
  2. EDB 다운로드 표에서 PostgreSQL 18.x 줄의 Windows x86-64를 받습니다.
  3. 받은 파일(postgresql-18.x-windows-x64.exe)을 실행하고, 관리자 권한을 물으면 예를 누릅니다.
3

4

pgAdmin으로 서버에 접속

  1. Win → pgAdmin 4 실행. 처음에는 여는 데 시간이 조금 걸립니다.
  2. Master Password를 물으면 pgAdmin 전용 비밀번호를 새로 정합니다. DB 비밀번호와 다른 것입니다.
  3. 왼쪽 Object Explorer에서 Servers → PostgreSQL 18을 누릅니다.
  4. 비밀번호 창에 설치 때 정한 postgres 비밀번호를 입력합니다. Save Password를 체크하면 다음부터 묻지 않습니다.
  5. 서버 아래에 Databases가 펼쳐지면 접속된 것입니다.

서버가 목록에 없으면Servers에서 오른쪽 클릭 → Register → Server… → General 탭 Name에 아무 이름 → Connection 탭에 Host localhost, Port 5432, Username postgres, Password 입력 → Save.

5

Query Tool을 열고 설정 두 가지

  1. Databases → postgres를 선택하고 위 메뉴 Tools → Query Tool을 누릅니다.
  2. Query Tool 위쪽 실행 버튼(▶) 옆 ▾를 눌러 다음처럼 맞춥니다.
설정값이유
Auto commit?체크 (ON)한 문장씩 바로 저장됩니다. BEGIN;을 쓰면 그때만 묶입니다.
Auto rollback on error?체크 해제 (OFF)오류 뒤 ROLLBACK;을 직접 실행해 보는 수업입니다.

같은 설정은 File → Preferences → Query Tool → Options에도 있습니다. 여기서 바꾸면 새로 여는 Query Tool에 계속 적용됩니다.

6

접속 확인 SQL 실행

Query Tool에 아래를 붙여 넣고 F5(또는 ▶)를 누릅니다.

Query Tool · postgres DB
SELECT version();
SELECT current_user, current_database();

아래 Data Output에 PostgreSQL 18.x, compiled by Visual C++ …와 postgres · postgres가 보이면 준비 끝입니다.

여기까지만실습용 DB(knowledge_lab) 만들기와 표 준비는 수업 1교시에 함께 합니다. 미리 만들지 않아도 됩니다.

7

psql로도 접속해 보기

선택
  1. Win → SQL Shell (psql) 실행.
  2. Server, Database, Port, Username은 Enter를 네 번 눌러 기본값을 씁니다.
  3. 비밀번호를 입력합니다. 화면에 글자가 보이지 않아도 정상입니다.
  4. postgres=#가 보이면 아래를 입력하고, 끝낼 때 \q를 입력합니다.
SQL Shell (psql)
SELECT version();
\conninfo
\q

"Console code page (949) differs from Windows code page" 경고는 무시해도 됩니다. 한글 결과가 깨져 보이면 한글이 들어간 실습은 pgAdmin으로 합니다.
