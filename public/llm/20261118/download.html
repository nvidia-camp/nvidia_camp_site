02

Vector · Similarity · Distance

2교시

문장을 벡터로 표현하면 숫자로 가까움을 비교할 수 있습니다. 이번 모델의 384차원은 숫자 384개라는 뜻이지, 384글자 또는 384개 정답이 아닙니다.

척도뜻가까운 순서
Cosine similarity두 벡터 방향의 유사도큰 값 우선
Cosine distance1 − Cosine similarity작은 값 우선
Dot Product좌표별 곱의 합, 벡터 길이 영향 가능큰 값 우선
L2 distance두 점 사이의 유클리드 거리작은 값 우선

정규화

벡터를 길이 1로 맞춥니다. 영벡터에는 코사인 유사도를 정의할 수 없습니다.

주의

Cosine 0.8은 정답 확률 80%가 아닙니다. 같은 차원만으로 서로 다른 모델의 벡터를 섞지 않습니다.

같은 Embedding 계약의 벡터를, 같은 거리 기준으로 비교합니다.

03

Sentence Transformers: 질문과 지식의 역할 구분

3교시

교육용 후보인 intfloat/multilingual-e5-small은 384차원 벡터를 출력합니다. 검색용 입력에는 모델 지침에 따라 query: 와 passage: 접두어를 구분합니다.

질문 · 질의 벡터

query: 파일은 어디에 보관하나요?

지식 원문 · 사전 준비할 문서 벡터

passage: 실습 파일은 개인 폴더에 보관합니다.

기록할 것

모델 ID·revision, 입력 규칙, 벡터 차원·정규화, 원문 버전

바뀌면?

모델·입력 계약 변경 시 문서와 질의 벡터를 함께 재생성하고 검증

실습 원칙: 기존 가상환경 재사용 · Python 패키지는 필요한 것만 설치 · CPU 우선

오늘의 encode는 모델 가중치를 다시 학습하지 않고 Embedding을 계산합니다.

버전

설치 버전 v0.8.7은 수업용 후보입니다. 실제 서버 확장 버전과 설치 성공은 각 PC에서 조회·검증해야 합니다.

pip만으로는 끝나지 않습니다

Python용 pgvector를 pip로 설치해도 PostgreSQL 서버 확장 설치가 자동으로 끝나지는 않습니다.

실행하는 프로그램이 다릅니다. 빌드는 Native Tools, 활성화는 pgAdmin, 패키지 설치는 Git Bash에서 합니다.

05

Exact Top-k · Metadata · HNSW

5·6교시

Top-k는 질문과 가까운 후보를 최대 k개 반환합니다. 이번 SQL의 <=>는 Cosine distance이므로 값이 작은 순서(ASC)로 검색합니다.

SELECT id, title, content,
       embedding <=> %s AS distance
FROM day23_search_docs
ORDER BY embedding <=> %s ASC
LIMIT %s;

Exact Search

전체 후보를 비교하는 정확 검색 기준선입니다.

HNSW

근사 검색을 위한 그래프 인덱스입니다. 기준선 후보를 놓칠 수 있습니다.

EXPLAIN

쿼리 계획을 확인합니다. 작은 테이블에서 Seq Scan도 정상일 수 있습니다.

인덱스 생성 성공, 실제 인덱스 사용, 검색 품질 향상은 서로 다른 검증입니다.
