1읽기와 배열 확인cv2 · NumPy

imread(path) 파일 → BGR 배열 · 실패: None

shape 높이·너비·채널 · dtype 자료형
min() / max() 값 범위 · uint8: 0~255

읽기 성공 확인 후 처리 · shape/dtype은 속성

2색 표현 바꾸기cv2.cvtColor

cvtColor(src, code) 입력 → 변환된 배열

COLOR_BGR2GRAY 밝기 1채널
COLOR_BGR2RGB Matplotlib 표시용
COLOR_GRAY2BGR 같은 값 3채널 복제

RGB 표시용 배열은 BGR로 되돌려 저장

3크기와 보간법cv2.resize

resize(src, dsize, interpolation=...)
dsize=(W,H) · (160,120) → shape (120,160)

INTER_AREA 축소에 자주 사용
INTER_LINEAR 기본값 · 부드러운 보간
INTER_NEAREST 최근접 · Mask에 적합

320×240 → 160×120은 가로세로 비율 유지

4이웃으로 잡음 줄이기cv2.GaussianBlur

GaussianBlur(src, ksize, sigmaX)
가중 평균 · 입력과 같은 크기의 배열 반환

(3,3) 이웃 크기 · 여기서는 양수 홀수
0 sigmaX를 Kernel 크기로부터 계산

큰 Kernel → 강한 Blur·세부 손실 증가

5경계 찾기cv2.Canny

Canny(image, threshold1, threshold2)
강한 경계와 연결된 약한 경계를 남김
임계값↓: 잡음 증가 · ↑: 약한 경계 손실

80/160은 밝기 이진화 기준이 아님
출력 0/255 · 흰색은 경계, 검은색은 배경

6저장·재읽기cv2.imwrite

imwrite(filename, img) → 저장 성공 bool
출력 폴더 먼저 준비 · 확장자가 형식 결정
imread(path, 0) Gray로 재읽고 shape 확인

7같은 처리를 Frame마다cv2
