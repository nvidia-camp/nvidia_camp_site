1. 데이터 불러오기pd.read_csv() · df.head() · df.info()먼저 표의 모양을 확인하고 X와 y를 나누기
2. 전처리train_test_split() · .fit_transform() · .transform()분할 먼저, 전처리는 train에서만 배우고 같은 규칙을 적용
3. 모델DecisionTreeClassifier() · .fit() · .predict()모델 이름보다 fit은 학습, predict는 예측이라는 공통 흐름 기억
4. 하이퍼파라미터 조정max_depth · n_estimators설정을 하나씩 바꾸되, 비교하는 데이터와 지표는 동일하게
5. 최종 모델 선택cross_val_score() · scores.mean()미리 정한 기준으로 비교하고, 선택한 모델을 전체 train에 다시 학습
6. 평가f1_score() · confusion_matrix()점수와 오답을 함께 확인. Day7에서는 test를 보관
7. 저장joblib.dump() · joblib.load() · .to_csv()모델 파일과 결과표는 다름. 전처리가 있으면 모델과 함께 저장

fit → 배우기전처리는 통계·범주를, 모델은 예측 규칙을 학습

transform → 바꾸기이미 배운 전처리 규칙으로 입력을 변환

predict → 예측하기Pipeline에서는 변환을 거쳐 모델의 예측값 반환

기본 흐름을 위한 축소 예제. 기본필수 정상 20건에서 글자 수 한 열만 사용합니다. 원본 통합 실습의 작업 종류 인코딩은 생략했으므로 원본 결과와 직접 비교하지 않습니다. test는 보관합니다. 작은 자료에서는 후보가 모두 동점이거나 F1=0일 수 있으며, 이때 성능 우위를 단정하지 않고 정해 둔 순서로 잠정 선택합니다.

직접 익힐 부분은 데이터 선택·fit·predict·점수 비교. Pipeline은 “전처리와 모델을 묶어 누수를 막는 틀”로 이해하고 제공 코드를 사용하면 됩니다. 복잡한 조합 문법은 암기 대상이 아닙니다.

실행 위치: 이 HTML이 있는 폴더. 기존 수업 가상환경 사용. 생성물은 outputs/basic_flow_*에 저장.

Python긴 코드는 가로로 스크롤
# 이 HTML이 있는 폴더에서 실행. 기본필수 정상 20건 사용.
from pathlib import Path
import pandas as pd
import joblib
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import f1_score, confusion_matrix

# 1. 불러오기: 글자 수로 실패 여부를 예측
raw = pd.read_csv("../01_basic/requests.csv")
print(raw.head())

# 2. 분할: train 12 / valid 4 / test 4. test는 보관만.
develop, test = train_test_split(
    raw, test_size=0.2, stratify=raw["failed"], random_state=42
)
train, valid = train_test_split(
    develop, test_size=0.25, stratify=develop["failed"], random_state=42
)
X_train, y_train = train[["input_chars"]], train["failed"]
X_valid, y_valid = valid[["input_chars"]], valid["failed"]

# 3~4. 모델과 설정 후보: 깊이만 바꾼 Tree 두 개 + Forest
candidates = [
    ("Tree 깊이1", DecisionTreeClassifier(max_depth=1, random_state=42)),
    ("Tree 깊이3", DecisionTreeClassifier(max_depth=3, random_state=42)),
    ("Forest", RandomForestClassifier(
        n_estimators=20, max_depth=3, random_state=42
    )),
]

# 5. 같은 3-fold로 비교. 동점이면 먼저 적은 후보를 유지.
best_cv = -1
for name, estimator in candidates:
    # 제공 틀: CV의 각 학습 부분에서 전처리까지 새로 학습.
    # 정상 20건에는 결측이 없어 median 대체로 값이 바뀌지 않음.
    model = Pipeline([
        ("fill", SimpleImputer(strategy="median")),
        ("model", estimator),
    ])
    scores = cross_val_score(model, X_train, y_train, cv=3, scoring="f1")
    print(name, "CV 평균:", scores.mean(), "편차:", scores.std())
    if scores.mean() > best_cv:
        best_cv, best_name, best = scores.mean(), name, model

best.fit(X_train, y_train)  # CV 후에는 전체 train으로 다시 학습
print("선택:", best_name)

# 6. valid 진단. test로 예측하거나 평가하지 않음.
prediction = best.predict(X_valid)
print("valid F1:", f1_score(y_valid, prediction, zero_division=0))
print(confusion_matrix(y_valid, prediction, labels=[0, 1]))

# 7. 학습한 전처리와 모델을 함께 저장
out = Path("outputs")
out.mkdir(exist_ok=True)
joblib.dump(best, out / "basic_flow_pipeline.joblib")
restored = joblib.load(out / "basic_flow_pipeline.joblib")
print("복원 예측 동일:", (prediction == restored.predict(X_valid)).all())
pd.DataFrame({"actual": y_valid, "prediction": prediction}).to_csv(
    out / "basic_flow_predictions.csv", index=False, encoding="utf-8-sig"
)
