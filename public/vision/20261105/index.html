8교시seed 고정

무작위 시작값을 맨 앞에서 고정합니다. 그래야 다시 돌려도 같은 결과가 나옵니다.

transform = transforms.Compose([transforms.Resize((32, 32)), transforms.ToTensor()])
train_set = ImageFolder("data/train", transform=transform)
valid_set = ImageFolder("data/valid", transform=transform)
train_set.class_to_idx              # {'circle': 0, 'square': 1, 'triangle': 2}

1교시① 데이터 읽기

폴더 이름이 곧 라벨 번호입니다. class_to_idx로 매핑을 눈으로 확인하고, 입력 규칙(32×32, 값 0~1)도 여기서 정합니다.

backbone = load_pretrained_backbone()          # 다른 데이터로 이미 학습된 특징 추출기
for p in backbone.parameters():
    p.requires_grad = False                    # ① Backbone을 얼린다
# [3교시] Partial이면 마지막 Conv 층만 다시 연다: backbone[4].requires_grad_(True)
head = nn.Linear(256, 3)                       # ② 새 Head (특징 256개 → 클래스 3개)
model = nn.Sequential(backbone, head)
backbone.eval()                                # ③ BN 기억값 고정 (얼리기와 별개)

2교시② 모델 만들기

얼리고 → 새 Head를 붙이고 → eval(). 얼리기는 가중치를, eval()은 BN 기억값을 고정하는 서로 다른 스위치입니다.

optimizer = torch.optim.AdamW(
    [p for p in model.parameters() if p.requires_grad], lr=0.01)
criterion = nn.CrossEntropyLoss()              # [4교시] 불균형이면 weight=...

best_loss = float("inf")
for epoch in range(8):
    optimizer.zero_grad()                      # 1) 지난 gradient 지우기
    loss = criterion(model(X_train), y_train)  # 2) 예측하고 오차 계산
    loss.backward()                            # 3) gradient 계산
    optimizer.step()                           # 4) 한 걸음 이동
    valid_loss = F.cross_entropy(model(X_valid), y_valid)   # valid는 채점만
    if valid_loss < best_loss:                 # [7교시] 가장 좋았던 순간 기억
        best_loss, best_state = valid_loss, copy.deepcopy(model.state_dict())
model.load_state_dict(best_state)

3·4교시③ 학습 ×8 → ④ best 복원

열린 파라미터만 optimizer에 넘깁니다. 한 epoch = 지우기 → 오차 → gradient → 한 걸음. valid는 채점만 하고, valid loss가 가장 낮았던 가중치를 기억했다가 되돌립니다.

pred = model(X_valid).argmax(dim=1)            # 가장 큰 점수 = 예측
f1_score(y_valid, pred, average="macro")       # 클래스마다 같은 비중으로 평균
confusion_matrix(y_valid, pred)                # 행 = 실제, 열 = 예측

4·5교시⑤ 평가

가장 큰 점수가 예측입니다. 클래스마다 같은 비중인 Macro F1과 confusion matrix(행=실제, 열=예측)로 어디서 틀렸는지 봅니다.

features = conv_layers(image)                  # 마지막 Conv 블록의 특징 지도
score = remaining_layers(features)             # 나머지 층 → 클래스 점수 3개
grad = torch.autograd.grad(score[0, target], features)[0]
cam = (grad.mean(dim=(2, 3), keepdim=True) * features).sum(dim=1).relu()

6교시⑥ 설명 · Grad-CAM

target 클래스 점수를 마지막 Conv 특징 지도로 미분해 채널별 중요도를 구하고, 점수를 올린 곳(relu)만 남깁니다.

torch.save({"weights": best_state, "classes": train_set.classes,
            "lr": 0.01, "epochs": 8, "seed": 14, "test_used": False}, "model.pt")

사전학습 모델의 공식 입력 규칙 지키기잘못 섞으면 조용히, 자신 있게 틀림
BN 정책을 정하고 비교파라미터를 얼려도 BN 기억값은 따로 바뀔 수 있음

3교시학습

lr·epoch·전략을 바꿔 가며 재기학습량이 부족하면 Head-only가 덜 배운 채 끝남
단계적 해제와 층별 lr새 Head는 크게, 이미 배운 Backbone은 작게 움직임

4교시불균형

class weight 적용적은 클래스를 되살리되, 너무 세면 오히려 나빠짐(0.539)
Sampler와 별도 후보로 비교둘을 함께 쓰면 보정이 두 번 들어감

5교시오류

오답을 확신도와 함께 저장자신 있게 틀린 오답이 더 위험
오답마다 관찰 → 가설 → 다음 확인을 기록해 다음 실험으로 연결

6교시설명

target을 바꿔 비교같은 이미지라도 묻는 클래스에 따라 답이 다름
Occlusion 실험CAM이 가리킨 곳을 가린 입력에서 점수가 실제로 바뀌는지 확인

7교시선택

후보 3개를 한 조건씩 바꿔 비교표로 나란히
미리 정한 규칙(Macro F1 → loss)으로 선택결과를 본 뒤 기준을 바꾸지 않음

8교시재현
