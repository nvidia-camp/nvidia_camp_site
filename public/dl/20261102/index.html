Kernel 연산

작은 창의 값과 가중치를 곱해 합산 → Feature Map의 한 칸

× =

강조한 영역 × Kernel = 1 + 1 + 1 = 3 → 출력 첫 칸. 창을 한 칸씩 옮기며 반복합니다. 이 Kernel은 세로선에 반응합니다. 실제 Kernel 값은 학습으로 정해집니다. (PDF p.6 · stride 1, padding 0, bias 0)

한 칸의 계산 hij = a[β + ΣΣ ωmn·xi+m−2, j+n−2] (UDL 식 10.6)
출력 크기 Hout = ⌊(H + 2P − D(K−1) − 1) / S⌋ + 1 (PDF p.26)

Kernel 크기 K 창의 크기. 가운데를 두려고 보통 홀수
Stride S 창이 건너뛰는 칸 수. 2면 출력이 약 ½
Padding P 가장자리에 0을 덧댐. 3×3에 P=1이면 크기 유지
채널 Cin → Cout Kernel 하나가 출력 채널 하나. RGB면 Kernel 하나가 3채널을 모두 봄

같은 Kernel을 모든 위치에 씁니다(가중치 공유). Conv 3→16(3×3)은 3·16·3·3 + 16 = 448개입니다. 같은 사진을 펼쳐 뉴런 128개에 연결하면 첫 층만 약 157만 개입니다. 파라미터 수는 사진 크기와 무관합니다.UDL 10.2.4 · 10.3 · PDF p.18

주석의 A·B가 지도 위치입니다. 지도 A는 모델 클래스 안, 지도 B는 클래스 밖입니다.

# B-1 데이터 준비 ─────────────────────────────────────
train_ds = ImageFolder("data/train", transform=train_tf)   # 증강은 train에만
valid_ds = ImageFolder("data/valid", transform=valid_tf)
train_loader = DataLoader(train_ds, batch_size=32, shuffle=True)

# 지도 A · 모델 안 ────────────────────────────────────
class SmallCNN(nn.Module):
    def __init__(self, num_classes):
        super().__init__()
        self.features = nn.Sequential(       # A-① 특징 추출부
            nn.Conv2d(3, 16, 3, padding=1),  # A-② Conv 블록 (A-③ Kernel은 이 안)
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(16, 32, 3, padding=1), # A-② Conv 블록 두 번째
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.pool = nn.AdaptiveAvgPool2d(1)  # A-① Global Avg Pool
        self.fc = nn.Linear(32, num_classes) # A-① Head

    def forward(self, x):                    # [N,3,H,W]
        x = self.features(x)                 # [N,32,H/4,W/4]
        x = torch.flatten(self.pool(x), 1)   # [N,32]
        return self.fc(x)                    # [N,K] 점수

# B-2 모델 후보 · 전이학습 ────────────────────────────
model = resnet18(weights=ResNet18_Weights.DEFAULT)
for p in model.parameters():
    p.requires_grad = False                  # Backbone 고정
model.fc = nn.Linear(model.fc.in_features, num_classes)  # Head 교체

# B-3 학습 ~ B-6 성능표 ───────────────────────────────
loss_fn = nn.CrossEntropyLoss()              # Softmax 포함
