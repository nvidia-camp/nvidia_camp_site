공통 바탕1교시

Q1 RNN은 왜 모든 시점에 같은 가중치를 쓰나?시점마다 다른 가중치를 쓰면 길이가 바뀔 때마다 새로 배워야 한다. 같은 가중치를 쓰면 길이가 4든 50이든 같은 모델로 읽는다.
따로W₁W₂W₃W₄W₅ ?길이 5는 못 읽음
같이WWWWW길이 상관없음

코드에서는nn.RNN(input_size, hidden_size)에는 길이 T를 정하는 인자가 없다. 그래서 길이가 다른 입력도 같은 모델에 넣는다 (p.28).

Q2 Padding은 왜 계속 빼라고 하나?Padding은 길이를 맞추려고 채운 0이라 실제 값이 아니다. 계산에 섞이면 평균이나 마지막 값이 틀어진다.
순서31400실제 길이 3 + Padding 2
✕(3+1+4+0+0) ÷ 5 = 1.6Padding까지 평균
○(3+1+4) ÷ 3 = 2.67실제 길이로 평균

코드에서는RNN·LSTM은 lengths로 실제 마지막 시점을 고른다. Transformer는 src_key_padding_mask로 Padding을 가리고, 평균은 실제 길이로 나눈다 (p.67, 77).

RNN2교시

Q3 Hidden state h에는 무엇이 들어 있나?지금까지 읽은 입력을 정해진 크기(hidden_size)로 요약한 값이다. 크기가 정해져 있어 다 담지 못하고, 예측에 필요한 것 위주로 남는다.

비유글을 읽으며 적는 메모 한 장. 칸이 정해져 있어 중요한 것만 적는다.

입력x₁x₂x₃…x₅₀길이 4든 50이든
hh · 16칸크기는 항상 hidden_size

코드에서는nn.LSTM(1, 16)의 16이 이 요약의 크기(hidden_size)다 (p.41).

Q4 output과 h_n은 뭐가 다른가?output은 모든 시점의 Hidden state를 모은 것이고, h_n은 마지막 시점의 Hidden state다.
outputh₁h₂h₃h₄[B,T,H]
h_nh₁h₂h₃h₄[L·D,B,H]

코드에서는분류 모델은 h_n[-1](p.30), 예측 모델은 output[:, -1](p.41)로 마지막 시점을 꺼낸다. 1층·단방향·Padding 없음이면 둘은 같은 값이다.

LSTM3교시

Q5 RNN은 왜 긴 순서를 잘 기억하지 못하나?같은 가중치를 시점마다 계속 곱하기 때문이다. 1보다 작은 수를 여러 번 곱하면 0에 가까워지듯, 먼 과거에서 오는 Gradient가 사라진다.
0.9¹0.90
0.9¹⁰0.35
0.9²⁰0.12
0.9⁵⁰0.005

곱하는 횟수(시점 수)가 늘수록 거의 0이 된다.

코드에서는그래서 긴 Window에는 nn.RNN 대신 nn.LSTM을 쓴다. 실습 03 응용에서 둘의 valid MSE를 비교한다 (p.44).

Q6 LSTM은 기억을 어떻게 오래 유지하나?이전 Cell state에 남길 비율(forget gate)을 곱하고, 새 정보는 쓸 비율(input gate)만큼 더한다. 곱하기만 반복하지 않고 더하기로 이어 가서 기억이 오래 간다.
남길 양이전 c 2×forget 0.5=1
쓸 양새 후보 0.5×input 0.4=0.2
새 c1+0.2=1.2c = f⊙c + i⊙g · 강의 p.6

코드에서는Gate 계산은 nn.LSTM이 모두 알아서 한다. 우리가 정하는 것은 hidden_size와 층 수 정도다 (p.36).

Q7 LSTM은 왜 상태가 h와 c 두 개인가?Cell state c는 안에서 오래 들고 가는 기억이고, Hidden state h는 그중 지금 필요한 부분을 꺼낸 출력이다.
cCell state ━━━안에서만 전달
hHidden state→output밖으로 나감

코드에서는output, (h_n, c_n) = lstm(x)처럼 h와 c를 괄호로 묶어 따로 돌려준다. 둘을 하나의 Tensor로 다루면 오류가 난다 (p.40, 43).

Transformer5–6교시

Q8 LSTM이 있는데 왜 Attention이 또 나왔나?LSTM도 한 시점씩 차례로 계산해서 느리고, 먼 시점의 정보는 중간을 모두 거쳐 와야 한다. Attention은 모든 위치를 한 번에 직접 비교한다.
LSTM1→2→3→4차례로 · 거쳐 옴
Attention12344가 1·2·3을 한 번에 직접 봄

코드에서는그래서 Transformer는 시점을 하나씩 돌지 않고 [B,T,E] 전체를 한 번에 받는다 (p.64).

Q9 Attention은 무엇을 계산하나? (Query·Key·Value)Query와 Key를 비교해 어느 위치를 얼마나 볼지(Attention weight)를 정하고, 그 비율대로 Value를 섞는다.

비유회의에서 내 질문(Query)과 관련 있는 사람(Key)일수록 그 사람 말(Value)에 더 귀 기울인다.

weight0.20.30.5Query·Key 비교 → softmax, 합 1
Value102030섞을 내용
출력0.2×10 + 0.3×20 + 0.5×30 = 23강의 p.9

코드에서는Self-Attention은 Query·Key·Value를 모두 같은 입력에서 만들어서 attn(x, x, x)로 쓴다 (p.62).

Q10 Attention 점수는 왜 √d로 나눠서 쓰나?점수 차이가 너무 크면 softmax가 한 위치에 거의 100%를 몰아준다. 그러면 학습이 잘 안 되므로, 점수를 줄여 골고루 보게 한다.

비유점수 차이가 너무 크면 한 사람 말만 듣게 된다.

✕ 점수 [8, 4, 0] 그대로 → 한 곳만 봄

위치 10.98
위치 20.02
위치 30.00

○ √16 = 4로 나눠 [2, 1, 0] → 골고루 봄

위치 10.67
위치 20.24
위치 30.09

코드에서는직접 쓸 일은 없다. nn.MultiheadAttention 안에서 자동으로 나눈다.

Q11 Transformer에는 왜 Position을 더하나?Attention은 위치끼리 비교만 해서 순서를 모른다. 단어 순서를 바꿔도 같은 묶음으로 본다. 그래서 위치마다 다른 값을 더해 순서를 알려 준다.
문장 1womanateraccoon
문장 2raccoonatewoman뜻은 반대인데 같은 묶음
해결입력+Position위치 1·2·3마다 다른 값

코드에서는x + self.position(pos)처럼 입력에 Position Embedding을 더한다. 그래서 입력 길이는 max_len 이하여야 한다 (p.75).

Q12 Encoder Layer 한 층 안에는 무엇이 있나?Self-Attention(위치끼리 정보 섞기)과 Feedforward(위치마다 따로 변환)가 있고, 각각 뒤에 Residual 더하기와 LayerNorm이 붙는다. 입력과 출력 크기가 같아서 여러 층을 쌓을 수 있다.
한 층Self-Attention+LayerNorm→Feedforward+LayerNorm크기 그대로 [B,T,E]
BatchNorm여러 샘플을 묶어 정규화
LayerNorm위치 하나 안에서 정규화 → 길이가 제각각이어도 OK

코드에서는nn.TransformerEncoderLayer(d_model=16, nhead=4) 하나가 이 한 층이다. d_model은 nhead로 나누어떨어져야 한다 (p.64, 73).

Q13 순서가 길어지면 왜 Transformer가 더 무거워지나?모든 위치 쌍을 비교하므로 길이가 T면 T×T번 비교한다. 길이가 2배면 비교는 4배가 된다.
T = 416번
T = 864번 · 길이 2배 → 4배

코드에서는실습 07에서 길이 16·32·64로 시간과 Peak Memory를 재 보면 이 차이가 보인다 (p.88, 91).

Autoencoder4교시

Q14 Autoencoder는 왜 따로 떨어져 있나?미래 값을 맞히는 게 아니라 입력을 그대로 되살리는 게 목표라서, 정답과 평가 지표가 다르다.
예측과거 12개→다음 1개정답 = 미래 값
재구성x 8개→x̂ 8개정답 = x 자신

코드에서는정답이 입력 자신이라 loss = loss_fn(recon, x)처럼 x와 비교한다 (p.56).

Q15 Autoencoder는 왜 가운데를 좁게 만드나?가운데(Latent)가 넓으면 입력을 그대로 베끼기만 한다. 좁게 만들어야 중요한 특징만 골라 담는다. 너무 좁으면 중요한 정보까지 잃는다.

비유긴 글을 세 줄로 요약했다가 다시 풀어 쓰기. 요약이 짧아야 핵심만 남는다.

통로8→4→2→4→8
너무 넓으면그대로 베낌 · 배운 것 없음
너무 좁으면중요한 정보도 잃음

코드에서는nn.Linear(4, 2)의 2가 Latent 크기다. 실습 04 응용에서 1·2·4를 비교한다 (p.56–57).

Q16 재구성 오차가 크면 왜 '이상'이 아니라 '이상 후보'인가?정상 데이터로만 배운 모델이라 낯선 입력은 잘 되살리지 못해 오차가 커진다. 하지만 전처리나 모델 크기 때문에도 오차가 커질 수 있어 확정할 수는 없다.
정상 입력작음
낯선 입력큼

개념 그림이다. 기준값(임계값)은 valid에서 정한다.

코드에서는MSELoss(reduction="none")로 샘플별 오차를 구하고, 기준값은 valid에서 정한 뒤 test는 마지막에 한 번만 본다 (p.54–55).
