pgvector 거리 계산과 검색 기능 검증

pgAdmin Query Tool

9-1. 벡터 거리 계산(데이터베이스 변경 없음)

실행 위치: pgAdmin Query Tool

-- 코사인 거리(<=>)는 작을수록 가깝습니다.
SELECT
  '[1,0,0]'::vector <=> '[1,0,0]'::vector AS same_direction,
  '[1,0,0]'::vector <=> '[0,1,0]'::vector AS perpendicular,
  '[1,0,0]'::vector <=> '[-1,0,0]'::vector AS opposite_direction;

정상 기대값: same_direction = 0, perpendicular = 1, opposite_direction = 2 (실수 표현에 따른 아주 작은 오차는 가능).

9-2. 임시 테이블에 저장하고 Top-k 조회

아래 SQL은 해당 Query Tool 세션의 임시 테이블만 사용하므로 기존 knowledge 테이블을 변경하지 않습니다.

-- 실습을 다시 실행할 때 현재 세션의 동명 임시 테이블만 제거
DROP TABLE IF EXISTS pg_temp.day23_vector_check;

CREATE TEMP TABLE day23_vector_check (
  id integer PRIMARY KEY,
  label text NOT NULL,
  embedding vector(3) NOT NULL
);

INSERT INTO day23_vector_check (id, label, embedding) VALUES
  (1, '같은 방향', '[1,0,0]'),
  (2, '가까운 방향', '[0.8,0.6,0]'),
  (3, '직각 방향', '[0,1,0]');

SELECT id, label,
       ROUND((embedding <=> '[1,0,0]'::vector)::numeric, 4) AS cosine_distance
FROM day23_vector_check
ORDER BY embedding <=> '[1,0,0]'::vector ASC
LIMIT 3;

정상 기대 결과:

id label cosine_distance
1 같은 방향 0.0000
2 가까운 방향 0.2000
3 직각 방향 1.0000

설치 확인 통과 조건: 확장 버전이 0.8.7이고, 벡터 자료형 생성·INSERT·<=> 검색이 모두 동작해야 합니다. 여기까지는 실제 Embedding 모델이 없어도 점검 가능합니다. 강의에서 사용하는 E5-small의 출력은 384차원이므로 본 실습 테이블에서는 vector(384)를 사용합니다. 이 검증용 3차원 벡터와 혼동하지 마세요.

# 프로젝트 폴더에서 실행. 기존 환경 이름이 다르면 실제 이름을 사용하세요.
source .venv/Scripts/activate
python -c "import sys; print(sys.executable)"
python -m pip show pgvector psycopg python-dotenv

  • 이미 있는 패키지는 그대로 사용합니다. 아래 설치 명령은 없는 패키지에 한해 실행해도 됩니다.

10-2. .env 파일 작성

프로젝트의 Python 확인 파일과 같은 폴더에 .env 파일을 만듭니다.

PGHOST=127.0.0.1
PGPORT=5432
PGDATABASE=knowledge_lab
PGUSER=postgres
PGPASSWORD=본인의_DB_비밀번호

반드시 확인: PGDATABASE, PGPORT, PGUSER, PGPASSWORD는 본인의 PostgreSQL 설정으로 교체합니다. knowledge_lab, postgres, 5432는 예시이므로 실제 환경과 다를 수 있습니다. .env는 Git에 올리지 않습니다. 프로젝트의 .gitignore에 아래 한 줄을 추가합니다.

10-3. verify_pgvector.py 파일 작성

.env와 같은 폴더에 verify_pgvector.py를 만들고 그대로 붙여넣습니다.

"""Windows 11 · PostgreSQL 18 · pgvector 설치 확인용, 데이터 수정 없음."""
from pathlib import Path
import psycopg
from dotenv import dotenv_values
from pgvector import Vector
from pgvector.psycopg import register_vector

# .env는 현재 파이썬 파일과 같은 폴더에서만 읽습니다.
cfg = dotenv_values(Path(__file__).with_name(".env"), interpolate=False)
required = ("PGHOST", "PGPORT", "PGDATABASE", "PGUSER", "PGPASSWORD")
missing = [key for key in required if not cfg.get(key)]
if missing:
    raise RuntimeError(".env 설정 누락: " + ", ".join(missing))

with psycopg.connect(
    host=cfg["PGHOST"],
    port=int(cfg["PGPORT"]),
    dbname=cfg["PGDATABASE"],
    user=cfg["PGUSER"],
    password=cfg["PGPASSWORD"],
) as conn:
    # 중요: PostgreSQL 연결마다 vector 타입을 등록합니다.
    register_vector(conn)

    q = Vector([1.0, 0.0, 0.0])
    database, dimensions, distance = conn.execute(
        "SELECT current_database(), vector_dims(%s::vector), "
        "%s::vector <=> %s::vector",
        (q, q, q),
    ).fetchone()

    assert dimensions == 3, f"잘못된 차원: {dimensions}"
    assert abs(float(distance)) < 1e-6, f"잘못된 거리: {distance}"
    print("연결 DB:", database)
    print("벡터 차원:", dimensions)
    print("자기 자신과의 코사인 거리:", distance)
    print("DB 연결 및 pgvector 확인 완료")

실행 위치: VS Code의 Git Bash, 기존 가상환경 활성화 상태

python verify_pgvector.py

정상 예상 출력 예시:

연결 DB: knowledge_lab
벡터 차원: 3
자기 자신과의 코사인 거리: 0.0
DB 연결 및 pgvector 확인 완료

실제 DB 이름과 소수점 표시는 다를 수 있습니다. 이 코드는 데이터를 INSERT하거나 삭제하지 않습니다.

Python register_vector 실패 해당 DB에서 확장 미활성화 또는 잘못된 DB 접속 pgAdmin에서 current_database() 및 pg_extension 재확인

운영 원칙: 오류가 나면 무조건 PostgreSQL을 재설치하지 마세요. 마지막 한 줄만 캡처하는 대신, 실행한 창 종류·실행 명령·첫 번째 오류·확인한 DB 이름을 강사에게 전달하세요. 비밀번호·API 키는 가리고 공유합니다.

12

최종 설치 완료 체크리스트

  • PostgreSQL 18.6 설치본과 현재 접속 DB를 확인했다.
  • 빌드 전용 CMD에서 where cl, where nmake가 성공했다.
  • PGROOT가 PostgreSQL 18 최상위 폴더를 가리킨다.
  • pgvector 공식 소스 태그가 v0.8.7이다.
  • nmake /F Makefile.win 성공 및 vector.dll 생성 확인.
  • PostgreSQL lib와 share\extension 아래 확장 파일이 존재한다.
  • 강의용 DB의 pg_extension 조회에서 vector 0.8.7이 보인다.
  • SQL에서 코사인 거리 0 · 1 · 2가 조회된다.
  • 임시 테이블 Top-k가 ID 1 → 2 → 3으로 조회된다.
  • 기존 Python 가상환경에서 import pgvector, import psycopg가 된다.
  • python verify_pgvector.py가 DB 연결 및 pgvector 확인 완료를 출력한다.

여기까지 완료하면 내일의 Embedding → PostgreSQL vector(384) 저장 → Cosine Top-k Search 실습을 시작할 수 있습니다.
