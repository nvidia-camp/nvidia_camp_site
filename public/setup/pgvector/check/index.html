오류별 해결 방법

증상·오류 메시지 원인 후보 해결할 위치·방법
git 또는 nmake를 찾지 못함 Git 설치·PATH 문제 또는 일반 CMD 사용 Git 설치 여부를 확인하고 x64 Native Tools Command Prompt를 다시 열어 where 확인
echo %VSCMD_ARG_TGT_ARCH%가 x64가 아님 x86용 개발자 프롬프트를 열었음 x64 Native Tools 프롬프트로 변경
Cannot open include file: 'postgres.h' / fatal error C1083 PGROOT 오류 또는 PostgreSQL 개발 헤더 누락 echo %PGROOT%, dir "%PGROOT%\include\server\postgres.h" 검사
postgres.lib 파일을 찾지 못함 / 링크 오류 다른 PostgreSQL 설치 경로 또는 개발 라이브러리 누락 %PGROOT%\lib\postgres.lib와 pg_config가 같은 설치본인지 확인
error C2196: case value '4' already used x86/x64 아키텍처 불일치 가능 x64 도구에서 nmake /F Makefile.win clean 후 다시 빌드
NMAKE : fatal error U1077 앞쪽 컴파일·링크 실패의 후속 메시지 로그에서 맨 처음 나온 실제 오류부터 수정
Access is denied / Permission denied during install PostgreSQL Program Files 폴더 쓰기 권한 부족 관리자 권한으로 x64 개발자 프롬프트 재실행
extension "vector" is not available 서버 파일이 올바른 PostgreSQL 설치 폴더에 없음 %PGROOT%\lib, %PGROOT%\share\extension 파일 위치와 접속 서버 버전 확인
permission denied to create extension "vector" 현재 DB 계정 권한 부족 적절한 권한의 DB 관리자 계정으로 해당 DB에서 실행
type "vector" does not exist 현재 연결한 DB에 확장이 없음 해당 DB에서 CREATE EXTENSION IF NOT EXISTS vector; 실행
current transaction is aborted 이전 SQL 실패로 트랜잭션이 중단됨 오류가 난 세션에서 ROLLBACK; 실행 후 근본 원인 수정
ModuleNotFoundError: No module named 'pgvector' 다른 Python 인터프리터에 설치 python -c "import sys; print(sys.executable)"와 python -m pip show pgvector 대조
connection refused PostgreSQL 서버 중지 또는 호스트·포트 불일치 pgAdmin의 실제 서버 호스트·포트 및 서비스 상태 확인
password authentication failed DB 계정/비밀번호 불일치 .env의 PGUSER, PGPASSWORD 점검 (공개 공유 금지)
Python register_vector 실패 해당 DB에서 확장 미활성화 또는 잘못된 DB 접속 pgAdmin에서 current_database() 및 pg_extension 재확인

운영 원칙: 오류가 나면 무조건 PostgreSQL을 재설치하지 마세요. 마지막 한 줄만 캡처하는 대신, 실행한 창 종류·실행 명령·첫 번째 오류·확인한 DB 이름을 강사에게 전달하세요. 비밀번호·API 키는 가리고 공유합니다.

12

최종 설치 완료 체크리스트

  • PostgreSQL 18.6 설치본과 현재 접속 DB를 확인했다.
  • 빌드 전용 CMD에서 where cl, where nmake가 성공했다.
  • PGROOT가 PostgreSQL 18 최상위 폴더를 가리킨다.
  • pgvector 공식 소스 태그가 v0.8.7이다.
  • nmake /F Makefile.win 성공 및 vector.dll 생성 확인.
  • PostgreSQL lib와 share\extension 아래 확장 파일이 존재한다.
  • 강의용 DB의 pg_extension 조회에서 vector 0.8.7이 보인다.
  • SQL에서 코사인 거리 0 · 1 · 2가 조회된다.
  • 임시 테이블 Top-k가 ID 1 → 2 → 3으로 조회된다.
  • 기존 Python 가상환경에서 import pgvector, import psycopg가 된다.
  • python verify_pgvector.py가 DB 연결 및 pgvector 확인 완료를 출력한다.

여기까지 완료하면 내일의 Embedding → PostgreSQL vector(384) 저장 → Cosine Top-k Search 실습을 시작할 수 있습니다.
