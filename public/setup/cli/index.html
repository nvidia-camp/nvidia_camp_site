CLI 도구

CLI를 쓰면 AI 코딩 에이전트가 문서를 조회하고, 서비스 상태를 확인하고, 작업 결과를 검증할 수 있습니다. 사람도 같은 명령으로 확인할 수 있습니다.

MCP 대신 CLI

MCPCLI
대화 길이연결만 해도 도구 설명 전체가 매 요청에 들어감쓸 때만 명령과 출력이 들어감
연결에이전트마다 따로 등록설치하면 모든 에이전트가 사용
로그인MCP마다도구마다 한 번 (gh auth login 등)

대신 모델은 도구가 있는지 모릅니다. 설치한 도구는 아래 4처럼 AGENTS.md에 적어 알려 줍니다.

1

기본 묶음

도구하는 일자주 쓰는 명령
ghGitHub 이슈 · PR · CI 실패 로그gh issue view 12
gh run view --log-failed
uv파이썬 실행 · 패키지 · 가상환경 (pip 대신)uv add requests
uv run main.py
ruff파이썬 오류 검사 · 자동 수정ruff check . --fix
gitleaks커밋 전 비밀번호 · API 키 유출 검사gitleaks dir . -v
jq긴 JSON에서 필요한 값만 꺼내기… | jq '.[] | {number, title}'
PowerShell · 한 번에 설치
winget install GitHub.cli astral-sh.uv astral-sh.ruff Gitleaks.Gitleaks jqlang.jq --accept-package-agreements --accept-source-agreements

한 번에 안 되면 하나씩 설치합니다. 설치 후 PowerShell 창을 새로 엽니다.

3

에이전트에게 연결하면 유용한 CLI

선택

지금 작업에 필요한 도구를 골라 연결합니다. 도구 이름을 누르면 공식 사용 안내로 이동합니다.

문서 조회 · 자료 읽기 · 결과 확인

도구이럴 때에이전트에게 도움이 되는 점
Context7
ctx7		라이브러리를 사용해 코딩할 때필요한 문서와 코드 예제를 조회해 사용법을 확인합니다.
Playwright CLI
playwright-cli		웹페이지를 만들거나 수정할 때브라우저를 열고 버튼을 클릭하며 화면과 동작을 확인합니다.
MarkItDown
markitdown		문서를 AI의 입력 자료로 쓸 때PDF · Word · PPT의 내용을 Markdown으로 변환해 읽고 활용합니다.
ripgrep
rg		프로젝트의 코드를 찾을 때함수 이름이나 오류 문구를 검색해 관련 파일과 코드 위치를 찾습니다.
jq
jq · 기본 묶음		API 응답이나 JSON이 길 때필요한 필드만 추려 읽을 내용을 줄이고 데이터를 비교합니다.

서비스 조회 · 작업 수행

서비스 · CLI이럴 때에이전트에게 도움이 되는 점
GitHub
gh · 기본 묶음		GitHub 프로젝트를 작업할 때이슈 · PR · CI 실패 로그를 읽어 작업할 내용과 오류 원인을 파악합니다.
Docker
docker		앱이나 DB를 컨테이너로 실행할 때컨테이너를 실행하고 상태와 로그를 확인해 실행 환경을 점검합니다.
AWS
aws		AWS의 서버 · 저장소를 다룰 때클라우드 자원의 실제 설정과 상태를 조회하고 필요한 작업을 수행합니다.
Google Cloud
gcloud		Google Cloud의 앱을 관리할 때프로젝트와 배포 상태를 조회하고 로그를 읽어 문제를 확인합니다.
Vercel
vercel		웹사이트를 Vercel에 배포할 때사이트를 배포하고 배포 상태와 로그를 확인합니다.

설치한 도구는 아래 4처럼 안내문에 적어 에이전트가 언제 쓸지 알 수 있게 합니다. 서비스 CLI는 해당 계정의 로그인과 권한 설정이 필요할 수 있습니다.

4

에이전트에게 알려 주기

전역 안내문 $HOME\.config\opencode\AGENTS.md에 설치한 도구만 한 줄씩 적습니다. Claude Code는 CLAUDE.md에 같은 내용을 적습니다.

AGENTS.md
# 사용할 수 있는 CLI
- 최신 라이브러리 문서: `npx ctx7 library <이름> "<질문>"` → `npx ctx7 docs <ID> "<질문>"`
- 파이썬: pip 대신 `uv` (`uv run`, `uv add`). 파일을 고친 뒤 `ruff check`
- GitHub: `gh` (출력은 `--json 필드 --limit N`으로 줄이기). CI 실패는 `gh run view --log-failed`
- 커밋 전: `gitleaks dir . -v`

에이전트는 내 계정 권한을 그대로 씁니다. 로그인된 gh로 저장소 삭제도 할 수 있습니다. gh repo delete처럼 되돌릴 수 없는 명령은 승인 창에서 거부합니다.
