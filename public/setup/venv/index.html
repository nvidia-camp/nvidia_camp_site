Python 가상환경

Python 패키지를 용도별로 따로 설치해 두는 폴더입니다. 수업에서는 가상환경을 용도별 이름으로 만들고, 실습 저장소 바깥에 둡니다.

C:\workspace\
├─ envs\                    ← 가상환경을 모아 두는 폴더
│  ├─ gpuenv\               ← GPU 실습용 (PyTorch · CUDA)
│  └─ backendenv\           ← 백엔드 실습용 (FastAPI · DB)
└─ practice_assignment\     ← 실습 저장소. 가상환경을 넣지 않음
   ├─ 20261112\
   └─ 20261113\
용도별 이름

필요한 패키지가 다른 실습끼리 환경을 나눕니다. 이름만 보고 무엇을 위한 환경인지 압니다.

저장소 바깥에 두는 이유

여러 날짜 폴더가 같은 환경을 함께 씁니다. 저장소를 지우거나 다시 받아도 환경이 남고, git에 섞이지 않습니다.

켜졌다는 표시

PowerShell 줄 맨 앞에 (gpuenv)처럼 환경 이름이 붙습니다.

환경 이름과 폴더 위치는 예시입니다. 수업에서 안내하는 이름이 있으면 그 이름을 씁니다.

1

설치된 Python 확인

PowerShell
py --list          # 설치된 Python 버전 목록
py -3.13 --version # Python 3.13.x

py는 Windows용 Python에 함께 설치되는 실행기입니다. 버전을 골라 실행할 수 있어서 py -3.13으로 시작합니다.

2

가상환경 만들기

가상환경을 모아 둘 폴더를 만들고, 그 안에 용도별 이름으로 만듭니다. 환경마다 한 번만 합니다.

PowerShell
mkdir C:\workspace\envs -Force
py -3.13 -m venv C:\workspace\envs\gpuenv
py -3.13 -m venv C:\workspace\envs\backendenv
환경쓰는 실습
gpuenvGPU를 쓰는 실습: PyTorch · CNN · YOLO · LLM
backendenv서버와 DB 실습: FastAPI · PostgreSQL 연동
3

가상환경 켜기

어느 폴더에 있든 환경의 전체 경로로 켭니다.

PowerShell
C:\workspace\envs\gpuenv\Scripts\Activate.ps1

줄 맨 앞에 (gpuenv)가 붙으면 켜진 것입니다. PowerShell 창을 새로 열 때마다 다시 켜야 합니다.

확인
Get-Command python   # Source가 C:\workspace\envs\gpuenv\Scripts\python.exe

"이 시스템에서 스크립트를 실행할 수 없으므로" 오류가 나면 아래 명령을 한 번 실행한 뒤 다시 켭니다. 내 계정에만 적용됩니다.

PowerShell · 한 번만
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
4

패키지 설치

환경을 켠 상태에서 실습 폴더로 이동해 설치합니다. 설치한 패키지는 실습 폴더가 아니라 켜져 있는 환경에 들어갑니다.

PowerShell · (gpuenv)가 보이는 상태
cd C:\workspace\practice_assignment\20261113
python -m pip install -r requirements.txt   # 목록대로 한 번에
python -m pip list                          # 설치된 패키지 확인

pip 대신 python -m pip로 쓰면 지금 켜진 환경에 설치되는 것이 분명해집니다. 설치 전에 줄 맨 앞의 환경 이름을 확인합니다.

5

VS Code에 연결

가상환경이 저장소 바깥에 있으면 VS Code가 자동으로 찾지 못합니다. 경로를 한 번 직접 알려 줍니다.

  1. VS Code에서 실습 저장소 폴더를 엽니다 (파일 → 폴더 열기).
  2. Ctrl+Shift+P → Python: Select Interpreter를 고릅니다.
  3. Enter interpreter path…를 고르고 아래 경로를 붙여 넣습니다.
인터프리터 경로
C:\workspace\envs\gpuenv\Scripts\python.exe

오른쪽 아래 상태 표시줄에 ('gpuenv')가 보이면 연결된 것입니다. 한 번 고르면 목록에 남아서, 다음부터는 목록에서 바꿉니다.

6

바꾸기 · 다시 만들기

하고 싶은 것방법
끄기deactivate
다른 환경으로 바꾸기바꿀 환경의 Activate.ps1을 실행합니다. 줄 맨 앞 이름이 바뀝니다.
켜지 않고 실행C:\workspace\envs\gpuenv\Scripts\python.exe main.py
처음부터 다시C:\workspace\envs\gpuenv 폴더를 지우고 2부터 다시 합니다. 실습 코드에는 영향이 없습니다.

환경 이름이 줄 앞에 안 보임3의 경로가 맞는지 확인합니다. ls C:\workspace\envs로 폴더가 있는지 봅니다.
