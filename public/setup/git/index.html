Git 설치 · 이름 · 이메일 · 저장소 시작 · 두 터미널의 차이펼치기접기

Git이 없다면 git-scm.com에서 설치합니다. 설치하면 Git Bash도 함께 생깁니다.

내 이름 · 이메일 등록

PowerShell · Git Bash 공통
git config --global user.name "내이름"
git config --global user.email "내이메일"
git config --global init.defaultBranch main   # 새 저장소 기본 브랜치 = main
git config --global pull.rebase false         # pull은 merge 방식으로

public 저장소에는 커밋 이메일이 공개됩니다. GitHub → Settings → Emails의 숫자+아이디@users.noreply.github.com을 쓰면 가려집니다.

로그인: 첫 git push 때 GitHub 로그인 창이 뜹니다. Sign in with your browser로 한 번 로그인하면 Windows가 기억합니다.

매일 루프 · commit · push · pull

status→add→commit→push

PowerShell · Git Bash 공통 · 올리기
git status                # 지금 상태 보기 (언제든)
git add .                 # 바뀐 파일 전부 Staging으로
git commit -m "메시지"     # 기록 하나 남기기
git push                  # GitHub로 올리기
PowerShell · Git Bash 공통 · 받기
git pull                  # GitHub의 새 커밋 받기 (다른 PC · 팀원)
PowerShell · Git Bash 공통 · 확인
git log --oneline         # 커밋 목록
git diff                  # 아직 add 안 한 변경 내용

파일 하나만 올리려면 git add main.py처럼 이름을 씁니다. 처음 push하는 저장소는 git push -u origin main으로 한 번 연결하면 그다음부터 git push만 씁니다.
