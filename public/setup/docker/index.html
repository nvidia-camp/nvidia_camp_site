1

WSL 2 설치

  1. Win 키 → PowerShell 입력 → 관리자 권한으로 실행을 고릅니다.
  2. 아래 명령을 실행하고 PC를 다시 시작합니다.
PowerShell (관리자)
wsl --install
  1. 다시 시작한 뒤 Ubuntu 창이 열려 사용자 이름과 비밀번호를 물으면 정해서 입력합니다. 비밀번호는 입력해도 화면에 보이지 않습니다.
  2. 버전을 확인하고 최신으로 올립니다.
PowerShell
wsl --version     # WSL 버전: 2.1.5 이상
wsl --update      # 최신으로 올리기
wsl -l -v         # Ubuntu의 VERSION이 2

이미 WSL이 설치되어 있으면 wsl --install은 도움말만 보여 줍니다. 그때는 wsl --update만 하고 넘어갑니다.

2

Docker Desktop 설치

  1. Docker 공식 설치 페이지에서 Docker Desktop for Windows - x86_64를 받습니다.
  2. 받은 Docker Desktop Installer.exe를 실행합니다.
  3. 설정 화면에서 Use WSL 2 instead of Hyper-V가 체크되어 있는지 확인하고 진행합니다.
  4. 설치가 끝나면 Close를 누릅니다.
  5. 시작 메뉴에서 Docker Desktop을 실행하고, 약관 화면에서 Accept를 누릅니다. 설치 직후에는 자동으로 실행되지 않습니다.

로그인 화면이 나오면 건너뛰어도 됩니다. 작업 표시줄 트레이의 고래 아이콘이 멈춰 있으면 준비가 끝난 것입니다. 개인 학습과 교육 목적은 무료입니다.

기본 명령

명령하는 일
docker pull 이미지이미지 내려받기
docker images내려받은 이미지 목록
docker run -d -p 8080:80 --name web nginx컨테이너 실행. -d 뒤에서 실행, -p 내PC포트:컨테이너포트, --name 이름
docker ps · docker ps -a실행 중인 컨테이너 · 멈춘 것까지 모두
docker logs web컨테이너가 출력한 내용 보기
docker exec -it web bash실행 중인 컨테이너 안으로 들어가기. exit로 나옴
docker stop web · docker rm web멈추기 · 지우기

위 nginx 예시를 실행한 뒤 브라우저에서 http://localhost:8080을 열면 컨테이너 안의 웹 서버가 보입니다.

5

Compose · 여러 컨테이너를 한 번에

프로젝트 폴더의 compose.yaml에 필요한 컨테이너를 적어 두고, 명령 하나로 올리고 내립니다.

PowerShell · compose.yaml이 있는 폴더에서
docker compose up -d     # 모두 실행
docker compose ps        # 상태 보기
docker compose logs -f   # 로그 따라 보기. Ctrl+C로 그만 보기
docker compose down      # 모두 멈추고 지우기

막히면

증상할 일
docker를 찾을 수 없음PowerShell 창을 닫고 새로 엽니다.
"error during connect" · "daemon is not running"Docker Desktop이 꺼져 있습니다. 시작 메뉴에서 실행하고 고래 아이콘이 멈출 때까지 기다립니다.
Docker Desktop이 WSL 오류로 시작되지 않음관리자 PowerShell에서 wsl --update 후 PC를 다시 시작합니다.
"가상화가 꺼져 있다"는 안내BIOS/UEFI에서 가상화(Virtualization)를 켜야 합니다. 강사에게 알려 주세요.
"port is already allocated"그 포트를 다른 프로그램이 쓰고 있습니다. -p 8081:80처럼 앞쪽 숫자를 바꿉니다.
이름이 이미 사용 중이라는 오류docker rm 이름으로 예전 컨테이너를 지우고 다시 실행합니다.
