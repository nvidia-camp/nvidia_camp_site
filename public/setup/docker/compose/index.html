compose.yaml · run 명령을 파일로

compose.yaml · 프로젝트 폴더에
services:
  web:
    image: nginx
    ports:
      - "8080:80"
  db:
    image: postgres
    environment:
      POSTGRES_PASSWORD: 1234
    volumes:
      - pgdata:/var/lib/postgresql
volumes:
  pgdata:
run 옵션compose.yaml
--name webweb:
이미지 nginximage: nginx
-p 8080:80ports:

들여쓰기는 스페이스 2칸입니다. 탭 문자를 쓰면 오류가 납니다.

2

명령 · up · down

PowerShell · Git Bash 공통 · compose.yaml이 있는 폴더에서
docker compose up -d     # 모두 만들어 실행
docker compose ps        # 상태 보기
docker compose logs -f   # 출력 따라 보기 · Ctrl+C로 그만 보기
docker compose down      # 모두 멈추고 지우기 (볼륨은 남음)

컨테이너 이름은 폴더이름-서비스-1로 붙습니다(예: myproject-web-1). down -v는 볼륨까지 지워 DB 데이터가 사라집니다.
