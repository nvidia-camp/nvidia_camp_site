Dockerfile · build

큰 그림 · Dockerfile로 이미지를 쌓습니다

Dockerfile 한 줄이 이미지의 층(layer) 하나가 됩니다. 아래 버튼을 누르면 해당 단계가 다시 재생됩니다.

내 PC
프로젝트 폴더내 코드 · Dockerfile
build
이미지 myappImage · 층을 쌓은 설치본
run
컨테이너Container · 실행한 것

1

Dockerfile · 3줄

myapp/
├─ app.py
└─ Dockerfile     ← 확장자 없음
app.py
print("Hello from container!")
Dockerfile
FROM python:3.13-slim
COPY app.py .
CMD ["python", "app.py"]
줄하는 일
FROM바탕이 될 이미지. Docker Hub에서 받아 옵니다
COPY내 PC의 파일을 이미지 안으로 복사
RUN이미지를 만들 때 명령 실행 (라이브러리 설치)
CMD컨테이너를 실행할 때 할 명령
2

build · run

PowerShell · Git Bash 공통 · myapp 폴더에서
docker build -t myapp .   # 지금 폴더(.)의 Dockerfile로 이미지 myapp 만들기
docker run myapp          # 실행 → Hello from container!

코드를 고치면 다시 build해야 이미지에 반영됩니다. -t는 이미지 이름(tag)이고, 끝의 .을 빠뜨리지 않습니다.

3

라이브러리가 필요할 때

requirements.txt를 먼저 복사해 설치하고, 코드는 그다음에 복사합니다.

Dockerfile
FROM python:3.13-slim
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY app.py .
CMD ["python", "app.py"]

이 순서면 app.py만 고쳤을 때 설치 층은 CACHED로 건너뛰어 build가 빠릅니다.
