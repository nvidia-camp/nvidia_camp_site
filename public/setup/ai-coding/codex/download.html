AI 코딩 도구 · ChatGPT Plus 이상 · 공식 문서 기준 (2026-11-14 확인)

Codex

OpenAI의 터미널 AI 코딩 도구입니다. ChatGPT 계정으로 로그인해서 씁니다. Windows에서는 WSL 없이 PowerShell에서 바로 동작합니다.

공통OpenCodeClaude CodeCodexagy
1

설치

PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

업데이트도 같은 명령입니다. Node.js가 있다면 npm install -g @openai/codex로 설치해도 됩니다.

2

처음 실행 · 로그인

새 PowerShell
cd 내-프로젝트-폴더
codex
  1. Sign in with ChatGPT를 고릅니다.
  2. 브라우저에서 ChatGPT 계정으로 로그인합니다.
  3. 로그인만 따로 할 때는 codex login, 로그아웃은 codex logout.
3

자주 쓰는 명령

입력하는 일
/init지금 폴더에 AGENTS.md 초안을 만듭니다
/new새 대화
/compact지금 대화를 요약해서 공간 확보
/model모델과 추론 강도 고르기
/diff바뀐 파일 보기 (git diff)
/review바뀐 코드를 Codex가 검토
/status지금 설정과 사용량
/resume지난 대화 이어서
codex exec "…"터미널에서: 한 번 실행하고 끝내기

되돌리기 명령이 따로 없으므로 작업 전후로 git 커밋을 해 둡니다.

4

권한: /permissions

Codex가 묻지 않고 할 수 있는 범위를 정합니다.

/permissions대화 중에 권한 범위 바꾸기
codex --sandbox read-only읽기만. 코드 설명·검토를 맡길 때
codex --yolo승인 요청·샌드박스 보호 없이 실행
5

안내문: AGENTS.md

이 프로젝트만프로젝트 폴더의 AGENTS.md
모든 프로젝트$HOME\.codex\AGENTS.md

실행할 때 한 번 읽으므로 고친 뒤에는 Codex를 다시 시작해야 합니다.
