AI 코딩 도구 · Google AI Pro 이상 · 공식 문서 기준 (2026-11-14 확인)

agy (Antigravity CLI)

Google의 터미널 AI 코딩 도구입니다. Google 계정으로 로그인해서 씁니다. Gemini CLI의 GEMINI.md 같은 설정을 그대로 읽습니다.

공통OpenCodeClaude CodeCodexagy
1

설치

PowerShell
irm https://antigravity.google/cli/install.ps1 | iex

끝나면 새 PowerShell 창에서 확인합니다.

새 PowerShell
agy --version

데스크톱 앱 Antigravity와는 다른 프로그램입니다. 이 페이지는 터미널용 agy입니다.

2

처음 실행 · 로그인

PowerShell
cd 내-프로젝트-폴더
agy
  1. 로그인 방법에서 Google OAuth를 고릅니다.
  2. 브라우저에서 Google 계정으로 로그인하고, 나온 코드를 복사해 터미널에 붙여 넣습니다.
  3. 색 테마 → 이용 약관 → Yes, I trust this folder(이 폴더 신뢰)를 차례로 고릅니다.
  4. 다음부터는 로그인 없이 바로 열립니다. 로그아웃은 /logout.
3

자주 쓰는 명령

입력하는 일
/clear새 대화 (/new도 같음)
/plan 할 일코드를 읽고 구현 계획부터 세우기
/rewind이전 시점으로 되돌리기 (/undo도 같음)
/model모델 바꾸기
/diff바뀐 내용 보기
/usage남은 사용량 보기
/resume지난 대화 고르기
!셸 모드: 터미널 명령을 바로 실행
/help전체 명령 보기
agy -p "…"터미널에서: 한 번 답하고 끝내기
4

모드: Shift+Tab

모드하는 일
default (기본)파일을 쓰기 전에 바뀐 내용을 보여 주고, 명령 실행 전에 묻습니다.
accept-edits파일 수정은 묻지 않지만 명령 실행은 묻습니다.
plan읽고 분석해서 계획부터 세웁니다.
자동 승인 (Skip)agy --dangerously-skip-permissions
도구 권한 요청을 자동 승인하며 시작합니다.

승인 창에서 y 허용, n 거부. 시작할 때 고르려면 agy --mode=plan.

5

안내문: AGENTS.md 또는 GEMINI.md

이 프로젝트만프로젝트 폴더의 AGENTS.md 또는 GEMINI.md
모든 프로젝트$HOME\.gemini\AGENTS.md 또는 GEMINI.md

찾은 파일을 모두 합쳐서 읽지만 하위 폴더의 안내문은 읽지 않습니다.
