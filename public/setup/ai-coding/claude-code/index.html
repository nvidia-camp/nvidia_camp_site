AI 코딩 도구 · Claude Pro 이상 · 공식 문서 기준 (2026-11-14 확인)

Claude Code

Anthropic의 터미널 AI 코딩 도구입니다. Claude Pro 구독으로 로그인해서 씁니다. 무료 Claude 계정에는 포함되지 않습니다.

0공통1OpenCode2Claude Code3Codex4agy
1

설치

PowerShell
irm https://claude.ai/install.ps1 | iex

관리자 권한은 필요 없습니다. 끝나면 새 PowerShell 창에서 확인합니다.

새 PowerShell
claude --version
claude doctor      # 설치 상태 점검

Git for Windows가 있으면 Claude Code가 bash 명령을 쓸 수 있습니다. 없으면 PowerShell로 동작합니다.

2

처음 실행 · 로그인

PowerShell
cd 내-프로젝트-폴더
claude
  1. 로그인 방법에서 Claude 구독 계정을 고릅니다.
  2. 브라우저가 열리면 로그인하고 승인합니다. 다음부터는 묻지 않습니다.
  3. 계정을 바꾸거나 다시 로그인할 때는 /login.
3

자주 쓰는 명령

입력하는 일
/init프로젝트를 살펴보고 CLAUDE.md 초안을 만듭니다
/clear새 대화
/compact지금 대화를 요약해서 공간 확보
/model모델 바꾸기
/resume지난 대화 고르기
Esc답하는 중에 멈추기
Esc 두 번빈 입력창에서: 이전 시점으로 코드·대화 되돌리기
/help전체 명령 보기
claude -c터미널에서: 이 폴더의 마지막 대화 이어서
claude -p "…"터미널에서: 한 번 답하고 끝내기
4

권한 모드: Shift+Tab

모드하는 일
Manual (기본)파일 수정·명령 실행 전에 묻습니다. 처음에는 이 모드로 씁니다.
accept edits파일 수정은 묻지 않고 합니다. 명령 실행은 묻습니다.
plan코드를 읽고 계획만 세웁니다. 계획을 승인하기 전에는 고치지 않습니다.

Windows에서 Shift+Tab이 안 먹으면 Alt+M.

5

안내문: CLAUDE.md

이 프로젝트만프로젝트 폴더의 CLAUDE.md
모든 프로젝트$HOME\.claude\CLAUDE.md

CLAUDE.md가 없으면 AGENTS.md를 읽습니다. 200줄 안쪽으로 짧게 둡니다.
