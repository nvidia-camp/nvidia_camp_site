OpenCode: 로컬 AI로 코딩하기

내 PC의 GPU에서 도는 모델이라 구독도 한도도 없고, 코드가 밖으로 나가지 않습니다. 대신 모델이 작고 기억하는 대화가 짧아서 쓰는 습관이 더 중요합니다. 설치는 로컬 AI 코딩 환경 설치에 있습니다.

로컬 모델과 바로 대화하기

코드 작업이 아니라 질문만 할 때는 OpenCode 없이 Ollama로 바로 물으면 됩니다.

PowerShell
ollama run gpt-oss:20b      # 대화 시작. 끝낼 때는 /bye
ollama ps                   # 지금 올라가 있는 모델 · GPU 사용 확인
ollama stop gpt-oss:20b     # 모델 내리기: GPU 메모리 약 14GB를 돌려받음

설치 3-2에서 1시간 유지로 설정했다면 마지막 사용 뒤 1시간 동안 모델이 GPU에 남아 있어 바로 답합니다. Ollama 앱의 Chat 화면도 같은 모델을 씁니다. 게임이나 다른 GPU 실습 전에는 ollama stop으로 모델을 내려 두십시오.

로컬 모델이라 더 지킬 5가지

  1. "완료했다"는 말을 더 의심합니다.작은 모델은 하지 않은 일을 했다고 말하는 경우가 많으니 화면의 실행 기록과 파일을 직접 봐야 합니다.
  2. 테스트를 고치지 말라고 적어 둡니다.테스트가 실패하면 코드 대신 테스트를 고치는 경우가 있으니 바뀐 파일 목록에 테스트가 있는지 봅니다.
  3. 주제가 바뀌면 /new로 새로 시작합니다.화면의 %는 128K 기준이라 50% 근처면 이미 한계(64K)입니다. 했던 일을 반복하거나 규칙을 잊으면 넘친 것입니다.
  4. 작게 시키고, 계획을 먼저 봅니다.여러 파일을 고치는 일은 Plan으로 계획부터 세웁니다.
  5. 입력창 아래 모델을 확인합니다.gpt-oss:20b Ollama가 아니면 질문이 외부 서버로 전송됩니다.

입력창에 /만 입력하면 전체 목록이 나옵니다.

Plan → Build

Build는 파일을 고치고 명령을 실행합니다. Plan은 코드를 읽고 계획만 세우며 파일을 고치지 않습니다. 작은 모델은 큰 일을 한 번에 시키면 헤매기 쉬워서 계획을 먼저 보면 실패가 크게 줄어듭니다.

  1. Shift+Tab으로 Plan → "이 기능을 넣으려면 어떤 파일을 어떻게 바꿔야 하는지 계획만 세워줘"
  2. 계획을 읽고 틀린 부분을 대화로 고칩니다.
  3. Shift+Tab으로 Build → "그 계획대로 진행해줘"

AGENTS.md · 프로젝트 안내문

대화를 시작할 때마다 모델에게 자동으로 전달되는 안내문입니다. 프로젝트 폴더에 두면 그 프로젝트에만, $HOME\.config\opencode\AGENTS.md에 두면 모든 프로젝트에 적용됩니다.

AGENTS.md 예시
# 프로젝트 안내
- Python 3.12, 실행: `python main.py`
- 답변과 주석은 한국어로
- 파일을 고친 뒤에는 반드시 실행해서 확인할 것

짧게 쓰는 것이 좋습니다. 매 요청마다 대화 길이(64K)를 차지하기 때문입니다. OpenCode는 CLAUDE.md를 읽지 않으니 Claude Code와 같이 쓰는 프로젝트라면 AGENTS.md를 따로 만들어야 합니다.

승인 창

Allow once이번 한 번만 허용
Allow always이 프로젝트에서 같은 종류는 계속 허용
Reject거부

묻지 않고 모두 허용하는 opencode --auto는 망가져도 되는 테스트 폴더에서만 쓰십시오. 로컬 모델은 실수가 잦아서 특히 그렇습니다.
