Python 가상환경

실습별로 필요한 패키지를 따로 담아 두는 폴더입니다. 명령 두 줄로 만들고 설치합니다.

practice_assignment\
└─ envs\
   ├─ requirements-gpu.txt        ← 설치 목록
   ├─ requirements-backend.txt
   ├─ requirements-all.txt
   ├─ .gpuenv\                    ← GPU 실습용 환경
   ├─ .backendenv\                ← 서버 · DB 실습용 환경
   └─ .venv\                      ← (선택) 위 둘을 합친 하나의 환경
환경설치 목록쓰는 실습
.gpuenvrequirements-gpu.txtPython 기초 · ML · DL · Vision · Transformer
.backendenvrequirements-backend.txtFastAPI · DB 연동 · Prompt · Context

pip로 설치되지 않는 프로그램

가상환경과는 별개로 PC에 직접 설치합니다. 한 번만 설치하며, Python은 가상환경을 만들기 전에 꼭 필요합니다.

프로그램버전필요한 실습받는 곳

PostgreSQL + pgAdmin 418SQL (11/11) · API와 DB 연동 (11/12)PostgreSQL 가이드

CUDA Toolkit은 따로 설치하지 않습니다. PyTorch를 설치할 때 함께 들어옵니다. Python 설치 화면에서는 py launcher 항목을 켜 둡니다.

터미널 · Python 확인
py -3.13 --version # Python 3.13.x
1

설치 목록 받기

아래 명령은 모두 practice_assignment 폴더에서 연 PowerShell 또는 Git Bash에서 실행합니다. 먼저 envs 폴더를 만들고, 받은 파일을 그 안에 저장합니다.

터미널
mkdir envs

requirements-gpu.txt requirements-backend.txt requirements-all.txt (.venv용)

받은 파일을 practice_assignment\envs 안으로 옮깁니다. .gpuenv와 .backendenv를 쓰면 앞의 두 파일, .venv 하나만 쓰면 requirements-all.txt만 받습니다.

2

가상환경 만들고 설치 · 명령 두 줄

  • 1환경을 만듭니다. py -3.13 -m venv 뒤에 만들 폴더를 씁니다.
  • 2설치 목록대로 설치합니다. pip install -r 뒤에 설치 목록 파일을 씁니다.
.gpuenv
py -3.13 -m venv envs\.gpuenv
envs\.gpuenv\Scripts\python.exe -m pip install -r envs\requirements-gpu.txt
.backendenv
py -3.13 -m venv envs\.backendenv
envs\.backendenv\Scripts\python.exe -m pip install -r envs\requirements-backend.txt
.venv (선택) · 위 둘 대신 이것 하나만
py -3.13 -m venv envs\.venv
envs\.venv\Scripts\python.exe -m pip install -r envs\requirements-all.txt

Git Bash에서는 경로를 \가 아니라 /로 씁니다.

.gpuenv는 PyTorch(CUDA)를 받느라 10분 넘게 걸립니다. 마지막 줄에 Successfully installed …가 나올 때까지 기다립니다.

3

터미널과 VS Code에서 같은 환경 쓰기

실행할 Python을 고르는 곳이 두 곳입니다. 둘 다 같은 환경을 가리키게 합니다.

터미널환경을 켭니다 (Activate)
VS Code인터프리터를 고릅니다 (Select Interpreter)
↓   ↓
같은 환경의 python.exe envs\.gpuenv\Scripts\python.exe

터미널 · 켜기

practice_assignment 폴더에서
envs\.gpuenv\Scripts\Activate.ps1

줄 맨 앞에 (.gpuenv)가 보이면 켜진 것입니다. 다른 환경은 이름만 바꿉니다(.backendenv, .venv). 끌 때는 deactivate를 입력합니다.

VS Code · 고르기

  1. VS Code에서 practice_assignment 폴더를 엽니다 (파일 → 폴더 열기).
  2. Ctrl+Shift+P → Python: Select Interpreter를 고릅니다.
  3. Enter interpreter path…를 고르고 아래 경로를 붙여 넣습니다.
인터프리터 경로 · 쓸 환경 한 줄
.\envs\.gpuenv\Scripts\python.exe
.\envs\.backendenv\Scripts\python.exe

오른쪽 아래 상태 표시줄에 ('.gpuenv')처럼 환경 이름이 보이면 연결된 것입니다. 한 번 넣은 경로는 목록에 남습니다.

참고 · 두 곳이 같은 환경인지 확인

터미널과 VS Code의 Python 실행에서 아래 명령을 각각 실행해 경로가 같은지 봅니다. 다르면 3의 켜기, 고르기를 다시 합니다.

터미널 · 실제 실행되는 Python
