knowledge_lab에서 Query Tool 열기

Query Tool은 트리에서 선택한 DB에 붙어서 열립니다. 수업에서 가장 자주 나는 실수가 postgres DB에서 실습 SQL을 실행하는 것입니다.

  1. 1교시에 postgres DB의 Query Tool에서 CREATE DATABASE knowledge_lab; 한 문장만 실행합니다.
  2. 트리의 Databases를 오른쪽 클릭 → Refresh. knowledge_lab이 나타납니다.
  3. knowledge_lab을 선택하고 Tools → Query Tool로 새 Query Tool을 엽니다.
  4. 2 연결 표시가 knowledge_lab/postgres@PostgreSQL 18인지 보고, 아래 한 줄로 한 번 더 확인합니다.
Query Tool · knowledge_lab
SELECT current_database();

Data Output에 knowledge_lab이 나오면 맞는 DB입니다. postgres가 나오면 3번부터 다시 합니다.

5

SQL 실행하기

방법실행되는 범위
▶ Execute script · F5편집기 전체. 드래그로 선택해 두면 선택한 부분만 실행됩니다.
Execute query · Alt+F5커서가 있는 문장 하나 (밑줄로 표시)
Explain · F7실행하지 않고 실행 계획만 봅니다 (7교시)

수업 규칙실습 파일은 -- @step 주석으로 구간이 나뉘어 있습니다. 한 구간씩 드래그로 선택하고 F5를 누릅니다. 여러 문장을 한꺼번에 실행하면 Data Output에는 마지막 문장 결과만 남습니다.

  • Auto commit이 켜져 있어 한 문장씩 바로 저장됩니다. BEGIN;을 실행했다면 COMMIT;이나 ROLLBACK;까지 같은 Query Tool 탭에서 이어 갑니다.
  • 오류가 난 뒤에는 ROLLBACK; 한 줄만 따로 선택해 실행합니다. 설정은 1 셋업 4단계에 있습니다.
