psql 접속 가이드

psql은 PostgreSQL을 설치할 때 함께 들어온 명령창 도구입니다. 수업은 pgAdmin으로 하므로 해 보지 않아도 됩니다.

1

SQL Shell (psql) 열기

Win 키를 누르고 psql을 검색해 SQL Shell (psql)을 엽니다.

2

접속하기

  1. Server, Database, Port, Username은 대괄호 안이 기본값입니다. Enter를 네 번 누릅니다.
  2. postgres 사용자의 암호에 설치 때 정한 비밀번호를 입력하고 Enter. 글자가 보이지 않아도 입력되고 있습니다.
  3. postgres=#가 보이면 접속된 것입니다.
3

버전과 연결 정보 보기

postgres=# 뒤에 한 줄씩 입력하고 Enter를 누릅니다.

SQL Shell (psql)
SELECT version();
\conninfo
\q

SELECT version();은 PostgreSQL 18.x로 시작하는 한 줄, \conninfo는 데이터베이스·유저 postgres, 호스트 localhost, 포트 5432를 보여 줍니다. \q는 끝내기입니다. psql은 pgAdmin과 달리 여러 문장의 결과를 차례로 모두 보여 줍니다.
