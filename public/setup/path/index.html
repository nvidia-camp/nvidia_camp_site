경로 설정 (PATH)

프로그램을 설치했는데 "명령을 찾을 수 없다"고 나올 때 보는 가이드입니다. 왜 못 찾는지, 어떻게 연결하는지, 연결됐는지 어떻게 확인하는지를 순서대로 봅니다. 예시는 Tesseract입니다.

왜 필요한가 · Windows가 명령을 찾는 방식

PowerShell에 tesseract라고 입력하면, Windows는 PATH에 적힌 폴더를 위에서부터 하나씩 열어 tesseract.exe가 있는지 찾습니다. PATH는 "명령을 찾아볼 폴더 목록"입니다.

추가 전

입력 tesseract --version

  1. C:\WINDOWS\system32없음
  2. C:\Program Files\Git\cmd없음
  3. C:\Users\…\Python313없음

목록 끝까지 없음 → "인식되지 않습니다" 오류

tesseract.exe는 C:\Program Files\Tesseract-OCR에 설치되어 있습니다. 그 폴더가 목록에 없어서 못 찾는 것입니다.

추가 후

입력 tesseract --version

  1. C:\WINDOWS\system32없음
  2. C:\Program Files\Git\cmd없음
  3. C:\Users\…\Python313없음
  4. C:\Program Files\Tesseract-OCRtesseract.exe 있음

찾음 → 그 파일을 실행

목록에 폴더 한 줄을 더했을 뿐입니다. 이제 어느 폴더에서 입력해도 실행됩니다.

전체 흐름 · 설치부터 확인까지

  1. 설치실행 파일이 설치 폴더에 놓입니다
  2. 폴더 찾기실행 파일이 든 폴더의 경로를 알아냅니다
  3. PATH에 저장그 경로를 Windows 설정(내 계정)에 기록합니다
  4. 새 창 열기PowerShell은 열릴 때 PATH를 읽습니다
  5. 확인이름만 입력해 실행되는지 봅니다

"폴더 찾기"와 "PATH에 저장"을 하는 방법은 두 가지입니다. 하는 일과 결과는 같습니다. 하나만 고릅니다.

방법 A GUI · 창을 눌러서 파일 탐색기와 환경 변수 창을 씁니다. 눈으로 보면서 하므로 처음이면 이쪽을 권합니다. 방법 B 터미널 · 명령을 입력해서 PowerShell 명령 몇 줄로 끝냅니다. 같은 일을 여러 번 하거나 기록으로 남길 때 편합니다.

내 프로그램에 적용하기

이 가이드의 명령과 경로는 Tesseract를 예로 든 것입니다. 색이 다른 글자가 예시이며, 이 부분만 내 프로그램의 것으로 바꿉니다. 나머지는 그대로 씁니다.

1

지금 상태 확인

먼저 정말 PATH 문제인지 확인합니다. Get-Command는 Windows가 그 이름으로 찾아낸 파일이 어디 있는지 알려 줍니다.

PowerShell
tesseract --version
Get-Command tesseract | Select-Object -ExpandProperty Source
결과뜻
C:\Program Files\Tesseract-OCR\tesseract.exe처럼 경로가 나옴이미 연결되어 있습니다. 더 할 일이 없습니다.
"…인식되지 않습니다" 오류PATH에 폴더가 없습니다. 2로 갑니다.

설치 직후라면 PowerShell 창을 닫고 새로 연 뒤 다시 해 봅니다. 열려 있던 창은 예전 PATH를 갖고 있습니다. 다른 프로그램은 tesseract 자리에 그 프로그램의 명령 이름을 넣습니다. --version이 없는 프로그램도 있으니, 그때는 둘째 줄만 봅니다.

방법 A

GUI · 창을 눌러서 연결

A-1 폴더 찾기 · 파일 탐색기

  1. 파일 탐색기에서 프로그램을 설치한 폴더를 엽니다. 대부분 C:\Program Files 아래에 있습니다.
  2. 그 안에서 실행 파일을 찾습니다. 이름이 명령 이름과 같고, 유형이 응용 프로그램인 파일입니다.
  3. 위쪽 주소 표시줄을 누르면 경로가 글자로 바뀝니다. Ctrl+C로 복사합니다.
탐색기에서 보이는 것뜻
이름에 .exe가 안 보임Windows는 기본으로 확장명을 숨깁니다. 유형 열이 "응용 프로그램"이면 .exe 파일입니다.
이름이 비슷한 파일이 여러 개tesseract.1(문서), tesseract-uninstall(제거 프로그램)은 아닙니다. 명령 이름과 정확히 같은 응용 프로그램을 고릅니다.
실행 파일이 안 보임bin 폴더 안에 있는 경우가 많습니다. 그때는 bin 폴더가 PATH에 넣을 폴더입니다.

파일이 아니라 폴더를 넣습니다. 실행 파일이 C:\Program Files\Tesseract-OCR\tesseract.exe라면 PATH에 넣을 값은 파일명을 뺀 C:\Program Files\Tesseract-OCR입니다.

설치 폴더를 모르면 시작 메뉴에서 프로그램을 찾아 우클릭 → 파일 위치 열기를 누릅니다. 바로 가기가 나오면 한 번 더 우클릭 → 파일 위치 열기를 누릅니다.

A-2 PATH에 저장 · 환경 변수 창

  1. Win 키 → 환경 변수 입력 → 계정의 환경 변수 편집을 엽니다.
  2. 위쪽 사용자 변수 목록에서 Path를 선택하고 편집을 누릅니다.
  3. 새로 만들기를 누르고 A-1에서 복사한 폴더 경로를 붙여 넣습니다.
  4. 확인을 두 번 눌러 닫습니다. 이때 Windows 설정에 저장됩니다.

캡처의 회색 칸은 PC 사용자 이름을 가린 것입니다. 세 번째 캡처의 목록이 바로 "명령을 찾아볼 폴더 목록"입니다.

기존 항목은 지우지 않습니다. 다른 폴더를 지우면 잘 되던 명령이 실행되지 않습니다. 추가만 합니다.

방법 B

터미널 · 명령을 입력해서 연결

B-1 폴더 찾기 · Get-ChildItem

프로그램이 설치되는 폴더들 안에서 실행 파일 tesseract.exe를 찾아, 그 파일이 든 폴더 경로를 출력합니다.

PowerShell
Get-ChildItem "C:\Program Files", "C:\Program Files (x86)", "$env:LOCALAPPDATA\Programs" -Recurse -Filter tesseract.exe -ErrorAction SilentlyContinue | Select-Object -ExpandProperty DirectoryName

출력 예: C:\Program Files\Tesseract-OCR. 이 값을 B-2에 넣습니다. 찾는 데 시간이 조금 걸립니다. 아무것도 나오지 않으면 실행 파일 이름이 다르거나 다른 곳에 설치된 것이니 방법 A의 A-1로 찾습니다.

B-2 PATH에 저장 · 명령 2줄

방법 A의 환경 변수 창에서 한 일을 명령으로 하는 것입니다. 둘째 줄의 폴더만 B-1에서 찾은 값으로 바꿔 실행합니다.

PowerShell · 한 번만 실행
$old = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$old;C:\Program Files\Tesseract-OCR", "User")
  1. 1줄 · 지금 저장된 PATH를 읽어 옴 Windows 설정에서 내 계정(User)의 Path 값을 꺼내 $old라는 이름으로 잠시 들고 있습니다. 폴더들이 ;로 이어진 한 줄입니다. C:\Users\…\Python313;C:\Users\…\npm
  2. 2줄 · 뒤에 새 폴더를 붙여서 다시 저장 들고 있던 값($old) 뒤에 ;와 새 폴더를 붙여 Windows 설정에 저장합니다. C:\Users\…\Python313;C:\Users\…\npm;C:\Program Files\Tesseract-OCR
  3. 결과 · 폴더 목록에 한 줄이 늘어남 방법 A의 환경 변수 편집 창에서 새로 만들기로 한 줄을 넣은 것과 같습니다. 다음에 여는 PowerShell 창부터 이 목록을 읽습니다.
명령의 부분뜻
"Path"바꿀 환경 변수의 이름입니다. 바꾸지 않습니다.
"User"내 계정에만 적용합니다. 방법 A의 사용자 변수와 같은 곳입니다. 바꾸지 않습니다.
$old;기존 목록을 그대로 두고 뒤에 더한다는 뜻입니다. 지우면 기존 목록이 사라집니다. 반드시 남깁니다.
C:\Program Files\Tesseract-OCR추가할 폴더입니다. 이 부분만 바꿉니다.

한 번만 실행합니다. 두 번 실행하면 같은 폴더가 두 번 들어갑니다. 잘못 넣었으면 방법 A의 환경 변수 창에서 그 줄을 지웁니다.

저장하지 않고 지금 창에서만 시험해 보기
PowerShell
$env:Path += ";C:\Program Files\Tesseract-OCR"

지금 창이 갖고 있는 목록에만 더합니다. 창을 닫으면 사라집니다. 맞는 폴더인지 먼저 시험할 때 씁니다.

3

새 창에서 확인

PowerShell은 열릴 때 한 번 PATH를 읽어 갑니다. 그래서 저장하기 전에 열려 있던 창은 예전 목록을 갖고 있습니다. 창을 닫고 새로 연 뒤 확인합니다. VS Code 터미널을 쓴다면 VS Code를 다시 시작합니다.

확인하는 것명령기대하는 결과

어느 파일이 실행되는가Get-Command tesseract | Select-Object -ExpandProperty SourceC:\Program Files\Tesseract-OCR\tesseract.exe
목록에 들어갔는가$env:Path -split ';'폴더가 한 줄씩 나오고, 방금 넣은 폴더가 보입니다
