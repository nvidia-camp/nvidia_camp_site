VS Code 확장

VS Code에 기능을 더하는 프로그램입니다. Python 실습에 꼭 필요한 기본 확장과, 실습별로 있으면 편한 추천 확장을 정리했습니다.

기본 확장

Python 코드 실행 · 자동 완성 · 디버깅 · 노트북에 필요합니다. 모두 설치합니다.

추천 확장

없어도 실습은 됩니다. 필요한 과목에서 골라 설치합니다.

설치됐다는 표시

확장 화면에서 설치 버튼이 톱니바퀴 아이콘으로 바뀝니다.

1

설치 방법

  1. VS Code 왼쪽 막대에서 확장 아이콘을 누릅니다 (Ctrl+Shift+X).
  2. 검색 칸에 확장 이름을 입력합니다.
  3. 이름과 게시자가 아래 표와 같은 항목에서 설치를 누릅니다.

게시자를 꼭 확인합니다. 이름이 비슷한 확장이 많습니다. 표의 게시자와 다르면 다른 확장입니다.

명령으로 한 번에 설치하기
PowerShell · 기본 확장 5개
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
code --install-extension ms-python.debugpy
code --install-extension ms-toolsai.jupyter
code --install-extension MS-CEINTL.vscode-language-pack-ko

code를 찾을 수 없다고 나오면 VS Code를 다시 시작하거나 경로 설정 (PATH)을 봅니다.

2

기본 확장 · 모두 설치

확장게시자하는 일
Python
ms-python.python		MicrosoftPython 파일 실행, 가상환경(인터프리터) 선택
Pylance
ms-python.vscode-pylance		Microsoft자동 완성, 함수 설명, 오류 밑줄
Python Debugger
ms-python.debugpy		Microsoft중단점을 걸고 한 줄씩 실행
Jupyter
ms-toolsai.jupyter		Microsoft.ipynb 노트북을 VS Code에서 열고 실행
Korean Language Pack
MS-CEINTL.vscode-language-pack-ko		Microsoft메뉴를 한국어로 표시. 설치 후 VS Code를 다시 시작

Python 확장을 설치하면 Pylance와 Python Debugger가 함께 설치되는 경우가 많습니다. 이미 설치되어 있으면 넘어갑니다. 가상환경을 고르는 방법은 Python 가상환경 5단계에 있습니다.

확인 · 관리

하고 싶은 것방법
설치된 확장 보기확장 화면 검색 칸에 @installed를 입력합니다. 터미널에서는 code --list-extensions
잠깐 끄기확장을 선택하고 사용 안 함을 누릅니다.
지우기확장을 선택하고 제거를 누릅니다.
한국어로 바꾸기Ctrl+Shift+P → Configure Display Language → 한국어

막히면

증상할 일
설치했는데 동작하지 않음VS Code를 완전히 닫고 다시 엽니다.
실행 버튼(▷)이 보이지 않음Python 확장이 설치됐는지, 연 파일이 .py인지 확인합니다.
import에 노란 밑줄인터프리터가 다른 Python입니다. 가상환경을 VS Code에 연결합니다.
노트북에서 커널을 고르라고 나옴오른쪽 위 커널 선택에서 실습에 쓰는 가상환경을 고릅니다.
메뉴가 영어로 나옴4의 "한국어로 바꾸기"를 한 뒤 VS Code를 다시 시작합니다.
