OpenCode 설치

터미널에서 쓰는 AI 코딩 도구 OpenCode에 내 PC의 로컬 모델을 연결합니다. 질문과 코드가 외부 서버로 나가지 않습니다.

1설치2사용법
설치되는 것
  • Node.js (npm 포함)
  • Ollama · 로컬 모델 실행기
  • 모델 gpt-oss:20b · 13GB
  • OpenCode v2
필요한 것
  • NVIDIA GPU 메모리 16GB
  • C: 여유 공간 40GB 이상
  • 설치를 맡길 AI 코딩 에이전트 (Claude Code 등)
끝났다는 표시

설치는 AI 에이전트에게 맡기기

  1. 설치 문서를 내려받습니다.
SETUP_FOR_AI.md 내려받기
  1. AI 코딩 에이전트에게 이 파일을 주고 이렇게 말합니다.
에이전트에게
SETUP_FOR_AI.md 문서대로 내 PC에 OpenCode와 로컬 AI 모델을 설치해줘.
  1. 에이전트가 명령을 실행하기 전에 승인을 요청합니다. 명령이 무엇을 하는지 읽고 승인합니다. 모델 다운로드(13GB)에 10분쯤 걸립니다.
  2. 에이전트가 멈추고 직접 하라고 하면 아래 2~4를 따라 합니다.
AI 에이전트 없이 직접 설치
PowerShell
winget install --id OpenJS.NodeJS.LTS -e
irm https://ollama.com/install.ps1 | iex
setx OLLAMA_KEEP_ALIVE 1h
# 아래 2를 마치고 Ollama를 껐다 켠 뒤, 새 PowerShell 창에서
ollama pull gpt-oss:20b
npm install -g --allow-scripts=@opencode/cli @opencode/cli

설정 파일 두 개(opencode.jsonc · AGENTS.md)는 SETUP_FOR_AI.md 5단계의 내용을 $HOME\.config\opencode\에 그대로 만듭니다.

2

Ollama 대화 길이를 64k로

직접
  1. 시작 메뉴에서 Ollama 앱을 엽니다. 첫 화면의 Apps 목록은 누르지 않습니다.
  2. 왼쪽 Settings → Context length 슬라이더를 64k로 옮깁니다.

64k보다 올리지 않습니다. 128k는 GPU 메모리를 넘어 느려집니다. 같은 화면의 Expose Ollama to the network는 꺼진 채로 둡니다.

3

OpenCode 실행하고 모델 확인

직접

새 PowerShell 창에서 빈 테스트 폴더로 가서 실행합니다. OpenCode는 실행한 폴더의 파일을 직접 고칩니다.

PowerShell
mkdir $HOME\opencode-test -Force
cd $HOME\opencode-test
opencode

입력창 아래가 gpt-oss:20b Ollama이면 됩니다.

Iceman Free OpenCode로 보이면 클라우드 모델입니다. 이대로 질문하면 외부 서버로 전송됩니다. /models를 입력하고 gpt-oss:20b를 고릅니다.

4

첫 작업 시켜 보기

직접
OpenCode 입력창
hello.py 파일을 만들고, "Hello, OpenCode!"를 출력하는 프로그램을 작성한 뒤 python으로 실행해서 결과를 보여줘

승인 창이 뜨면 내용을 읽고 허용합니다. 폴더에 hello.py가 생기고 화면에 Hello, OpenCode!가 보이면 설치가 끝난 것입니다.

증상할 일

ollama만 입력했더니 메뉴가 뜸정상입니다. Esc로 닫습니다.

파일을 고치지 않고 말로만 답함입력창 아래 모델이 gpt-oss:20b Ollama인지, ollama ps의 CONTEXT가 65536인지 확인합니다.
nvidia-smi가 없음 · 다운로드가 아주 느림강사에게 알려 주세요.
